# C20. do while 循环

## 节点定位

- 所属模块：控制流程
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：处理至少需要执行一次的循环场景。

## 学习目标

- 能说明 `do while` 与 `while` 的区别。
- 能理解 `do while` 是“先执行，后判断”。
- 能写出正确的 `do while` 语法，并记住末尾分号。
- 能使用 `do while` 编写菜单循环和输入校验程序。
- 能判断什么时候适合使用 `do while`。
- 能避免条件写反、忘记分号、无法退出等常见错误。

## 初学者导读

C18 学习的 `while` 是“先判断，后执行”。如果一开始条件不成立，循环体一次也不会执行。

`do while` 不同，它是“先执行一次循环体，再判断是否继续”。因此，不管条件最开始是否成立，循环体至少会执行一次。

这类结构适合下面的场景：

- 菜单至少要显示一次。
- 用户至少要输入一次数据。
- 程序至少要执行一次操作，然后再询问是否继续。

如果一个任务天然要求“先做一次，再决定是否重复”，就可以考虑 `do while`。

## 关键术语说明

- 先执行后判断：`do while` 的核心特点。
- 循环体：`do { ... }` 中反复执行的代码。
- 循环条件：`while (条件);` 中决定是否继续的表达式。
- 至少执行一次：即使条件第一次判断为假，循环体也已经执行过一次。
- 菜单循环：显示菜单、读取选择、根据选择处理，并反复显示。
- 输入校验：反复要求用户输入，直到数据合法。
- 尾部分号：`do while` 结构最后的分号，是语法的一部分。

## 学习思路

学习 `do while` 时，建议抓住三个问题：

1. 哪些代码必须至少执行一次？
2. 执行完一次后，用什么条件决定是否继续？
3. 条件中的变量是否会在循环体中更新？

如果不能明确回答这些问题，说明暂时不适合使用 `do while`。

## 核心概念

`do while` 的基本形式是：

```c
do {
    循环体;
} while (条件);
```

执行过程是：

1. 先执行 `do { ... }` 中的循环体。
2. 再判断 `while (条件)`。
3. 如果条件为真，回到 `do` 再执行一轮。
4. 如果条件为假，循环结束。

注意：最后的分号不能省略。

## 最小示例

```c
int i = 1;

do {
    printf("%d\n", i);
    i++;
} while (i <= 5);
```

输出结果：

```text
1
2
3
4
5
```

这段代码和普通 `while` 类似，但执行顺序不同：它先输出，再判断是否继续。

## 至少执行一次

`do while` 最重要的特点是循环体至少执行一次。

```c
int i = 10;

do {
    printf("%d\n", i);
    i++;
} while (i <= 5);
```

虽然 `i <= 5` 一开始就是假的，但程序仍然会先执行一次循环体，输出：

```text
10
```

如果换成 `while`：

```c
int i = 10;

while (i <= 5) {
    printf("%d\n", i);
    i++;
}
```

这段代码一次也不会输出。

## while 与 do while 的区别

| 对比点 | `while` | `do while` |
|---|---|---|
| 判断位置 | 循环体之前 | 循环体之后 |
| 是否可能一次都不执行 | 可能 | 不可能 |
| 适合场景 | 先确认条件，再决定是否执行 | 先执行一次，再决定是否重复 |
| 常见用途 | 未知次数循环、输入读取 | 菜单、输入校验、是否继续 |

简单记忆：

- 不确定能不能执行：用 `while`。
- 至少要执行一次：可以用 `do while`。

## 菜单循环

菜单程序通常适合使用 `do while`，因为菜单至少应该显示一次。

```c
int choice;

do {
    printf("1. Start\n");
    printf("2. Settings\n");
    printf("0. Exit\n");
    scanf("%d", &choice);

    if (choice == 1) {
        printf("Start selected\n");
    } else if (choice == 2) {
        printf("Settings selected\n");
    } else if (choice != 0) {
        printf("Invalid choice\n");
    }
} while (choice != 0);
```

执行逻辑：

1. 先显示菜单。
2. 读取用户输入。
3. 根据输入执行对应操作。
4. 如果用户输入不是 0，就继续显示菜单。
5. 如果输入 0，循环结束。

## 输入校验

有些数据必须输入一次，然后检查是否合法。如果不合法，就要求重新输入。

```c
int score;

do {
    printf("Input score between 0 and 100:\n");
    scanf("%d", &score);
} while (score < 0 || score > 100);

printf("score = %d\n", score);
```

这段代码会至少要求输入一次分数。如果分数不在 0 到 100 之间，就继续输入。

与普通 `while` 相比，`do while` 可以避免在循环前单独写一次 `scanf`。

## 是否继续的循环

有些程序会在执行完一次操作后询问用户是否继续。

```c
char answer;

do {
    printf("processing...\n");
    printf("Continue? y/n\n");
    scanf(" %c", &answer);
} while (answer == 'y' || answer == 'Y');
```

这里 `%c` 前面的空格用于跳过前一次输入留下的换行符。这个细节在 C14 输入输出中已经介绍过。

## 条件写法要特别清楚

`do while` 的条件表示“满足什么条件就继续”，不是“满足什么条件就停止”。

例如菜单中输入 0 退出：

```c
} while (choice != 0);
```

含义是：只要选择不是 0，就继续循环。

如果误写成：

```c
} while (choice == 0);
```

就变成：只有选择 0 才继续循环。这与“0 表示退出”的意图相反。

写条件时可以先用一句话描述：

- “不是 0 就继续”：`choice != 0`
- “分数不合法就继续输入”：`score < 0 || score > 100`
- “回答 y 就继续”：`answer == 'y' || answer == 'Y'`

## 末尾分号

`do while` 的最后必须有分号。

正确：

```c
do {
    printf("hello\n");
} while (again);
```

错误：

```c
do {
    printf("hello\n");
} while (again)
```

因为 `do while` 是一个完整语句，末尾的分号属于语法的一部分。

## 可能的死循环

`do while` 也可能形成死循环。

错误示例：

```c
int choice = 1;

do {
    printf("menu\n");
} while (choice != 0);
```

这里 `choice` 一直是 1，没有在循环体中更新，所以条件永远成立。

修正方式：

```c
int choice;

do {
    printf("menu\n");
    scanf("%d", &choice);
} while (choice != 0);
```

只要循环依赖某个变量，就必须保证这个变量在循环中有机会改变。

## 示例

```c
#include <stdio.h>

int main(void) {
    int score;

    do {
        printf("Input score between 0 and 100:\n");
        scanf("%d", &score);
    } while (score < 0 || score > 100);

    printf("valid score = %d\n", score);
    return 0;
}
```

## 代码逐行解释

- `int score;`：声明变量保存分数。
- `do { ... }`：先执行一次输入过程。
- `printf(...)`：提示用户输入合法分数。
- `scanf("%d", &score);`：读取用户输入。
- `while (score < 0 || score > 100);`：如果分数不合法，就继续循环。
- 当分数合法时，条件为假，循环结束。
- 最后输出合法分数。

## 常见错误

- 忘记 `while (条件);` 后面的分号。
- 把继续条件写成停止条件，导致逻辑相反。
- 循环体中没有更新条件相关变量，导致死循环。
- 在不需要至少执行一次的场景中滥用 `do while`。
- 读取字符时忘记处理换行符。
- 菜单没有设计清楚退出选项。

## 初学者常见误区

- `do while` 一定至少执行一次循环体。
- 末尾分号不是多余的，而是语法要求。
- `while (choice != 0)` 表示“不是 0 就继续”，不是“等于 0 就退出”本身。
- 输入校验中，条件通常写“不合法时继续”。
- 如果先判断再执行更合理，就应该使用普通 `while`。
- `do while` 和 `while` 能实现类似功能，但表达的程序意图不同。

## 语法格式

```c
do {
    循环体;
    状态更新;
} while (条件);
```

菜单常用形式：

```c
do {
    显示菜单;
    读取选择;
    处理选择;
} while (选择不是退出值);
```

输入校验常用形式：

```c
do {
    读取输入;
} while (输入不合法);
```

1. 基础：用 `do while` 输出 1 到 5。

## 小结

`do while` 循环的核心特点是先执行一次，再判断是否继续。它特别适合菜单、输入校验和“是否继续”的交互式程序。学习时要重点检查继续条件是否写对、循环变量是否更新，以及末尾分号是否保留。
