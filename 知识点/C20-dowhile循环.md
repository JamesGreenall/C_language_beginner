## 初学者导读

`do while` 循环会先执行一次循环体，再判断是否继续执行。它适合菜单显示、输入校验等至少需要执行一次的场景。

## 关键术语说明

- 先执行后判断：`do while` 的核心特点。
- 菜单循环：显示菜单、读取选择、根据选择处理。
- 输入校验：反复要求用户输入合法数据。
- 结束条件：决定什么时候不再重复。
- 尾部分号：`while (条件);` 后面的分号不能少。

## 核心概念

`do while` 先执行循环体，再判断条件，因此循环体至少执行一次。

## 关键内容

- 适合菜单、输入校验等至少要执行一次的场景。
- 语法末尾需要分号。
- 条件仍然遵循 `0` 假、非 `0` 真。

## 示例

```c
int choice;
do {
    printf("1. Start\n0. Exit\n");
    scanf("%d", &choice);
} while (choice != 0);
```

## 代码逐行解释

- `do { ... }`：先执行一次菜单显示和输入。
- `scanf("%d", &choice);`：读取用户选择。
- `while (choice != 0);`：只要选择不是 0，就继续重复。
- 末尾分号是 `do while` 语法的一部分。

## 常见错误

- 忘记 `while (...)` 后面的分号。
- 条件写反。
- 在不需要至少执行一次的场景滥用。

## 初学者常见误区

- `do while` 末尾分号很容易漏。
- 如果不需要至少执行一次，优先考虑普通 `while`。
- 菜单循环要设计清楚退出选项。

## 语法格式

```c
do {
    循环体;
} while (条件);
```
