# C31. 地址与内存

## 节点定位

- 所属模块：内存与指针
- 学习难度：重点进阶
- 建议学习时间：60-90 分钟
- 典型用途：理解变量如何保存、地址是什么，以及指针为何能够间接访问数据。

## 学习目标

- 理解程序、变量与内存之间的关系。
- 区分变量的值、变量占用的空间和变量的地址。
- 会使用 `sizeof` 查看类型或对象占用的字节数。
- 会使用 `&` 取得变量地址，并使用 `%p` 正确输出地址。
- 理解连续存储、有效地址和内存访问边界等基本概念。

## 一、为什么要学习内存

程序运行时，需要有地方保存正在处理的数据。例如：

```c
int score = 95;
```

这条语句不仅表示“把 95 交给变量 `score`”，还意味着程序为 `score` 准备了一块能够存放 `int` 数据的内存空间，并把 95 保存到其中。

如果把内存看成一排按顺序编号的储物格，那么：

- 变量名 `score` 是程序员使用的名称；
- 数值 `95` 是储物格中保存的内容；
- 地址是这块储物空间在内存中的位置编号；
- 数据类型 `int` 说明这块空间按整数方式解释，并决定它通常需要多少字节。

这种类比只用于帮助理解。真实内存由大量字节组成，地址通常以十六进制形式显示。

## 二、什么是字节

计算机内存通常以字节为基本编址单位。一个字节等于 8 个二进制位，英文写作 byte，位写作 bit。

不同类型通常占用不同数量的字节。例如，在许多常见环境中：

| 类型 | 常见大小 | 主要用途 |
| --- | ---: | --- |
| `char` | 1 字节 | 字符或较小整数 |
| `short` | 2 字节 | 较小范围整数 |
| `int` | 4 字节 | 一般整数 |
| `long long` | 8 字节 | 较大范围整数 |
| `float` | 4 字节 | 单精度浮点数 |
| `double` | 8 字节 | 双精度浮点数 |

这些只是常见结果，不是所有计算机上都必须如此。C 语言标准允许某些类型的大小随编译环境变化，所以程序应使用 `sizeof` 获取实际结果。

## 三、使用 sizeof 查看大小

`sizeof` 用于得到类型或对象占用的字节数，其结果的类型是 `size_t`。

```c
#include <stdio.h>

int main(void) {
    int age = 16;

    printf("int 占 %zu 字节\n", sizeof(int));
    printf("age 占 %zu 字节\n", sizeof age);

    return 0;
}
```

说明：

- `sizeof(int)` 查询 `int` 类型的大小；
- `sizeof age` 查询变量 `age` 所占空间的大小；
- `%zu` 是输出 `size_t` 类型值的标准格式；
- `sizeof` 的结果以字节为单位，而不是以二进制位为单位。

对普通变量来说，`sizeof age` 通常不会读取变量中保存的数值，只根据它的类型确定大小。因此，`age` 保存 1 或 1000，并不会改变它占用的字节数。

## 四、什么是地址

内存中的每个字节都有地址。一个变量可能占用多个连续字节，通常把这块空间起始字节的地址称为该变量的地址。

在 C 语言中，取地址运算符 `&` 可以取得变量的地址：

```c
int number = 25;
&number
```

其中：

- `number` 表示变量中保存的值，即 25；
- `&number` 表示变量所在内存位置的地址；
- 这两个表达式含义不同，类型也不同。

`number` 的类型是 `int`，而 `&number` 的类型是 `int *`，读作“指向 `int` 的指针类型”。指针将在 C32 中详细学习。

## 五、正确输出地址

地址使用 `printf` 的 `%p` 格式输出，并把地址转换为 `void *`：

```c
#include <stdio.h>

int main(void) {
    int number = 25;

    printf("number 的值：%d\n", number);
    printf("number 的地址：%p\n", (void *)&number);

    return 0;
}
```

`void *` 表示一种通用对象地址类型。`%p` 要求对应参数是 `void *`，所以写成 `(void *)&number` 是规范且可移植的做法。

输出可能类似：

```text
number 的值：25
number 的地址：000000A1F5BFF924
```

地址的具体显示形式由运行环境决定。不要记忆某一次运行得到的地址，因为操作系统可能在下一次运行时把程序放到不同位置。

## 六、多个变量在内存中的情况

```c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 20;
    char c = 'A';

    printf("a: 值=%d，大小=%zu，地址=%p\n",
           a, sizeof a, (void *)&a);
    printf("b: 值=%d，大小=%zu，地址=%p\n",
           b, sizeof b, (void *)&b);
    printf("c: 值=%c，大小=%zu，地址=%p\n",
           c, sizeof c, (void *)&c);

    return 0;
}
```

观察结果时应注意：

- 不同变量通常拥有不同地址；
- 不能仅根据源代码中的声明顺序，断定变量地址一定递增或递减；
- 编译器可能为了对齐、优化等原因调整变量的存放方式；
- 两个地址之间的数值差，不能简单理解为两个变量大小之和。

## 七、连续存储的含义

普通局部变量不保证按照声明顺序连续摆放，但同一个数组中的元素是连续存储的：

```c
int data[3] = {10, 20, 30};
```

数组会为 3 个 `int` 元素准备一整块连续空间。若一个 `int` 占 4 字节，那么相邻元素的起始地址通常相差 4 字节。

连续存储使程序能够根据首元素的位置和下标快速找到任意元素。这也是数组和指针关系密切的重要原因。

## 八、内存中的数据必须按类型解释

内存本身保存的是二进制数据。数据类型告诉编译器：

- 应读取多少个字节；
- 应把这些二进制位解释为整数、浮点数还是字符；
- 可以对数据执行哪些运算；
- 通过地址移动时，一次跨过多少字节。

因此，地址本身只说明“在哪里”，类型还要说明“那里保存的是什么，以及应如何读取”。指针类型正是地址信息与类型信息的结合。

## 九、变量的存储期与地址有效期

地址只有在对应对象仍然存在时才有效。以下函数中的局部变量在函数返回后结束生命周期：

```c
int *wrong(void) {
    int value = 10;
    return &value;  // 错误：返回局部变量的地址
}
```

当 `wrong` 执行结束后，`value` 已经不存在。虽然原地址的数值可能暂时没有变化，但程序已经无权继续通过它访问原来的变量。这样的地址称为无效地址，使用它会产生未定义行为。

由此可见，判断一个地址能否使用，不能只看它是否“像一个地址”，还要确认：

1. 地址是否来自一个真实存在的对象；
2. 对象的生命周期是否尚未结束；
3. 访问范围是否没有越界；
4. 使用的类型是否正确。

## 十、常见错误与原因

### 1. 混淆值和地址

```c
int x = 10;
printf("%d\n", x);            // 输出值
printf("%p\n", (void *)&x);   // 输出地址
```

`x` 和 `&x` 不能互相替代。

### 2. 使用错误格式输出地址

```c
printf("%d\n", &x);  // 错误
```

`%d` 用于 `int`，不用于地址。地址应使用 `%p`。

### 3. 认为地址永久不变

变量在一次有效生命周期内地址保持稳定，但重新运行程序后，地址可能不同。不同计算机上的地址更没有可比性。

### 4. 根据地址猜测所有内存布局

编译器和操作系统共同管理内存。初学阶段可以观察地址，但不应根据几次输出结果总结不存在的固定规律。

### 5. 访问不属于程序的地址

程序不能随意构造一个整数并把它当作可访问地址。无效访问可能导致程序崩溃，也可能表现为更难发现的错误。

## 十一、完整观察实验

```c
#include <stdio.h>

int main(void) {
    int value = 100;
    int numbers[3] = {10, 20, 30};

    printf("value = %d\n", value);
    printf("sizeof value = %zu\n", sizeof value);
    printf("&value = %p\n", (void *)&value);

    for (int i = 0; i < 3; i++) {
        printf("numbers[%d] = %d，地址 = %p\n",
               i, numbers[i], (void *)&numbers[i]);
    }

    return 0;
}
```

实验时应关注概念关系，不必关注地址的具体数字：

- 一个变量同时具有值、类型、大小和地址；
- 数组元素的地址按元素顺序连续排列；
- `&numbers[i]` 表示第 `i` 个元素的地址。

## 十二、与后续知识的联系

- C32 指针基础：用专门的变量保存地址，并通过地址访问数据。
- C33 指针与数组：利用数组连续存储的特点访问各个元素。
- C34 指针与函数：把变量地址传入函数，使函数能够访问调用者的数据。
- C35 动态内存：程序在运行时申请一块内存，并用指针保存其起始地址。
- C44 常见未定义行为：越界访问、使用失效地址等都可能导致未定义行为。

## 分层练习

1. 声明 `int`、`double`、`char` 三个变量，分别输出值、大小和地址。
2. 创建一个含 5 个 `int` 元素的数组，输出每个元素的地址，观察相邻地址的变化。
3. 解释为什么 `sizeof(int)` 的结果不应直接写死为 4。
4. 分别说明表达式 `x`、`&x` 和 `sizeof x` 得到的是什么。
5. 思考：一个地址数值非零，是否就一定能够安全访问？说明理由。

## 小结

变量不是只有名称和值，它在程序运行期间还占据一块具有确定大小的内存空间。地址标识这块空间的位置，类型规定程序如何解释其中的数据。理解“值、地址、类型、大小和生命周期”之间的区别，是正确学习指针及动态内存的基础。
