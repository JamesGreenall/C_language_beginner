## 初学者导读

内存用于保存程序运行时的数据，地址用于标识数据在内存中的位置。理解地址与内存，是继续学习指针、数组和动态内存的基础。

## 关键术语说明

- 内存：程序运行时存放数据的地方。
- 地址：内存位置的编号。
- 取地址：用 `&` 得到变量所在位置。
- 字节数：某个变量或类型占用的空间大小。
- 内存布局：不同数据在内存中的摆放方式。

## 核心概念

程序中的变量存储在内存中，每个存储位置都有地址。理解地址是学习指针的前提。

## 关键内容

- `&变量` 获取变量地址。
- 地址通常用指针变量保存。
- 不同类型可能占用不同字节数。
- `sizeof` 可辅助理解内存布局。

## 示例

```c
int x = 10;
printf("%p\n", (void *)&x);
```

## 代码逐行解释

- `int x = 10;`：变量 x 存放整数 10。
- `&x`：取得 x 在内存中的地址。
- `(void *)&x`：按通用地址格式传给 `printf`。
- `%p`：专门用于输出地址。

## 常见错误

- 用错误格式输出地址。
- 认为地址值在每次运行中都固定。
- 不理解变量值和变量地址的区别。

## 初学者常见误区

- 地址每次运行可能不同，不要记具体地址值。
- `%p` 输出地址时建议把地址转成 `(void *)`。
- 变量的值和变量的地址是两件事。

## 语法格式

```c
&变量       // 取地址
sizeof(类型或变量) // 查看字节数
%p          // 地址输出格式，通常配合 (void *)
```
