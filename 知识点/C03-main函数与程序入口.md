## 初学者导读

`main` 函数是 C 程序开始执行的位置。理解程序入口，可以帮助初学者判断代码的执行顺序，并明确哪些语句会在程序运行时真正被执行。

## 关键术语说明

- 入口函数：程序开始执行的位置。
- `int`：表示 `main` 结束后会返回一个整数状态码。
- `void`：表示这个 `main` 不接收参数。
- `return 0`：通常表示程序正常结束。
- 命令行参数：运行程序时从命令行传进来的文字信息。

## 核心概念

`main` 是 C 程序的入口函数。程序运行时从 `main` 开始执行，通常通过 `return 0;` 表示正常结束。

## 关键内容

- 推荐写法：`int main(void)`。
- 返回值类型通常是 `int`。
- `return 0;` 表示程序成功结束。
- 带命令行参数时可写作 `int main(int argc, char *argv[])`。

## 示例

```c
int main(void) {
    return 0;
}
```

## 代码逐行解释

- `int main(void)`：定义程序入口，不接收外部参数。
- `{}`：花括号中的内容是 `main` 的函数体。
- `return 0;`：结束 `main`，并返回正常结束状态。
- 如果写成 `mian`，编译器找不到入口，程序就不能按预期生成。

## 常见错误

- 把 `main` 拼写成 `mian`。
- 省略返回类型。
- 在 `main` 外直接写执行语句。

## 初学者常见误区

- `main` 的拼写必须准确，不能写成 `mian`。
- 不要在函数外面直接写 `printf` 这类执行语句。
- `return 0` 不是计算结果，而是程序结束状态。

## 语法格式

```c
int main(void) {
    return 0;
}

int main(int argc, char *argv[]) {
    return 0;
}
```
