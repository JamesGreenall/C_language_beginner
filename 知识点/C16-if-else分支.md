## 初学者导读

`if/else` 用于根据条件选择不同的执行路径。初学者应重点理解条件表达式、分支顺序和边界值处理。

## 关键术语说明

- 条件：决定走哪条分支的表达式。
- 分支：程序执行路线的不同选择。
- `else if`：继续判断另一个条件。
- 边界值：刚好卡在条件边缘的值，如 60 分。
- 嵌套：一个 `if` 里面再写一个 `if`。

## 核心概念

`if/else` 根据条件选择不同代码路径，是程序决策能力的基础。

## 关键内容

- `if` 处理单条件。
- `else` 处理条件不成立的情况。
- `else if` 处理多分支。
- 条件表达式为 `0` 时是假，非 `0` 时是真。

## 示例

```c
if (score >= 90) {
    printf("A\n");
} else if (score >= 60) {
    printf("Pass\n");
} else {
    printf("Fail\n");
}
```

## 代码逐行解释

- 第一个 `if` 先判断是否达到 90 分。
- 如果不满足，再用 `else if` 判断是否至少 60 分。
- 前两个条件都不满足，才进入 `else`。
- 分支顺序很重要，判断等级时通常从高到低写。

## 常见错误

- 分支顺序错误。
- 忘记处理边界值。
- 悬空 `else` 导致匹配关系误解。

## 初学者常见误区

- 多分支判断要注意顺序，范围判断尤其如此。
- 每个分支最好处理一种清楚情况。
- 边界值如 59、60、90、100 要单独测试。

## 语法格式

```c
if (条件) {
    语句;
} else if (另一个条件) {
    语句;
} else {
    语句;
}
```
