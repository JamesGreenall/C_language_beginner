# C16. if/else 分支

## 节点定位

- 所属模块：控制流程
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：让程序根据条件选择不同的执行路径。

## 学习目标

- 能说明 `if`、`else if`、`else` 的作用。
- 能写出单分支、双分支和多分支结构。
- 能理解分支结构只会执行满足条件的对应代码块。
- 能正确处理边界值，如 59、60、89、90。
- 能说明分支顺序为什么会影响程序结果。
- 能避免悬空 `else`、漏写花括号等常见问题。

## 初学者导读

前面 C15 学习了如何写条件，例如 `score >= 60`。但是只有条件还不够，程序还需要根据条件决定“接下来执行哪一段代码”。

`if/else` 就是用来解决这个问题的。

例如：

- 如果分数大于等于 60，就输出及格。
- 否则，输出不及格。

这就是最典型的分支结构。它使程序不再只能从上到下机械执行，而是能够根据数据做出不同选择。

## 关键术语说明

- 条件：决定是否进入某个分支的表达式。
- 分支：程序可能选择的不同执行路线。
- 单分支：只有 `if`，条件成立才执行。
- 双分支：`if` 和 `else` 配合，二选一执行。
- 多分支：使用 `else if` 处理多个条件。
- 边界值：刚好处于条件边缘的值，例如 60 分、90 分。
- 嵌套：一个 `if` 结构内部再写另一个 `if` 结构。
- 悬空 `else`：没有花括号时，`else` 可能与最近的 `if` 匹配，造成理解错误。

## 学习思路

学习本知识点时，建议按照以下顺序理解：

1. 先理解 `if`：条件成立才执行。
2. 再理解 `if/else`：条件成立执行一段，否则执行另一段。
3. 然后学习 `else if`：按顺序检查多个条件。
4. 最后重点练习边界值和分支顺序。

## 核心概念

`if/else` 根据条件表达式的真假选择执行路径。

```c
if (条件) {
    条件成立时执行的语句;
} else {
    条件不成立时执行的语句;
}
```

在 C 语言中，条件为 `0` 表示假，非 `0` 表示真。实际写程序时，更推荐使用清楚的关系表达式，例如 `score >= 60`，而不是直接写一个数字。

## 单分支：只有 if

单分支用于“满足条件就做某件事，不满足就跳过”。

```c
if (score >= 60) {
    printf("pass\n");
}
```

执行逻辑：

1. 判断 `score >= 60` 是否成立。
2. 如果成立，执行花括号中的语句。
3. 如果不成立，跳过花括号中的语句。

单分支适合只需要处理一种情况的场景。

例如：

```c
if (temperature > 37) {
    printf("fever warning\n");
}
```

如果体温不大于 37，程序就什么也不输出。

## 双分支：if 和 else

双分支用于“二选一”的情况。

```c
if (score >= 60) {
    printf("pass\n");
} else {
    printf("fail\n");
}
```

执行逻辑：

- 如果 `score >= 60` 成立，输出 `pass`。
- 否则，输出 `fail`。

`else` 不需要再写条件，因为它表示“前面的条件不成立时”。

常见场景：

- 及格或不及格。
- 输入合法或非法。
- 年龄达到要求或未达到要求。

## 多分支：else if

当情况超过两种时，可以使用 `else if`。

```c
if (score >= 90) {
    printf("A\n");
} else if (score >= 80) {
    printf("B\n");
} else if (score >= 60) {
    printf("Pass\n");
} else {
    printf("Fail\n");
}
```

执行逻辑是从上到下依次判断：

1. 先判断是否 `score >= 90`。
2. 如果不成立，再判断是否 `score >= 80`。
3. 如果还不成立，再判断是否 `score >= 60`。
4. 前面都不成立，执行 `else`。

一旦某个条件成立并执行了对应分支，后面的 `else if` 和 `else` 就不会再判断。

## 分支顺序很重要

多分支判断中，顺序可能直接改变结果。

错误示例：

```c
if (score >= 60) {
    printf("Pass\n");
} else if (score >= 90) {
    printf("A\n");
}
```

如果 `score` 是 95，程序会先判断 `score >= 60`，这个条件已经成立，于是输出 `Pass`，后面的 `score >= 90` 不会再判断。

正确写法：

```c
if (score >= 90) {
    printf("A\n");
} else if (score >= 60) {
    printf("Pass\n");
} else {
    printf("Fail\n");
}
```

当多个条件有包含关系时，通常应先判断更严格、更具体的条件。

## 边界值处理

边界值是最容易出错的地方。

例如“60 分及格”，就要明确：

- 59 分不及格。
- 60 分及格。
- 61 分及格。

因此条件应写为：

```c
score >= 60
```

如果写成：

```c
score > 60
```

那么 60 分会被错误地判断为不及格。

写分支代码时，建议主动测试边界值。

| 场景 | 应测试的值 |
|---|---|
| 及格线 60 | 59、60、61 |
| A 等级 90 | 89、90、91 |
| 合法范围 0-100 | -1、0、100、101 |

## 花括号的作用

在 C 语言中，花括号用于表示一个代码块。

推荐写法：

```c
if (score >= 60) {
    printf("pass\n");
    printf("keep going\n");
}
```

如果不写花括号，`if` 默认只控制后面一条语句。

容易出错的写法：

```c
if (score >= 60)
    printf("pass\n");
    printf("keep going\n");
```

上面代码中，第二个 `printf` 不受 `if` 控制，不管分数是否及格都会执行。

因此初学阶段建议：即使分支中只有一条语句，也写花括号。

## 悬空 else 问题

当多个 `if` 嵌套而没有花括号时，`else` 会和最近的、尚未匹配的 `if` 结合。

例如：

```c
if (a > 0)
    if (b > 0)
        printf("A\n");
else
    printf("B\n");
```

这段代码容易让人误解。实际中，`else` 会和离它最近的 `if (b > 0)` 匹配。

更清楚的写法是：

```c
if (a > 0) {
    if (b > 0) {
        printf("A\n");
    } else {
        printf("B\n");
    }
}
```

或者根据真实意图调整花括号。花括号能让匹配关系变得明确。

## 嵌套 if

嵌套 `if` 表示在一个条件成立后，再继续判断另一个条件。

```c
if (score >= 0 && score <= 100) {
    if (score >= 60) {
        printf("pass\n");
    } else {
        printf("fail\n");
    }
} else {
    printf("invalid score\n");
}
```

这段程序先判断分数是否合法，再判断是否及格。这样可以避免对非法分数做等级判断。

初学阶段不要过度嵌套。如果嵌套层数太多，说明程序逻辑可能需要重新整理。

## 复杂条件的写法

`if` 中的条件可以是关系表达式，也可以是逻辑表达式。

```c
if (score >= 0 && score <= 100) {
    printf("valid score\n");
}
```

如果条件比较长，建议用括号帮助阅读：

```c
if ((score >= 0 && score <= 100) && (age >= 6)) {
    printf("accepted\n");
}
```

括号不会改变清楚表达的意图，反而能减少误读。

## 示例

```c
#include <stdio.h>

int main(void) {
    int score;

    scanf("%d", &score);

    if (score < 0 || score > 100) {
        printf("invalid score\n");
    } else if (score >= 90) {
        printf("A\n");
    } else if (score >= 60) {
        printf("Pass\n");
    } else {
        printf("Fail\n");
    }

    return 0;
}
```

## 代码逐行解释

- `int score;`：声明变量用于保存分数。
- `scanf("%d", &score);`：从键盘输入分数。
- `score < 0 || score > 100`：判断分数是否不合法。
- `score >= 90`：判断是否达到 A 等级。
- `score >= 60`：判断是否及格。
- `else`：处理剩余情况，也就是合法但不及格。
- 分支按顺序判断，只有一个分支会被执行。

## 常见错误

- 把 `==` 写成 `=`。
- 分支顺序错误，导致更具体的情况没有机会执行。
- 忘记处理边界值，如 60 分、90 分。
- 忘记写 `else` 处理剩余情况。
- 不写花括号，导致语句归属和预期不一致。
- 嵌套 `if` 过多，逻辑变得难以阅读。

## 初学者常见误区

- `else` 表示前面条件不成立，不需要再写条件。
- `else if` 会按顺序判断，不是所有条件都会检查。
- 一组 `if/else if/else` 中，通常只会执行其中一个分支。
- 缩进只是给人看的，真正决定结构的是花括号。
- 判断等级、范围时，要优先考虑边界值。
- 条件越复杂，越需要拆开分析。

## 练习题

1. 写一个程序，输入分数，判断是否及格。
2. 修改程序，使它能判断 A、B、C、Fail 四种结果。
3. 写出 60 分及格时应该测试哪些边界值。
4. 解释为什么等级判断通常从高分到低分写。
5. 说明不写花括号可能带来什么问题。

## 分层练习

1. 基础：输入一个整数，判断它是正数、负数还是 0。
2. 基础：输入年龄，判断是否达到 18 岁。
3. 提升：输入分数，先判断是否合法，再判断等级。
4. 提升：输入两个整数，输出较大的一个。
5. 进阶：输入年份，判断它是否为闰年。
6. 思考：什么时候使用多个独立的 `if`，什么时候使用 `if/else if/else`？

## 小结

`if/else` 是程序获得决策能力的基础。学习本节时，不应只记语法格式，还要理解条件判断的顺序、边界值和代码块范围。掌握这些内容后，程序就能根据不同输入执行不同操作。
