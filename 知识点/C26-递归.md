## 节点定位

## 初学者导读

递归是函数调用自身的一种程序设计方式，适合解决能够分解为同类子问题的问题。学习递归时，应重点关注终止条件和问题规模的缩小。

## 关键术语说明

- 递归调用：函数调用自己。
- 终止条件：递归停止的条件。
- 子问题：比原问题更小、形式相同的问题。
- 调用栈：记录函数一层层调用的信息。
- 栈溢出：递归太深导致内存不够。

## 核心概念

递归是函数直接或间接调用自身。递归适合处理能拆成相同子问题的问题。

## 关键内容

- 必须有递归终止条件。
- 每次递归应让问题规模变小。
- 递归会消耗栈空间。
- 可用循环替代部分递归。

## 示例

```c
int factorial(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * factorial(n - 1);
}
```

## 代码逐行解释

- `if (n <= 1) return 1;`：这是递归停止条件。
- `factorial(n - 1)`：把问题变成更小的阶乘问题。
- `n * factorial(n - 1)`：当前层等待下一层算出结果再相乘。
- 没有终止条件，递归会一直调用下去。

## 常见错误

- 没有终止条件导致无限递归。
- 递归层数过深导致栈溢出。
- 不理解每一层调用都有独立局部变量。

## 初学者常见误区

- 每次递归都必须更接近终止条件。
- 递归不是魔法，只是函数调用叠了很多层。
- 先用小数字手算调用过程，再写代码。

## 语法格式

```c
返回类型 函数名(问题规模) {
    if (终止条件) {
        return 基本结果;
    }
    return 当前步骤 + 函数名(更小的问题规模);
}
```
