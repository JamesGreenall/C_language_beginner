## 初学者导读

关系表达式用于比较数据，逻辑表达式用于组合多个条件。它们是分支和循环判断的基础，也是程序根据不同情况执行不同操作的前提。

## 关键术语说明

- 关系表达式：比较大小或相等关系的表达式。
- 逻辑表达式：用 `&&`、`||`、`!` 组合条件。
- 真：C 中通常用非 0 表示。
- 假：C 中用 0 表示。
- 短路求值：前半部分已经决定结果时，后半部分可能不再计算。

## 核心概念

关系表达式用于比较，逻辑表达式用于组合多个条件。C 中 `0` 表示假，非 `0` 表示真。

## 关键内容

- 关系运算：`>`、`>=`、`<`、`<=`、`==`、`!=`
- 逻辑与：`&&`
- 逻辑或：`||`
- 逻辑非：`!`
- 短路求值：`&&` 和 `||` 可能不会计算右侧表达式。

## 示例

```c
if (score >= 60 && score <= 100) {
    printf("valid score\n");
}
```

## 代码逐行解释

- `score >= 60`：判断是否不低于 60。
- `score <= 100`：判断是否不超过 100。
- `&&` 要求左右两个条件都为真。
- 整个条件常用于判断一个分数是否在合法范围内。

## 常见错误

- 写成 `0 < x < 10`，在 C 中应写成 `x > 0 && x < 10`。
- 把 `==` 写成 `=`。
- 忽略短路求值带来的副作用。

## 初学者常见误区

- C 里不能写 `0 < x < 10`，要写成 `x > 0 && x < 10`。
- `&&` 是并且，`||` 是或者，不要凭中文感觉混用。
- 短路求值会影响带副作用的表达式。

## 语法格式

```c
if (条件1 && 条件2) {
    语句;
}

if (x > 0 || y > 0) {
    语句;
}
```
