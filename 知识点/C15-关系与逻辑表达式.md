# C15. 关系与逻辑表达式

## 节点定位

- 所属模块：控制流程
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：为分支和循环提供“条件判断”。

## 学习目标

- 能说明关系表达式和逻辑表达式分别解决什么问题。
- 能正确使用 `>`、`>=`、`<`、`<=`、`==`、`!=` 比较数据。
- 能理解 C 语言中“真”和“假”的表示方式。
- 能使用 `&&`、`||`、`!` 组合多个条件。
- 能避免 `0 < x < 10`、把 `==` 写成 `=` 等常见错误。
- 能理解短路求值的基本含义。

## 初学者导读

程序经常需要回答“是否满足某个条件”。例如：

- 分数是否及格？
- 年龄是否达到报名要求？
- 输入的数字是否在指定范围内？
- 用户选择的菜单编号是否有效？

这些问题的答案通常只有两种：成立或不成立。在 C 语言中，关系表达式和逻辑表达式就是用来描述这些条件的。

本节先学习“条件怎样写”。下一节 C16 会学习如何把这些条件放进 `if/else` 中，让程序根据条件选择不同的执行路径。

## 关键术语说明

- 关系表达式：用于比较两个数据关系的表达式，例如 `score >= 60`。
- 逻辑表达式：用于组合或改变条件的表达式，例如 `score >= 60 && score <= 100`。
- 真：条件成立。在 C 语言中，非 `0` 通常表示真。
- 假：条件不成立。在 C 语言中，`0` 表示假。
- 关系运算符：用于比较大小或相等关系的运算符。
- 逻辑运算符：用于连接、选择或取反条件的运算符。
- 短路求值：当左侧条件已经能决定结果时，右侧表达式可能不会再计算。

## 学习思路

学习本知识点时，建议按照以下顺序理解：

1. 先理解 C 语言如何表示真和假。
2. 再学习单个条件如何比较，如 `x > 0`。
3. 然后学习多个条件如何组合，如 `x > 0 && x < 10`。
4. 最后关注常见错误和短路求值。

## 核心概念

关系表达式用于比较，逻辑表达式用于组合条件。它们的结果可以作为 `if`、`while`、`for` 等控制结构的判断依据。

例如：

```c
score >= 60
```

这个表达式判断 `score` 是否大于或等于 60。如果成立，结果为真；如果不成立，结果为假。

再例如：

```c
score >= 0 && score <= 100
```

这个表达式判断分数是否在 0 到 100 之间。只有两个条件都成立，整个表达式才成立。

## C 语言中的真和假

C 语言没有把条件结果只限制为“true”或“false”两个单词。在判断条件时，它采用如下规则：

| 数值 | 在条件中表示 |
|---|---|
| `0` | 假 |
| 非 `0` | 真 |

例如：

```c
if (0) {
    printf("A\n");
}

if (5) {
    printf("B\n");
}
```

第一段条件为 `0`，不会执行。第二段条件为 `5`，因为非 `0` 表示真，所以会执行。

关系表达式的结果通常可以理解为：

- 条件成立时，结果为 `1`。
- 条件不成立时，结果为 `0`。

示例：

```c
printf("%d\n", 3 > 2);   // 输出 1
printf("%d\n", 3 < 2);   // 输出 0
```

初学阶段可以把 `1` 理解为真，把 `0` 理解为假。

## 关系表达式

关系表达式用于比较两个值之间的关系。

### 常见关系运算符

| 运算符 | 含义 | 示例 | 说明 |
|---|---|---|---|
| `>` | 大于 | `a > b` | 判断 `a` 是否大于 `b` |
| `>=` | 大于或等于 | `a >= b` | 判断 `a` 是否不小于 `b` |
| `<` | 小于 | `a < b` | 判断 `a` 是否小于 `b` |
| `<=` | 小于或等于 | `a <= b` | 判断 `a` 是否不大于 `b` |
| `==` | 等于 | `a == b` | 判断两个值是否相等 |
| `!=` | 不等于 | `a != b` | 判断两个值是否不相等 |

示例：

```c
int score = 75;

printf("%d\n", score >= 60);  // 1，表示成立
printf("%d\n", score == 100); // 0，表示不成立
printf("%d\n", score != 0);   // 1，表示成立
```

## `=` 和 `==` 的区别

这是初学者最容易混淆的地方。

| 写法 | 含义 | 示例 |
|---|---|---|
| `=` | 赋值，把右边的值存入左边变量 | `x = 10;` |
| `==` | 判断是否相等 | `x == 10` |

例如：

```c
int x = 5;

x = 10;      // 把 10 赋给 x
x == 10;     // 判断 x 是否等于 10
```

在条件判断中，如果把 `==` 误写成 `=`，程序含义会完全改变。

```c
if (x = 0) {
    printf("true\n");
}
```

这不是判断 `x` 是否等于 0，而是把 0 赋给 `x`。赋值表达式的结果为 0，因此条件为假。

正确写法是：

```c
if (x == 0) {
    printf("true\n");
}
```

## 逻辑表达式

一个条件有时不够，需要把多个条件组合起来。例如：

- 分数至少 60，并且不超过 100。
- 用户输入的是 1 或 2。
- 变量不等于 0。

这时需要使用逻辑运算符。

### 常见逻辑运算符

| 运算符 | 名称 | 含义 | 示例 |
|---|---|---|---|
| `&&` | 逻辑与 | 两边都真，结果才真 | `x > 0 && x < 10` |
| `||` | 逻辑或 | 两边至少一个真，结果就真 | `choice == 1 || choice == 2` |
| `!` | 逻辑非 | 把真变假，把假变真 | `!finished` |

## 逻辑与 `&&`

`&&` 表示“并且”。只有左右两个条件都成立，整个表达式才成立。

```c
score >= 0 && score <= 100
```

含义是：`score` 大于或等于 0，并且 `score` 小于或等于 100。

| 左侧条件 | 右侧条件 | 整体结果 |
|---|---|---|
| 假 | 假 | 假 |
| 假 | 真 | 假 |
| 真 | 假 | 假 |
| 真 | 真 | 真 |

常见用途：判断一个数是否在某个范围内。

```c
if (score >= 0 && score <= 100) {
    printf("valid score\n");
}
```

## 逻辑或 `||`

`||` 表示“或者”。只要左右两个条件中有一个成立，整个表达式就成立。

```c
choice == 1 || choice == 2
```

含义是：`choice` 等于 1，或者 `choice` 等于 2。

| 左侧条件 | 右侧条件 | 整体结果 |
|---|---|---|
| 假 | 假 | 假 |
| 假 | 真 | 真 |
| 真 | 假 | 真 |
| 真 | 真 | 真 |

常见用途：判断一个输入是否属于几个可接受值之一。

```c
if (choice == 1 || choice == 2) {
    printf("valid choice\n");
}
```

## 逻辑非 `!`

`!` 表示“不是”或“取反”。它会把真变成假，把假变成真。

```c
int finished = 0;

if (!finished) {
    printf("not finished\n");
}
```

因为 `finished` 的值为 0，表示假，所以 `!finished` 为真。

常见写法：

```c
if (x != 0) {
    printf("x is not zero\n");
}

if (!(x == 0)) {
    printf("x is not zero\n");
}
```

这两段含义相同，但第一种写法更直接。

## 范围判断的正确写法

数学中可以写：

```text
0 < x < 10
```

但在 C 语言中不能这样写来表示范围。

错误写法：

```c
if (0 < x < 10) {
    printf("in range\n");
}
```

C 会先计算 `0 < x`，结果是 0 或 1，然后再拿这个结果去和 10 比较。这样表达式的含义已经改变，不能表示“x 在 0 到 10 之间”。

正确写法：

```c
if (x > 0 && x < 10) {
    printf("in range\n");
}
```

判断“x 不在 0 到 10 之间”可以写成：

```c
if (x <= 0 || x >= 10) {
    printf("out of range\n");
}
```

## 短路求值

`&&` 和 `||` 有一个重要特点：当左侧条件已经能决定结果时，右侧表达式可能不会再计算。

### `&&` 的短路

对于 `&&`，只要左侧为假，整体一定为假，因此右侧不再计算。

```c
if (x != 0 && 10 / x > 1) {
    printf("ok\n");
}
```

如果 `x` 等于 0，左侧 `x != 0` 为假，右侧 `10 / x > 1` 不会执行，从而避免除以 0。

### `||` 的短路

对于 `||`，只要左侧为真，整体一定为真，因此右侧不再计算。

```c
if (age < 6 || age > 60) {
    printf("special ticket\n");
}
```

如果 `age < 6` 已经成立，就不需要再判断 `age > 60`。

初学阶段应注意：不要在右侧表达式中放入必须执行的操作。因为短路求值可能导致它不执行。

## 运算优先级与括号

关系运算符和逻辑运算符也有优先级。初学阶段不必死记所有规则，但应掌握一个原则：复杂条件优先使用括号表达清楚。

例如：

```c
if ((score >= 60 && score <= 100) || bonus > 0) {
    printf("accepted\n");
}
```

括号可以让读者明确看出：

- 先判断分数是否在 60 到 100 之间。
- 或者判断是否有额外加分。

常见优先级大致如下：

| 优先级 | 运算符 |
|---|---|
| 高 | `!` |
| 中 | `>`、`>=`、`<`、`<=`、`==`、`!=` |
| 低 | `&&` |
| 更低 | `||` |

为了降低错误率，建议把多个条件用括号分组。

## 示例

```c
#include <stdio.h>

int main(void) {
    int score = 75;

    if (score >= 0 && score <= 100) {
        printf("valid score\n");
    }

    if (score >= 60) {
        printf("pass\n");
    }

    return 0;
}
```

## 代码逐行解释

- `int score = 75;`：声明分数变量，并设置初始值。
- `score >= 0`：判断分数是否不小于 0。
- `score <= 100`：判断分数是否不大于 100。
- `&&`：要求左右两个条件都成立。
- `score >= 60`：判断是否达到及格线。
- 两个 `if` 分别根据条件决定是否执行输出语句。

## 常见错误

- 把判断相等的 `==` 写成赋值的 `=`。
- 写成 `0 < x < 10`，误以为能判断范围。
- 把 `&&` 和 `||` 混用。
- 忽略 `&&`、`||` 的短路求值。
- 对复杂条件不加括号，导致含义不清。
- 用浮点数直接比较是否完全相等，可能受到精度影响。

## 初学者常见误区

- C 语言中 `0` 表示假，非 `0` 表示真。
- `x = 5` 是赋值，不是判断。
- 判断范围时要拆成两个条件，再用 `&&` 连接。
- `&&` 要求条件都成立，`||` 只要求至少一个成立。
- `!` 只改变条件真假，不会改变变量本身的值。
- 条件越复杂，越应该用括号帮助表达。

## 语法格式

```c
表达式1 > 表达式2
表达式1 >= 表达式2
表达式1 < 表达式2
表达式1 <= 表达式2
表达式1 == 表达式2
表达式1 != 表达式2

条件1 && 条件2
条件1 || 条件2
!条件
```

## 小结

关系表达式用于比较数据，逻辑表达式用于组合条件。掌握本节后，学生就能写出“是否满足某条件”的表达式。后续学习 `if/else`、`while` 和 `for` 时，这些表达式将直接决定程序执行哪条路径、是否继续循环。
