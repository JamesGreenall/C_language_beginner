## 初学者导读

二维数组用于表示具有行和列的数据结构，例如表格、矩阵或棋盘。理解二维数组有助于处理更接近表格形式的问题。

## 关键术语说明

- 行：二维数组第一维。
- 列：二维数组第二维。
- 嵌套循环：循环里面再写循环。
- 矩阵：数学中的二维数字表。
- 列数固定：函数接收二维数组时通常必须知道列数。

## 核心概念

二维数组可以理解为“数组的数组”，常用于表格、矩阵、棋盘等结构。

## 关键内容

- 声明形式：`type name[row][col]`
- 访问形式：`name[i][j]`
- 内存中仍然是连续存储。
- 遍历时通常使用嵌套循环。

## 示例

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}
```

## 代码逐行解释

- `int matrix[2][3]`：创建 2 行 3 列的整数表。
- 外层循环 `i` 控制行。
- 内层循环 `j` 控制列。
- `matrix[i][j]` 访问第 i 行第 j 列元素。

## 常见错误

- 行列下标写反。
- 初始化列表维度不清。
- 函数参数中省略二维数组的列数。

## 初学者常见误区

- 行和列不要写反，可以先画表格再写代码。
- 二维数组传给函数时，列数通常不能省略。
- 嵌套循环中外层和内层变量要分清。

## 语法格式

```c
类型名 数组名[行数][列数];
数组名[行下标][列下标]
```
