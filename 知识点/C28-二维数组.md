# C28. 二维数组

## 节点定位

- 所属模块：数组与字符串
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：保存和处理具有行、列结构的数据。

## 学习目标

- 能说明二维数组适合解决什么问题。
- 能声明、初始化和访问二维数组元素。
- 能理解行下标和列下标都从 0 开始。
- 能使用嵌套循环遍历二维数组。
- 能完成按行求和、按列求和等基础操作。
- 能避免行列写反、下标越界等常见错误。

## 初学者导读

一维数组适合保存一排数据，例如 5 个分数。

如果数据具有“行”和“列”的结构，就更适合用二维数组。例如：

- 一个班级多名学生、多门科目的成绩表。
- 数学中的矩阵。
- 棋盘。
- 地图中的网格。

二维数组可以先理解为表格：

```text
第 0 行: 1 2 3
第 1 行: 4 5 6
```

在 C 语言中可以写成：

```c
int matrix[2][3];
```

表示 2 行 3 列，一共 6 个整数元素。

## 关键术语说明

- 二维数组：具有两个下标的数组。
- 行：二维数组的第一维。
- 列：二维数组的第二维。
- 行下标：访问第几行的编号。
- 列下标：访问第几列的编号。
- 嵌套循环：循环内部再写一个循环。
- 矩阵：数学中的二维数字表。
- 行优先存储：C 语言中二维数组在内存中按行连续存放。

## 学习思路

学习二维数组时，建议按照以下顺序：

1. 先把二维数组看作表格。
2. 再理解 `[行下标][列下标]` 的访问方式。
3. 然后使用外层循环控制行、内层循环控制列。
4. 最后学习按行、按列处理数据。

二维数组的难点不是语法本身，而是行、列、循环变量之间的对应关系。

## 核心概念

二维数组声明格式：

```c
类型名 数组名[行数][列数];
```

访问格式：

```c
数组名[行下标][列下标]
```

例如：

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

对应表格：

| 位置 | 第 0 列 | 第 1 列 | 第 2 列 |
|---|---|---|---|
| 第 0 行 | `matrix[0][0] = 1` | `matrix[0][1] = 2` | `matrix[0][2] = 3` |
| 第 1 行 | `matrix[1][0] = 4` | `matrix[1][1] = 5` | `matrix[1][2] = 6` |

## 声明二维数组

示例：

```c
int matrix[2][3];
double scores[4][5];
char board[3][3];
```

含义：

- `int matrix[2][3];`：2 行 3 列，共 6 个整数。
- `double scores[4][5];`：4 行 5 列，共 20 个小数。
- `char board[3][3];`：3 行 3 列，共 9 个字符。

元素总数等于：

```text
行数 * 列数
```

## 初始化二维数组

常见初始化写法：

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

每一对内层花括号表示一行。

也可以写成一行：

```c
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
```

为了可读性，初学阶段建议按行换行书写。

如果初值不足，未给出的元素会被初始化为 0。

```c
int a[2][3] = {
    {1, 2},
    {4}
};
```

对应：

```text
1 2 0
4 0 0
```

## 访问二维数组元素

使用两个下标访问元素：

```c
matrix[0][0]
matrix[0][1]
matrix[1][2]
```

示例：

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

printf("%d\n", matrix[1][2]);
```

输出：

```text
6
```

因为 `matrix[1][2]` 表示第 1 行第 2 列，也就是第二行第三列。

## 行列下标从 0 开始

对于：

```c
int matrix[2][3];
```

合法行下标：

```text
0, 1
```

合法列下标：

```text
0, 1, 2
```

因此合法元素包括：

```text
matrix[0][0], matrix[0][1], matrix[0][2]
matrix[1][0], matrix[1][1], matrix[1][2]
```

不合法：

```c
matrix[2][0]; // 行越界
matrix[0][3]; // 列越界
```

## 使用嵌套循环遍历

二维数组通常使用嵌套循环遍历。

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%d ", matrix[i][j]);
    }
    printf("\n");
}
```

输出：

```text
1 2 3
4 5 6
```

这里：

- 外层循环变量 `i` 控制行。
- 内层循环变量 `j` 控制列。
- `matrix[i][j]` 访问第 `i` 行第 `j` 列。

## 为什么需要嵌套循环

一维数组只有一个方向，用一个循环即可。

二维数组有行和列两个方向：

- 要遍历所有行，需要一个循环。
- 每一行中又有多列，需要另一个循环。

因此通常写成：

```c
for (int i = 0; i < 行数; i++) {
    for (int j = 0; j < 列数; j++) {
        使用 数组名[i][j];
    }
}
```

外层每执行一轮，内层会完整执行一遍。

## 输入二维数组

```c
int matrix[2][3];

for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++) {
        scanf("%d", &matrix[i][j]);
    }
}
```

这里 `matrix[i][j]` 是一个 `int` 元素，因此 `scanf` 需要写：

```c
&matrix[i][j]
```

## 按行求和

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int i = 0; i < 2; i++) {
    int row_sum = 0;

    for (int j = 0; j < 3; j++) {
        row_sum = row_sum + matrix[i][j];
    }

    printf("row %d sum = %d\n", i, row_sum);
}
```

输出：

```text
row 0 sum = 6
row 1 sum = 15
```

`row_sum` 放在外层循环内部，是因为每一行都要重新统计一次。

## 按列求和

按列求和时，外层可以控制列，内层控制行。

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int j = 0; j < 3; j++) {
    int col_sum = 0;

    for (int i = 0; i < 2; i++) {
        col_sum = col_sum + matrix[i][j];
    }

    printf("col %d sum = %d\n", j, col_sum);
}
```

输出：

```text
col 0 sum = 5
col 1 sum = 7
col 2 sum = 9
```

按行处理还是按列处理，取决于外层循环控制什么。

## 二维数组的内存存放

虽然二维数组看起来像表格，但在内存中仍然是连续存放的。

对于：

```c
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

C 语言通常按行存放：

```text
1 2 3 4 5 6
```

也就是说，先存第 0 行，再存第 1 行。这叫行优先存储。

初学阶段不需要深入指针计算，但知道这一点有助于后续理解二维数组和函数参数。

## 二维数组作为函数参数的预告

函数接收二维数组时，通常必须知道列数。

```c
void print_matrix(int matrix[][3], int rows) {
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < 3; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }
}
```

这里 `matrix[][3]` 中的列数 `3` 不能随意省略。原因与二维数组的内存布局有关，后续在指针与数组中会更深入理解。

当前阶段先记住：二维数组传给函数时，列数通常要写清楚。

## 示例

```c
#include <stdio.h>

int main(void) {
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for (int i = 0; i < 2; i++) {
        int row_sum = 0;

        for (int j = 0; j < 3; j++) {
            row_sum = row_sum + matrix[i][j];
        }

        printf("%d\n", row_sum);
    }

    return 0;
}
```

## 代码逐行解释

- `int matrix[2][3]`：声明 2 行 3 列的整数数组。
- 外层循环 `i`：依次处理每一行。
- `int row_sum = 0;`：每一行开始时，总和清零。
- 内层循环 `j`：依次访问当前行的每一列。
- `matrix[i][j]`：访问第 `i` 行第 `j` 列元素。
- `printf("%d\n", row_sum);`：输出当前行的总和。

## 常见错误

- 把行下标和列下标写反。
- 行或列越界。
- 外层循环和内层循环的范围写错。
- 初始化时没有按行理解数据。
- 按行求和时没有在每一行开始前清零。
- 函数参数中省略二维数组的列数。

## 初学者常见误区

- `matrix[2][3]` 表示 2 行 3 列，不是下标能取到 2 和 3。
- 合法行下标是 0 到行数减 1。
- 合法列下标是 0 到列数减 1。
- 外层循环不一定必须是行，但初学阶段建议外层行、内层列。
- 二维数组看起来像表格，内存中仍然连续存储。
- 行列不清楚时，先画表格再写代码。

## 语法格式

```c
类型名 数组名[行数][列数];

类型名 数组名[行数][列数] = {
    {第0行初值},
    {第1行初值}
};

数组名[行下标][列下标]

for (int i = 0; i < 行数; i++) {
    for (int j = 0; j < 列数; j++) {
        使用 数组名[i][j];
    }
}
```

二维数组适合表示表格、矩阵、棋盘等具有行列结构的数据。学习时要重点区分行下标和列下标，并熟练使用嵌套循环遍历。掌握二维数组后，处理表格型数据会更加自然。
