# C10. 作用域与生命周期

## 节点定位

- 能说清楚“作用域与生命周期”解决的具体问题。
- 能在一段 C 代码中识别与“作用域与生命周期”有关的语法现象。
- 能独立写出一个包含该知识点的最小示例程序。
- 能说明它与前置知识点、后续知识点之间的关系。

## 初学者导读

作用域描述一个名字可以在哪些位置被使用，生命周期描述一个变量在内存中存在多长时间。初学者经常遇到“这个变量为什么找不到”“为什么函数调用结束后值不见了”“为什么 `static` 变量会记住上一次的值”等问题，这些都与作用域和生命周期有关。

## 关键术语说明

- 作用域：一个名字能被使用的范围。
- 生命周期：一个变量在内存中存在的时间。
- 局部变量：定义在函数或代码块内部的变量。
- 全局变量：定义在函数外部的变量。
- `static`：让局部变量在多次函数调用之间保留值。
- 代码块：用 `{}` 包围的一段代码。
- 文件作用域：从某个名字声明的位置开始，到当前源文件末尾为止的可见范围。

## 核心概念

作用域决定名字在哪里可见，生命周期决定变量在内存中存在多久。

可以用两个问题区分它们：

1. “这段代码能不能使用这个名字？”这是作用域问题。
2. “这个变量此时还存在吗？”这是生命周期问题。

一个变量可能“还存在”，但在某个位置无法通过名字访问；也可能名字已经离开作用域，对应的局部变量也已经结束生命周期。

## 关键内容

- 局部变量只在所在代码块中可见。
- 全局变量在文件范围内可见。
- 函数参数属于函数局部作用域。
- `static` 局部变量生命周期贯穿整个程序运行期。

## 作用域：名字在哪里能被使用

### 1. 块作用域

块作用域是由 `{}` 形成的作用范围。在代码块中声明的变量，通常只能在这个代码块内部使用。

```c
int main(void) {
    {
        int x = 10;
        printf("%d\n", x);
    }

    // printf("%d\n", x); // 错误：x 已经离开作用域
    return 0;
}
```

在这个例子中，`x` 只在内层 `{}` 中可见。离开这对花括号后，不能再通过名字 `x` 使用它。

### 2. 函数作用域与函数参数

函数参数的作用域通常只在该函数内部。

```c
void print_score(int score) {
    printf("%d\n", score);
}

int main(void) {
    print_score(90);
    // printf("%d\n", score); // 错误：score 只在 print_score 内部可见
    return 0;
}
```

这里的 `score` 是 `print_score` 的参数，只能在 `print_score` 函数内部使用。

### 3. 文件作用域

在所有函数外部声明的变量具有文件作用域，通常从声明位置开始，到当前源文件末尾都可以使用。

```c
int global_count = 0;

void increase(void) {
    global_count++;
}

int main(void) {
    increase();
    printf("%d\n", global_count);
    return 0;
}
```

`global_count` 定义在函数外部，因此 `increase` 和 `main` 都可以访问它。

需要注意：全局变量虽然方便，但使用过多会让程序状态分散，增加调试难度。

### 4. 内层变量会遮蔽外层同名变量

如果内层作用域中声明了与外层同名的变量，内层名字会暂时遮蔽外层名字。

```c
int x = 100;

int main(void) {
    int x = 10;
    printf("%d\n", x); // 输出 10，而不是 100
    return 0;
}
```

这种写法虽然合法，但容易造成阅读混乱。初学阶段应尽量避免在内外层使用相同变量名。

## 生命周期：变量在内存中存在多久

### 1. 普通局部变量的生命周期

普通局部变量通常在进入所在代码块时创建，在离开代码块时结束。

```c
void test(void) {
    int count = 0;
    count++;
    printf("%d\n", count);
}
```

每次调用 `test` 时，`count` 都会重新创建并初始化为 `0`。因此多次调用时，通常每次输出都是 `1`。

### 2. 全局变量的生命周期

全局变量在程序开始运行前就已经准备好，通常直到程序结束才释放。

```c
int total = 0;

void add_one(void) {
    total++;
}
```

`total` 的生命周期贯穿整个程序运行过程，因此每次调用 `add_one` 都是在修改同一个 `total`。

### 3. static 局部变量的生命周期

`static` 局部变量的作用域仍然在函数内部，但生命周期贯穿整个程序运行期。

```c
void count_call(void) {
    static int times = 0;
    times++;
    printf("%d\n", times);
}
```

如果连续调用：

```c
count_call(); // 输出 1
count_call(); // 输出 2
count_call(); // 输出 3
```

原因是 `times` 只在第一次执行到声明时初始化一次，之后会保留上一次调用后的值。

### 4. 作用域与生命周期对比

| 变量类型 | 作用域 | 生命周期 | 是否保留上次值 |
|---|---|---|---|
| 普通局部变量 | 所在函数或代码块内部 | 进入代码块到离开代码块 | 通常不保留 |
| 函数参数 | 所在函数内部 | 函数调用期间 | 不保留 |
| 全局变量 | 从声明处到文件末尾，其他文件另需声明 | 程序整个运行期 | 保留 |
| `static` 局部变量 | 所在函数或代码块内部 | 程序整个运行期 | 保留 |

## 作用域与生命周期的判断方法

阅读代码时，可以按下面的顺序判断：

1. 先看变量声明在哪里。
2. 再看当前位置是否在它的作用域内。
3. 如果能访问，再判断它是普通局部变量、全局变量还是 `static` 局部变量。
4. 最后判断它的值是否会在多次调用之间保留。

## 示例

```c
int global_count = 0;

void increase(void) {
    int local = 1;
    static int times = 0;
    global_count++;
    local++;
    times++;
}
```

## 代码逐行解释

- `global_count` 定义在函数外，是全局变量。
- `local` 定义在函数内，只能在函数内部使用。
- `static int times` 第一次执行时初始化，以后调用会保留上次的值。
- `global_count++` 修改的是全局变量，多次调用会持续累加。
- `local++` 修改的是普通局部变量，下一次调用 `increase` 时又会重新从 `1` 开始。
- 变量写在哪里，直接影响它能在哪里被访问。

## 常见错误

- 在作用域外访问局部变量。
- 过度使用全局变量。
- 误以为普通局部变量会保留上次调用的值。
- 在内层作用域声明与外层同名的变量，导致实际访问的不是自己以为的变量。
- 返回局部变量的地址，导致函数结束后访问已经失效的内存位置。

## 初学者常见误区

- 代码块 `{}` 会影响局部变量的可见范围。
- 全局变量方便但容易让程序难以追踪。
- `static` 局部变量不是每次调用都重新初始化。
- `static` 局部变量的作用域没有变大，它仍然只能在声明它的代码块或函数内通过名字访问。
- 生命周期长不等于任何位置都能访问；能否访问仍然取决于作用域。
- 普通局部变量每次函数调用都会重新创建，不能依赖它自动记住上次的值。

## 语法格式

```c
{
    int local = 0;      // 块作用域
}

static int counter = 0; // 静态生命周期

int global_value = 0;   // 文件作用域，程序运行期生命周期
```
