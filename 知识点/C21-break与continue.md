## 初学者导读

`break` 和 `continue` 用于改变循环或 `switch` 的执行过程。它们能提高流程控制的灵活性，但应在逻辑清晰的前提下使用。

## 关键术语说明

- `break`：立刻结束当前循环或 `switch`。
- `continue`：跳过本轮循环剩下部分。
- 当前层：离它最近的那一层循环或 `switch`。
- 流程控制：改变程序执行顺序的手段。
- 可读性：别人能否顺着代码理解执行过程。

## 核心概念

`break` 终止当前循环或 `switch`，`continue` 跳过本轮循环剩余语句并进入下一轮。

## 关键内容

- `break` 可用于 `for`、`while`、`do while`、`switch`。
- `continue` 只用于循环。
- 多层循环中，`break` 只跳出最近的一层。

## 示例

```c
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;
    }
    if (i % 2 == 0) {
        continue;
    }
    printf("%d\n", i);
}
```

## 代码逐行解释

- `if (i == 5) break;`：当 i 等于 5 时直接结束循环。
- `if (i % 2 == 0) continue;`：遇到偶数跳过后面的输出。
- `printf` 只会输出没有被跳过的奇数。
- `break` 和 `continue` 都只影响最近的一层循环。

## 常见错误

- 以为 `break` 可以跳出所有嵌套循环。
- `continue` 后忘记更新状态，造成死循环。
- 过度使用导致流程难读。

## 初学者常见误区

- `break` 不会跳出所有嵌套循环，只跳出最近一层。
- `continue` 后面的更新语句如果被跳过，可能造成死循环。
- 过度使用会降低程序流程的可读性。

## 语法格式

```c
break;    // 结束当前循环或 switch
continue; // 跳过本轮循环剩余语句
```
