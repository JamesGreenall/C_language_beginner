# C02. 源文件、头文件与程序结构

## 节点定位

- 所属模块：程序结构与开发基础
- 学习难度：入门
- 建议学习时间：20-30 分钟
- 典型用途：在 C 程序中正确理解和使用“源文件、头文件与程序结构”。

## 学习目标

- 能说清楚“源文件、头文件与程序结构”解决的具体问题。
- 能在一段 C 代码中识别与“源文件、头文件与程序结构”有关的语法现象。
- 能独立写出一个包含该知识点的最小示例程序。
- 能说明它与前置知识点、后续知识点之间的关系。

## 初学者导读

C 程序通常保存在源文件中，并按照一定顺序组织代码。对于初学者来说，本节只需要先认识一个最小 C 程序的基本外观：引入需要的标准库、写出程序入口、在入口中放置要执行的语句。

## 关键术语说明

- 源文件：通常是 `.c` 文件，放具体代码实现。
- 头文件：通常是 `.h` 文件，用来提供其他代码需要提前知道的信息。初学阶段先记住标准库头文件的用法即可。
- `#include`：用于引入头文件，例如引入 `<stdio.h>` 后才能使用 `printf`。
- 程序入口：程序开始执行的位置，本阶段只需要知道入口通常写作 `main`。
- 程序结构：代码各部分的组织方式，不只是语法顺序。

## 学习思路

学习本知识点时，建议按照以下顺序理解：

1. 明确它要解决的具体问题。
2. 观察它在代码中的基本形式。
3. 分析它会如何影响程序的输入、输出、内存或执行顺序。
4. 理解它与前置知识点和后续知识点的联系。

## 核心概念

C 程序可以先从一个 `.c` 源文件开始学习。一个最小的 C 程序通常包括头文件引入、`main` 程序入口和若干条执行语句。随着程序变大，才需要进一步学习自定义函数、头文件组织和多文件拆分。

## 关键内容

- `.c` 文件是初学阶段最常接触的源文件。
- `.h` 文件属于头文件，后续学习多文件程序时会进一步使用。
- `#include` 用于引入头文件。
- 程序通常从 `main` 开始执行。

## 示例

```c
#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}
```

## 代码逐行解释

- `#include <stdio.h>`：引入标准输入输出相关声明，使程序可以使用 `printf`。
- `int main(void)`：写出程序入口，程序运行时会从这里开始执行。
- `{ ... }`：花括号中的内容表示程序入口中的代码块。
- `printf("Hello, C!\n");`：向屏幕输出一行文字。
- `return 0;`：表示程序正常结束。

## 常见错误

- 把头文件引入语句写错，例如漏写 `#` 或头文件名。
- 在 `main` 外面直接写执行语句。
- 忘记包含标准库头文件。

## 初学者常见误区

- `.h` 不是必须一开始就用，单文件程序也能学习 C。
- 本节提到头文件，是为了理解 `#include <stdio.h>`，不要求立即掌握自定义头文件。
- 本节提到 `main`，只需要先知道它是程序入口；更细的函数知识会在后续节点学习。
