# C18. while 循环

## 节点定位

- 所属模块：控制流程
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：在条件成立时重复执行一段代码。

## 学习目标

- 能说明 `while` 循环解决什么问题。
- 能写出包含初始值、循环条件、循环体、状态更新的 `while` 循环。
- 能理解 `while` 是“先判断，后执行”。
- 能分析循环执行了多少轮。
- 能识别死循环、边界错误和少循环/多循环一次的问题。
- 能判断什么场景适合使用 `while`。

## 初学者导读

程序中经常需要重复做一件事。例如：

- 从 1 数到 10。
- 不断输入数字，直到输入 0。
- 反复要求用户输入合法分数。
- 在条件满足时持续执行某段逻辑。

如果不用循环，就需要重复写很多相似代码。`while` 循环可以让程序在条件成立时反复执行同一段代码。

`while` 的重点不是“重复”两个字，而是“条件控制重复”。只要条件仍然成立，循环就继续；条件不成立，循环就结束。

## 关键术语说明

- 循环：重复执行某段代码的结构。
- 循环条件：决定是否继续执行循环的表达式。
- 循环体：每一轮循环中会被执行的代码。
- 迭代：循环执行的一轮。
- 初始值：循环开始前设置的变量状态。
- 状态更新：循环体中改变变量，使条件有机会变为假的语句。
- 死循环：条件一直为真，循环无法正常结束。
- 边界值：循环开始或结束附近的关键值，例如 0、1、n、n-1。

## 学习思路

学习 `while` 循环时，可以抓住四个问题：

1. 循环开始前，相关变量的初始值是什么？
2. 每一轮开始时，用什么条件判断是否继续？
3. 每一轮循环体具体做什么？
4. 循环体中有没有改变条件相关变量？

只要这四个问题回答清楚，大多数 `while` 循环都能分析明白。

## 核心概念

`while` 的基本含义是：当条件成立时，重复执行循环体。

```c
while (条件) {
    循环体;
}
```

执行过程是：

1. 先判断条件。
2. 如果条件为真，执行循环体。
3. 循环体执行完后，回到条件处再次判断。
4. 如果条件为假，循环结束，继续执行后面的语句。

因为 `while` 是先判断再执行，所以如果一开始条件就是假的，循环体一次也不会执行。

## 最小示例

```c
int n = 1;

while (n <= 5) {
    printf("%d\n", n);
    n++;
}
```

输出结果：

```text
1
2
3
4
5
```

这段代码中：

- `int n = 1;` 是初始值。
- `n <= 5` 是循环条件。
- `printf("%d\n", n);` 是循环体中的主要操作。
- `n++;` 是状态更新。

## while 的执行过程

以上面的代码为例：

| 轮次 | 判断条件 `n <= 5` | 输出 | 更新后 `n` |
|---|---|---|---|
| 第 1 轮 | `1 <= 5`，真 | 1 | 2 |
| 第 2 轮 | `2 <= 5`，真 | 2 | 3 |
| 第 3 轮 | `3 <= 5`，真 | 3 | 4 |
| 第 4 轮 | `4 <= 5`，真 | 4 | 5 |
| 第 5 轮 | `5 <= 5`，真 | 5 | 6 |
| 结束判断 | `6 <= 5`，假 | 不输出 | 循环结束 |

分析循环时，不要只看循环体，要把“判断条件”和“状态更新”一起看。

## 循环的四个组成部分

一个清晰的 `while` 循环通常包含四个部分。

### 1. 初始值

初始值在循环之前设置。

```c
int i = 1;
```

如果初始值不合理，循环可能一次都不执行，或者执行次数不符合预期。

### 2. 循环条件

循环条件写在 `while (...)` 中。

```c
while (i <= 10)
```

条件为真时继续循环，条件为假时结束循环。

### 3. 循环体

循环体写在花括号中。

```c
{
    printf("%d\n", i);
    i++;
}
```

循环体中通常包含要重复做的事情。

### 4. 状态更新

状态更新让循环条件逐渐变化。

```c
i++;
```

如果没有状态更新，条件可能永远为真，形成死循环。

## 死循环

死循环是指循环条件一直为真，程序无法正常结束循环。

错误示例：

```c
int i = 1;

while (i <= 5) {
    printf("%d\n", i);
}
```

这段代码中，`i` 一直是 1，条件 `i <= 5` 永远成立，程序会不断输出 1。

修正方式：

```c
int i = 1;

while (i <= 5) {
    printf("%d\n", i);
    i++;
}
```

状态更新不一定总是 `i++`，也可以是读取新输入、改变标志变量、累计某个值等。关键是：循环条件必须有机会变为假。

## 少循环或多循环一次

循环边界是初学者常出错的地方。

例如要输出 1 到 5：

正确写法：

```c
int i = 1;
while (i <= 5) {
    printf("%d\n", i);
    i++;
}
```

如果写成：

```c
int i = 1;
while (i < 5) {
    printf("%d\n", i);
    i++;
}
```

就只会输出 1 到 4，少输出了 5。

如果写成：

```c
int i = 1;
while (i <= 6) {
    printf("%d\n", i);
    i++;
}
```

就会输出到 6，多循环一次。

判断边界时，可以把开始值、结束值和最后一次条件单独列出来。

## 输入控制循环

`while` 特别适合循环次数不固定的情况。例如，不断输入数字，直到输入 0 才结束。

```c
int number;

scanf("%d", &number);

while (number != 0) {
    printf("input = %d\n", number);
    scanf("%d", &number);
}
```

这段代码的循环次数取决于用户什么时候输入 0。程序无法提前知道要循环几次。

注意这里有两次 `scanf`：

- 循环前先读入第一个数字，用于第一次判断。
- 循环体末尾再读入下一个数字，为下一轮判断做准备。

这种写法常用于“读到某个结束标记为止”的问题。

## 输入校验循环

`while` 还常用于要求用户输入合法数据。

```c
int score;

scanf("%d", &score);

while (score < 0 || score > 100) {
    printf("invalid score, input again:\n");
    scanf("%d", &score);
}

printf("score = %d\n", score);
```

只要分数不在 0 到 100 之间，就要求重新输入。输入合法后，循环结束。

## while 与 if 的区别

`if` 和 `while` 都有条件，但作用不同。

| 结构 | 条件成立时 |
|---|---|
| `if` | 执行一次 |
| `while` | 反复执行，直到条件不成立 |

示例：

```c
if (i <= 5) {
    printf("%d\n", i);
}
```

这最多输出一次。

```c
while (i <= 5) {
    printf("%d\n", i);
    i++;
}
```

这会重复输出，直到 `i <= 5` 不再成立。

## 示例

```c
#include <stdio.h>

int main(void) {
    int n = 1;
    int sum = 0;

    while (n <= 100) {
        sum = sum + n;
        n++;
    }

    printf("%d\n", sum);
    return 0;
}
```

## 代码逐行解释

- `int n = 1;`：从 1 开始累加。
- `int sum = 0;`：准备变量保存总和。
- `while (n <= 100)`：只要 `n` 不超过 100，就继续循环。
- `sum = sum + n;`：把当前 `n` 加到总和中。
- `n++;`：让 `n` 增加 1，为下一轮判断做准备。
- 循环结束后，`sum` 保存 1 到 100 的和。

## 常见错误

- 忘记更新循环变量，导致死循环。
- 把 `<=` 和 `<` 混用，导致少循环或多循环一次。
- 循环条件写反，导致循环一次也不执行。
- 状态更新的位置不合理，影响循环结果。
- 在循环体中修改太多变量，使循环难以分析。
- 没有考虑输入失败或非法输入。

## 初学者常见误区

- `while` 不是“执行一次判断一次”，而是“先判断，再决定是否执行”。
- 循环条件为假时，循环体一次也不会执行。
- 循环体中必须有机会改变循环条件。
- 调试循环时，可以输出循环变量观察每一轮变化。
- 当循环次数固定时，`for` 可能更清晰；当次数不固定时，`while` 往往更自然。

## 语法格式

```c
初始值;

while (条件) {
    循环体;
    状态更新;
}
```

## 练习题

1. 用 `while` 输出 1 到 5。
2. 用 `while` 求 1 到 100 的和。
3. 写一个程序，不断输入整数，直到输入 0 结束。
4. 写一个输入校验程序，要求分数必须在 0 到 100 之间。
5. 解释为什么忘记 `i++` 可能导致死循环。

## 分层练习

1. 基础：输出 5、4、3、2、1。
2. 基础：统计 1 到 100 中有多少个偶数。
3. 提升：不断输入整数，统计输入了多少个非 0 数。
4. 提升：不断输入分数，直到输入合法分数为止。
5. 进阶：输入一个正整数，计算它的位数。
6. 思考：什么时候应使用 `while`，什么时候更适合使用 `for`？

## 小结

`while` 循环用于在条件成立时重复执行代码。学习时要重点关注初始值、循环条件、循环体和状态更新四个部分。只要能分析每一轮变量如何变化，就能更可靠地写出不会死循环、边界正确的循环程序。
