## 初学者导读

`while` 循环用于在条件成立时重复执行一段代码，适合循环次数不固定的场景。学习时应重点关注循环条件如何变化。

## 关键术语说明

- 循环条件：决定是否继续重复的表达式。
- 循环体：每次重复执行的代码。
- 死循环：条件一直为真，程序停不下来。
- 迭代：循环执行的一轮。
- 状态更新：让循环条件逐渐变化的语句。

## 核心概念

`while` 在条件成立时重复执行代码，适合循环次数不确定的场景。

## 关键内容

- 先判断条件，再执行循环体。
- 条件为假时循环结束。
- 循环体中应有机会改变循环条件。
- 常用于输入校验、事件等待、未知次数迭代。

## 示例

```c
int n = 5;
while (n > 0) {
    printf("%d\n", n);
    n--;
}
```

## 代码逐行解释

- `int n = 5;`：循环从 5 开始。
- `while (n > 0)`：只要 n 大于 0 就继续。
- `printf` 输出当前 n 的值。
- `n--;` 每轮让 n 减 1，否则条件会一直成立。

## 常见错误

- 忘记更新循环变量导致死循环。
- 条件边界写错，多循环或少循环一次。
- 循环体中修改太多状态，难以推理。

## 初学者常见误区

- 循环体里必须有机会改变条件，否则可能死循环。
- 先判断再执行，所以条件一开始为假时一次都不执行。
- 调试循环时可以先输出循环变量。

## 语法格式

```c
while (条件) {
    循环体;
    更新条件相关变量;
}
```
