# C24. 参数传递

## 节点定位

- 所属模块：函数与模块化
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：理解调用函数时，数据如何进入函数。

## 学习目标

- 能说明实参和形参的区别。
- 能理解 C 语言普通参数默认按值传递。
- 能说明为什么函数内部修改形参不会直接改变外部变量。
- 能正确分析参数数量、类型和顺序。
- 能理解把表达式作为实参时，传入的是表达式的计算结果。
- 能初步知道如果要修改外部变量，后续需要学习地址和指针。

## 初学者导读

函数不是孤立工作的。调用函数时，通常需要把一些数据交给它。

例如：

```c
int sum = add(3, 4);
```

这里 `3` 和 `4` 就是传给 `add` 函数的数据。函数内部接收到这些数据后，才能完成计算。

本节要解决的问题是：调用函数时，外部的数据如何进入函数？函数内部的参数和外部变量是什么关系？

这部分非常重要，因为很多初学者会误以为“函数里改了参数，外面的变量也会自动改变”。在 C 语言中，普通参数默认不是这样工作的。

## 关键术语说明

- 参数：函数接收的数据。
- 形参：函数定义中写出的参数变量。
- 实参：函数调用时实际传入的数据。
- 值传递：把实参的值复制一份交给形参。
- 副本：复制出来的一份数据。
- 参数顺序：实参与形参按位置一一对应。
- 参数类型：函数要求接收的数据类型。
- 地址传递：把变量地址传给函数，使函数有机会修改外部变量；本节只做初步认识。

## 学习思路

学习参数传递时，建议先掌握三个问题：

1. 函数定义中写的是形参。
2. 函数调用中传入的是实参。
3. C 语言普通参数传递时，形参得到的是实参值的一份副本。

理解这三点后，再看更复杂的地址、指针、数组参数会轻松很多。

## 核心概念

C 语言普通函数参数默认按值传递。也就是说，调用函数时，实参的值会复制给形参。

```c
void change(int x) {
    x = 100;
}

int main(void) {
    int a = 10;
    change(a);
    printf("%d\n", a);
    return 0;
}
```

输出结果是：

```text
10
```

原因是：`change(a)` 调用时，`a` 的值 10 被复制给形参 `x`。函数内部修改的是 `x`，不是外部的 `a`。

## 形参与实参

示例：

```c
int add(int a, int b) {
    return a + b;
}

int result = add(3, 4);
```

其中：

| 名称 | 位置 | 示例 | 说明 |
|---|---|---|---|
| 形参 | 函数定义中 | `int a, int b` | 函数内部接收数据的变量 |
| 实参 | 函数调用中 | `3, 4` | 调用时真正传入的数据 |

调用时，实参按顺序传给形参：

- `3` 传给 `a`。
- `4` 传给 `b`。

因此 `add(3, 4)` 的结果是 7。

## 值传递的过程

看下面程序：

```c
void show(int x) {
    printf("%d\n", x);
}

int main(void) {
    int a = 10;
    show(a);
    return 0;
}
```

调用 `show(a)` 时，可以理解为：

1. 读取变量 `a` 的值，得到 10。
2. 把 10 复制给形参 `x`。
3. 进入 `show` 函数。
4. `show` 函数输出 `x` 的值。
5. 函数结束后，回到 `main`。

在这个过程中，`x` 是函数内部的变量，`a` 是 `main` 中的变量。二者不是同一个变量。

## 函数内部修改形参

示例：

```c
void change(int x) {
    x = 100;
    printf("x = %d\n", x);
}

int main(void) {
    int a = 10;
    change(a);
    printf("a = %d\n", a);
    return 0;
}
```

输出：

```text
x = 100
a = 10
```

这说明函数内部的 `x` 被改成了 100，但外部的 `a` 仍然是 10。

可以把它理解为：把作业本上的数字抄到草稿纸上，修改草稿纸不会改变原作业本。

## 实参可以是变量、常量或表达式

函数调用时，实参不一定是变量。

```c
int add(int a, int b) {
    return a + b;
}
```

可以这样调用：

```c
add(3, 4);
```

也可以这样调用：

```c
int x = 3;
int y = 4;
add(x, y);
```

还可以这样调用：

```c
add(x + 1, y * 2);
```

当实参是表达式时，程序会先计算表达式的值，再把结果传给形参。

例如 `add(x + 1, y * 2)` 中：

- `x + 1` 的结果传给第一个形参。
- `y * 2` 的结果传给第二个形参。

## 参数数量要匹配

函数定义需要几个参数，调用时通常就要传入几个实参。

```c
int add(int a, int b) {
    return a + b;
}
```

正确：

```c
add(3, 4);
```

错误：

```c
add(3);
add(3, 4, 5);
```

第一个调用少了一个参数，第二个调用多了一个参数。

## 参数类型要合适

函数参数有类型要求。

```c
double average(int a, int b) {
    return (a + b) / 2.0;
}
```

这里 `average` 的两个参数类型都是 `int`。调用时应传入适合作为整数的数据。

```c
average(80, 90);
```

如果传入类型不合适，编译器可能报错、警告，或者发生类型转换。初学阶段建议尽量让实参类型和形参类型一致。

## 参数顺序很重要

实参和形参按位置对应，不按名字对应。

```c
int subtract(int a, int b) {
    return a - b;
}
```

调用：

```c
subtract(10, 3);
```

结果是 7，因为：

- `10` 传给 `a`。
- `3` 传给 `b`。

如果写成：

```c
subtract(3, 10);
```

结果是 -7。

对于加法，调换参数顺序结果可能不变；但对于减法、除法、比较等函数，顺序非常重要。

## 多个参数的设计

函数参数不宜过多。参数太多时，调用者很容易传错顺序。

例如：

```c
int between(int x, int low, int high) {
    return x >= low && x <= high;
}
```

调用：

```c
between(score, 0, 100);
```

这表示判断 `score` 是否在 0 到 100 之间。

如果写成：

```c
between(0, score, 100);
```

含义就完全不同。

因此函数名和参数名要尽量清楚，调用时也要注意顺序。

## 如果希望函数修改外部变量

普通值传递不会修改外部变量。如果确实希望函数修改外部变量，通常需要传递变量的地址。

下面示例只做初步认识：

```c
void set_zero(int *p) {
    *p = 0;
}

int main(void) {
    int a = 10;
    set_zero(&a);
    printf("%d\n", a);
    return 0;
}
```

输出：

```text
0
```

这里：

- `&a` 表示变量 `a` 的地址。
- `int *p` 表示形参 `p` 接收一个整数变量的地址。
- `*p = 0;` 表示通过地址修改外部变量。

这涉及指针知识。当前阶段只需知道：普通参数传的是值的副本；如果要修改外部变量，需要学习地址和指针，后续 C32、C34 会详细讲。

## scanf 为什么需要 &

前面学习 `scanf` 时写过：

```c
scanf("%d", &age);
```

原因与参数传递有关。`scanf` 的任务是把输入结果写进变量，因此它不能只得到 `age` 当前的值，还必须知道 `age` 在内存中的位置。

所以要传入 `&age`，也就是变量地址。

这可以帮助理解：当函数需要修改外部变量时，通常要让函数知道变量的位置。

## 数组参数的预告

后面学习数组时会看到：

```c
void print_array(int arr[], int n);
```

数组作为函数参数时有特殊规则，常常会表现得像传入了数组首元素的地址。因此函数可以访问数组中的元素。

这部分会在 C27 一维数组和 C34 指针与函数中进一步学习。本节重点仍然是普通变量的值传递。

## 示例

```c
#include <stdio.h>

void change(int x) {
    x = 100;
    printf("inside: %d\n", x);
}

int main(void) {
    int a = 10;

    change(a);
    printf("outside: %d\n", a);

    return 0;
}
```

## 代码逐行解释

- `void change(int x)`：定义函数，形参 `x` 接收一个整数值。
- `x = 100;`：修改函数内部的形参。
- `int a = 10;`：在 `main` 中定义变量 `a`。
- `change(a);`：把 `a` 的值复制给形参 `x`。
- 函数内部修改 `x`，不会改变外部的 `a`。
- 最终输出可以看到内部是 100，外部仍是 10。

## 常见错误

- 以为函数内部修改普通形参会改变外部变量。
- 调用函数时实参数量和形参数量不一致。
- 实参类型与形参类型不合适。
- 调换参数顺序导致结果错误。
- 还没有理解指针时，直接模仿复杂地址传递代码。
- 想让函数修改外部变量，却只传入变量的值。

## 初学者常见误区

- 形参不是实参本身，而是接收实参值的变量。
- 普通参数传递时，函数得到的是值的副本。
- 实参可以是常量、变量或表达式。
- 参数按位置对应，不按变量名对应。
- 如果函数只需要计算结果，优先通过返回值交回结果。
- 如果函数需要修改外部变量，后续需要理解地址和指针。

## 语法格式

函数定义中的形参：

```c
返回类型 函数名(类型1 形参1, 类型2 形参2) {
    函数体;
}
```

函数调用中的实参：

```c
函数名(实参1, 实参2);
```

普通值传递示例：

```c
int add(int a, int b);
int sum = add(x, y);
```

地址传递预告：

```c
void set_zero(int *p);
set_zero(&a);
```

## 小结

参数传递描述的是调用函数时数据如何进入函数。C 语言普通参数默认按值传递，形参得到的是实参值的一份副本。理解这一点后，就能正确分析函数内部修改参数为什么不影响外部变量，也能为后续学习指针参数、数组参数打下基础。
