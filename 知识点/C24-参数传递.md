## 初学者导读

参数传递描述调用函数时数据如何进入函数。C 语言默认按值传递；如果希望函数修改外部变量，通常需要传递变量地址。

## 关键术语说明

- 实参：调用函数时真正传进去的数据。
- 形参：函数定义里接收数据的变量。
- 值传递：复制一份值交给函数。
- 地址传递：把变量所在位置交给函数。
- 输出参数：函数通过指针把结果写回外部变量。

## 核心概念

C 函数参数默认按值传递。函数得到的是实参值的一份副本。如果要修改外部变量，通常传递地址。

## 关键内容

- 值传递不会改变实参本身。
- 指针参数可以间接修改外部变量。
- 数组作为参数时会退化为指针。

## 示例

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

## 代码逐行解释

- `void swap(int *a, int *b)`：函数接收两个整数变量的地址。
- `*a` 表示访问第一个地址中的整数。
- `temp` 临时保存一个值，避免交换时丢失。
- 通过指针交换，函数外部的两个变量也会被改变。

## 常见错误

- 以为普通参数能修改外部变量。
- 传指针时忘记取地址。
- 解引用空指针或无效指针。

## 初学者常见误区

- 普通参数是复制值，函数里改了不会影响外面。
- 想改外部变量，就要传地址并用指针接收。
- 传地址后要警惕空指针和无效地址。

## 语法格式

```c
void by_value(int x);
void by_address(int *x);

by_value(a);
by_address(&a);
```
