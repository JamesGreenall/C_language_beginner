## 初学者导读

`switch` 适合处理一个表达式对应多个固定取值的情况，例如菜单编号、状态值或选项编号。它能让多分支代码更加清晰。

## 关键术语说明

- `switch` 表达式：用于匹配多个固定值的表达式。
- `case`：某一种具体情况。
- `break`：结束当前 `switch`。
- `default`：所有 `case` 都不匹配时执行。
- 贯穿执行：忘记 `break` 后继续执行下一个 `case`。

## 核心概念

`switch` 适合处理一个表达式对应多个固定值的分支场景。

## 关键内容

- `case` 后面通常是整型常量表达式。
- `break` 用于跳出 `switch`。
- `default` 处理未匹配情况。
- 字符、枚举值常用于 `switch`。

## 示例

```c
switch (level) {
case 1:
    printf("easy\n");
    break;
case 2:
    printf("normal\n");
    break;
default:
    printf("unknown\n");
    break;
}
```

## 代码逐行解释

- `switch (level)`：根据 `level` 的值选择分支。
- `case 1`：当值为 1 时执行这里。
- `break`：执行完当前情况后跳出 `switch`。
- `default`：没有任何 case 匹配时执行。

## 常见错误

- 忘记 `break` 导致贯穿执行。
- 用 `switch` 判断复杂区间。
- 没有写 `default`。

## 初学者常见误区

- 忘记 `break` 会继续执行后面的 `case`。
- `switch` 不适合判断复杂范围。
- `default` 能兜底处理意外输入。

## 语法格式

```c
switch (表达式) {
case 常量1:
    语句;
    break;
default:
    语句;
    break;
}
```
