# C12. 表达式

## 节点定位

- 所属模块：数据、表达式与基础交互
- 学习难度：入门
- 建议学习时间：20-30 分钟
- 典型用途：在 C 程序中正确理解和使用“表达式”。

## 学习目标

- 能说清楚“表达式”解决的具体问题。

- 能说明它与前置知识点、后续知识点之间的关系。

## 初学者导读

表达式是能够计算出结果的代码片段，可以用于赋值、条件判断、循环控制、函数调用等场景。初学者学习表达式时，需要同时关注三件事：表达式的值是什么、表达式的类型是什么、表达式是否会改变变量或程序状态。

## 关键术语说明

- 表达式：能计算出一个值的代码片段。
- 表达式的值：计算完成后的结果。
- 表达式的类型：结果属于什么数据类型。
- 副作用：表达式除了算值，还改变了变量或状态。
- 求值顺序：表达式中各部分被计算的先后关系。
- 左值：可以出现在赋值号左边、表示可修改存储位置的表达式。
- 右值：主要表示一个计算结果，通常不能直接被赋值。

## 核心概念

表达式由变量、字面量、运算符、函数调用等组成，计算后会产生一个值。

例如：

```c
a + b
score >= 60
x = 10
printf("hello\n")
```

这些都是表达式。它们有的用于计算数值，有的用于判断真假，有的会修改变量，有的会调用函数完成输出。

## 关键内容

- 算术表达式产生数值。
- 关系表达式产生真假意义。
- 赋值表达式会修改变量。
- 函数调用也可以出现在表达式中。
- 表达式的类型由参与运算的数据决定。

## 表达式由什么组成

表达式通常由以下元素组成：

| 组成部分 | 示例 | 说明 |
|---|---|---|
| 字面量 | `10`、`3.14`、`'A'` | 直接写出的固定值 |
| 变量 | `score`、`age` | 已经声明的变量名 |
| 运算符 | `+`、`=`、`>=`、`&&` | 对数据进行计算或判断 |
| 函数调用 | `printf("hi")` | 调用函数后产生效果或结果 |
| 括号 | `(a + b)` | 改变或明确计算顺序 |

## 表达式的值与类型

每个表达式通常都有一个值，也有一个类型。

```c
int a = 5;
int b = 2;

a + b;      // 值是 7，类型通常是 int
a / b;      // 值是 2，类型通常是 int
(double)a / b; // 值是 2.5，类型是 double
```

表达式的类型会影响后续计算结果。例如，`a / b` 是整数除法，而 `(double)a / b` 是浮点除法。

## 1. 算术表达式

算术表达式用于产生数值结果。

```c
int result = (a + b) * 2;
```

这里：

- `a + b` 是一个表达式。
- `(a + b) * 2` 也是一个表达式。
- 整个表达式的结果被保存到 `result` 中。

常见算术表达式包括：

```c
a + b
a - b
a * b
a / b
a % b
```

需要注意：如果参与除法的两个数都是整数，结果会按整数处理。

## 2. 关系表达式

关系表达式用于比较大小或判断是否相等，结果表示真假。

```c
score >= 60
age < 18
a == b
a != b
```

在 C 语言中，关系表达式成立时结果通常为 `1`，不成立时结果为 `0`。

```c
int is_pass = score >= 60;
```

这里 `score >= 60` 的结果会保存到 `is_pass` 中。

## 3. 逻辑表达式

逻辑表达式用于组合多个条件。

```c
score >= 0 && score <= 100
choice == 1 || choice == 2
!finished
```

示例：

```c
int valid = score >= 0 && score <= 100;
```

这表示 `score` 必须同时满足“大于等于 0”和“小于等于 100”，`valid` 才为真。

需要注意：`&&` 和 `||` 具有短路求值特性，右边表达式不一定会被计算。

## 4. 赋值表达式

赋值表达式会把右边的值保存到左边变量中。

```c
x = 10
x = x + 1
x += 5
```

赋值表达式不仅有结果，还会修改变量，这就是副作用。

```c
int x = 0;
x = 10; // 修改 x 的值
```

注意：

- `x = 10` 是赋值表达式。
- `x == 10` 是关系表达式，用于判断是否相等。

## 5. 自增自减表达式

`++` 和 `--` 也会产生副作用，因为它们会修改变量。

```c
int i = 1;
i++; // i 变为 2
```

前置和后置写法的表达式值不同：

```c
int i = 1;
int a = ++i; // i 先变为 2，a 得到 2

int j = 1;
int b = j++; // b 先得到 1，j 再变为 2
```

初学阶段建议把自增自减单独写成一行，避免放进复杂表达式中。

## 6. 条件表达式

条件表达式使用 `?:`，可以根据条件选择两个结果之一。

```c
int max = a > b ? a : b;
```

含义是：

- 如果 `a > b` 成立，表达式结果是 `a`。
- 否则表达式结果是 `b`。

条件表达式适合简单选择。复杂逻辑应优先使用 `if/else`。

## 7. 函数调用表达式

函数调用也可以作为表达式。

```c
printf("hello\n");
```

这类表达式的重点通常不是计算值，而是产生效果，例如输出内容。

有返回值的函数调用也可以参与计算：

```c
int len = strlen("hello");
```

这里 `strlen("hello")` 是函数调用表达式，它的结果被保存到 `len` 中。

## 8. 表达式中的副作用

副作用指表达式除了产生值以外，还改变了变量或程序状态。

有副作用的表达式包括：

```c
x = 10;        // 修改 x
x++;           // 修改 x
scanf("%d", &x); // 修改 x
printf("hi");  // 改变输出设备状态
```

没有明显副作用的表达式：

```c
a + b
score >= 60
```

区分副作用很重要，因为有副作用的表达式会改变后续程序状态。

## 9. 求值顺序与括号

表达式中有多个运算符时，优先级决定先算哪一部分。

```c
int result = 2 + 3 * 4; // 结果是 14
```

如果希望先算加法，应写成：

```c
int result = (2 + 3) * 4; // 结果是 20
```

括号不仅可以改变计算顺序，也可以让代码更容易阅读。

初学阶段建议：

- 表达式稍微复杂时主动加括号。
- 不要在同一个表达式中多次修改同一个变量。
- 把复杂表达式拆成多个中间变量。

不推荐：

```c
int y = x++ + ++x; // 不适合初学者，难以判断和维护
```

推荐：

```c
x++;
int y = x + 1;
x++;
```

## 10. 表达式与语句的区别

表达式强调“能计算出一个值”，语句强调“执行一个动作”。

例如：

```c
x + 1
```

这是表达式，但单独写出来不会改变 `x`。

```c
x = x + 1;
```

这是表达式语句。`x = x + 1` 是表达式，后面的分号让它成为一条语句，程序执行后会修改 `x`。

可以这样理解：

| 内容 | 重点 | 示例 |
|---|---|---|
| 表达式 | 计算出值 | `a + b` |
| 语句 | 执行动作 | `a = a + b;` |

## 11. 拆分复杂表达式

复杂表达式虽然可能写得很短，但不一定容易读。

不推荐：

```c
int result = (a + b) * (c - d) / (e + 1);
```

更适合初学者的写法：

```c
int sum = a + b;
int diff = c - d;
int base = e + 1;
int result = sum * diff / base;
```

拆分表达式的好处：

- 更容易看懂每一步含义。
- 更容易打印中间结果进行调试。
- 更容易发现除数是否可能为 0。

## 示例

```c
int result = (a + b) * 2;
int is_pass = score >= 60;
int max = a > b ? a : b;
```

## 代码逐行解释

- `(a + b) * 2`：先算括号里的加法，再乘 2。
- `score >= 60`：判断分数是否达到及格线。
- `int is_pass = ...`：把判断结果保存为整数，0 表示假，非 0 表示真。
- `a > b ? a : b`：根据条件选择 `a` 或 `b`，结果保存到 `max`。
- 表达式既可能用于计算，也可能用于判断。

## 常见错误

- 忽略括号导致计算顺序错误。
- 表达式过长，难以阅读和调试。
- 使用未初始化变量参与计算。
- 把赋值表达式 `=` 误写成判断相等，或把 `==` 误写成赋值。
- 在一个复杂表达式中多次修改同一个变量。
- 误以为表达式只要写出来就一定会改变变量。

## 初学者常见误区

- 不是所有表达式都只是“算数”，有些还会改变变量。
- 表达式过长时，拆成几步更容易调试。
- 判断条件也有类型和值，不是凭感觉真或假。
- 表达式的结果有类型，类型会影响计算结果。
- 函数调用也可以是表达式，但它常常还会产生输出、输入等副作用。

