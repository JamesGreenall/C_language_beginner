## 初学者导读

`for` 循环常用于已知次数的重复操作，尤其适合遍历数组。它把初始化、条件判断和更新集中在一起，便于描述计数型循环。

## 关键术语说明

- 初始化：循环开始前做一次的准备。
- 条件：每轮开始前判断是否继续。
- 更新：每轮结束后改变循环变量。
- 循环变量：控制循环次数的变量，常用 `i`。
- 遍历：按顺序访问一组数据中的每个元素。

## 核心概念

`for` 循环把初始化、条件判断、更新表达式放在一起，适合已知次数的循环。

## 关键内容

- 基本形式：`for (初始化; 条件; 更新)`
- 常用于遍历数组。
- 三个表达式都可以省略，但分号不能省略。
- 循环变量的边界设计非常重要。

## 示例

```c
for (int i = 0; i < 10; i++) {
    printf("%d\n", i);
}
```

## 代码逐行解释

- `int i = 0`：循环变量从 0 开始。
- `i < 10`：只要 i 小于 10 就继续。
- `i++`：每轮结束后 i 增加 1。
- 循环体会依次输出 0 到 9。

## 常见错误

- 数组下标越界。
- 把 `i <= n` 和 `i < n` 混用。
- 在循环体中意外修改循环变量。

## 初学者常见误区

- 数组遍历通常是 `i < 长度`，不是 `i <= 长度`。
- 不要在循环体里随便修改循环变量。
- 初学时先把三个部分写完整，再考虑省略。

## 语法格式

```c
for (初始化; 条件; 更新) {
    循环体;
}
```
