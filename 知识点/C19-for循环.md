# C19. for 循环

## 节点定位

- 所属模块：控制流程
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：处理循环次数较明确的重复操作。

## 学习目标

- 能说明 `for` 循环适合什么场景。
- 能理解 `for (初始化; 条件; 更新)` 三个部分的作用。
- 能分析 `for` 循环的执行顺序。
- 能正确设计循环变量的起点、终点和变化方式。
- 能使用 `for` 完成计数、求和、统计等基本任务。
- 能避免边界错误和数组下标越界。

## 初学者导读

上一节 C18 学习了 `while` 循环。`while` 适合“不知道要循环多少次，但知道什么时候停止”的场景。

`for` 循环更适合“循环次数比较明确”的场景。例如：

- 输出 1 到 10。
- 求 1 到 100 的和。
- 重复输入 5 个分数。
- 以后遍历数组中的每个元素。

`for` 的特点是把循环变量的初始值、继续条件、更新方式集中写在一行中，因此非常适合计数型循环。

## 关键术语说明

- 初始化：循环开始前执行一次的准备语句。
- 条件：每一轮开始前判断是否继续循环。
- 更新：每轮循环体执行完后执行的语句。
- 循环变量：控制循环次数的变量，常用名字是 `i`、`j`、`k`。
- 计数型循环：按照次数或编号重复执行的循环。
- 遍历：按照顺序访问一组数据中的每个元素。
- 边界：循环开始和结束的位置，例如 `i = 0`、`i < n`。

## 学习思路

学习 `for` 循环时，建议围绕三个位置理解：

```c
for (初始化; 条件; 更新) {
    循环体;
}
```

可以按下面的问题分析：

1. 循环变量从哪里开始？
2. 满足什么条件时继续？
3. 每一轮结束后变量怎样变化？
4. 循环体中重复做什么？

## 核心概念

`for` 循环把初始化、条件判断和更新集中在循环头部，适合表达结构清楚的计数循环。

```c
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

这段代码输出 1 到 5。

其中：

- `int i = 1`：设置循环变量初始值。
- `i <= 5`：判断是否继续循环。
- `i++`：每轮结束后让 `i` 增加 1。
- `printf("%d\n", i);`：每轮执行的循环体。

## for 循环的执行顺序

`for` 的书写顺序和执行顺序不完全一样。

```c
for (初始化; 条件; 更新) {
    循环体;
}
```

实际执行顺序是：

1. 执行初始化，只执行一次。
2. 判断条件。
3. 如果条件为真，执行循环体。
4. 执行更新。
5. 回到第 2 步继续判断。
6. 如果条件为假，循环结束。

以代码为例：

```c
for (int i = 1; i <= 3; i++) {
    printf("%d\n", i);
}
```

执行过程：

| 步骤 | `i` 的值 | 条件 `i <= 3` | 输出 | 更新 |
|---|---|---|---|---|
| 初始化 | 1 | - | - | - |
| 第 1 轮 | 1 | 真 | 1 | `i` 变 2 |
| 第 2 轮 | 2 | 真 | 2 | `i` 变 3 |
| 第 3 轮 | 3 | 真 | 3 | `i` 变 4 |
| 结束判断 | 4 | 假 | 不输出 | 循环结束 |

## 计数从 1 开始

如果要输出 1 到 5，可以写：

```c
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

这种写法符合日常数数习惯，适合刚开始学习循环。

注意：如果结束值要包含 5，就要写 `i <= 5`。

## 计数从 0 开始

C 语言中很多场景会从 0 开始计数，尤其是数组下标。

```c
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

输出结果是：

```text
0
1
2
3
4
```

这里不是输出到 5，而是输出 5 个数。

从 0 开始、条件写 `i < n`，是数组遍历中非常常见的写法。因为长度为 `n` 的数组，下标通常是 `0` 到 `n - 1`。

## `i++`、`i--` 与步长

最常见的更新方式是 `i++`，表示每轮增加 1。

```c
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

如果要倒序输出，可以使用 `i--`。

```c
for (int i = 5; i >= 1; i--) {
    printf("%d\n", i);
}
```

如果每次增加 2，可以写：

```c
for (int i = 0; i <= 10; i = i + 2) {
    printf("%d\n", i);
}
```

输出：

```text
0
2
4
6
8
10
```

更新表达式应当和循环条件配合。如果 `i` 在增加，条件通常应让它最终超过上界；如果 `i` 在减少，条件通常应让它最终低于下界。

## 求和示例

`for` 常用于求一段连续整数的和。

```c
int sum = 0;

for (int i = 1; i <= 100; i++) {
    sum = sum + i;
}

printf("%d\n", sum);
```

分析：

- `sum` 初始为 0，用来保存总和。
- `i` 从 1 到 100。
- 每一轮把当前 `i` 加到 `sum` 中。
- 循环结束后，`sum` 就是 1 到 100 的和。

## 统计示例

例如统计 1 到 100 中有多少个偶数：

```c
int count = 0;

for (int i = 1; i <= 100; i++) {
    if (i % 2 == 0) {
        count++;
    }
}

printf("%d\n", count);
```

这里把 `for` 和 `if` 结合起来使用：

- `for` 负责遍历 1 到 100。
- `if` 负责判断当前数字是否为偶数。
- `count++` 负责记录符合条件的数量。

## 固定次数输入

如果需要输入 5 个数，可以使用 `for`。

```c
int x;
int sum = 0;

for (int i = 1; i <= 5; i++) {
    scanf("%d", &x);
    sum = sum + x;
}

printf("%d\n", sum);
```

这段程序会读取 5 个整数并求和。因为输入次数是明确的，所以 `for` 比 `while` 更直观。

## for 与 while 的对应关系

很多 `for` 循环都可以改写成 `while`。

`for` 写法：

```c
for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}
```

对应的 `while` 写法：

```c
int i = 1;

while (i <= 5) {
    printf("%d\n", i);
    i++;
}
```

二者本质上都包含初始值、条件、循环体和更新。区别在于 `for` 把这些部分集中写在一起，计数结构更清楚。

## 循环边界设计

边界决定循环执行几次。

要输出 1 到 10：

```c
for (int i = 1; i <= 10; i++)
```

要输出 0 到 9：

```c
for (int i = 0; i < 10; i++)
```

两种写法都会循环 10 次，但输出的数字不同。

常见错误：

```c
for (int i = 0; i <= 10; i++) {
    printf("%d\n", i);
}
```

这会输出 0 到 10，一共 11 个数。如果本意是循环 10 次，就多了一次。

## 数组下标的预告

数组会在后续章节详细学习。这里先记住一个重要习惯：

如果数组长度是 `n`，遍历时通常写：

```c
for (int i = 0; i < n; i++) {
    // 使用第 i 个元素
}
```

原因是数组下标通常从 0 开始，最后一个下标是 `n - 1`。因此条件应写 `i < n`，而不是 `i <= n`。

这也是 `for` 循环特别重要的原因：它是数组遍历的基础。

## 示例

```c
#include <stdio.h>

int main(void) {
    int sum = 0;

    for (int i = 1; i <= 100; i++) {
        sum = sum + i;
    }

    printf("%d\n", sum);
    return 0;
}
```

## 代码逐行解释

- `int sum = 0;`：准备变量保存累加结果。
- `for (int i = 1; i <= 100; i++)`：让 `i` 从 1 变化到 100。
- `sum = sum + i;`：每轮把当前 `i` 加入总和。
- `printf("%d\n", sum);`：输出最终结果。
- `return 0;`：程序正常结束。

## 常见错误

- 把 `i < n` 写成 `i <= n`，导致多循环一次。
- 循环变量初始值写错，导致少循环或多循环。
- 更新方向与条件不匹配，导致死循环。
- 在循环体中随意修改循环变量，使执行次数难以判断。
- 遍历数组时下标越界。
- 忘记 `for` 头部的两个分号。

## 初学者常见误区

- `for` 不是只能从 0 开始，也可以从 1 或其他值开始。
- `i++` 不是必须的，更新表达式也可以是 `i--` 或 `i = i + 2`。
- `for` 的初始化只在循环开始前执行一次。
- 循环体执行完后，先执行更新，再回到条件判断。
- 数组遍历常写 `i < 长度`，不是 `i <= 长度`。
- 如果循环次数不确定，`while` 可能比 `for` 更合适。

## 语法格式

```c
for (初始化; 条件; 更新) {
    循环体;
}
```

常见形式：

```c
for (int i = 0; i < n; i++) {
    循环体;
}

for (int i = 1; i <= n; i++) {
    循环体;
}

for (int i = n; i >= 1; i--) {
    循环体;
}
```

## 练习题

1. 用 `for` 输出 1 到 10。
2. 用 `for` 输出 10 到 1。
3. 用 `for` 求 1 到 100 的和。

## 分层练习

1. 基础：输出 0 到 9。
2. 基础：输出 2、4、6、8、10。
3. 提升：输入 5 个整数，输出它们的总和。
4. 提升：输入 5 个整数，统计其中正数的个数。
5. 进阶：输出九九乘法表的一行，例如 `3 * 1` 到 `3 * 9`。
6. 思考：为什么数组遍历常写 `i < n`？如果写成 `i <= n` 会有什么风险？

## 小结

`for` 循环适合循环次数明确、循环变量变化规律清楚的场景。学习时要重点理解初始化、条件、更新的执行顺序，并认真处理边界。掌握 `for` 后，后续学习数组遍历、统计和批量处理会更顺畅。
