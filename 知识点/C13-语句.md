# C13. 语句

## 节点定位

- 所属模块：数据、表达式与基础交互
- 学习难度：入门
- 建议学习时间：20-30 分钟
- 典型用途：理解 C 程序中“一条完整命令”如何书写和执行。

## 学习目标

- 能说明语句与表达式的区别。
- 能识别常见的简单语句，如声明语句、赋值语句、函数调用语句和返回语句。
- 能理解分号在 C 语言中的作用。
- 能知道复合语句和空语句的基本形式。
- 能明白本节只是控制结构的入口，条件分支和循环将在后续知识点中详细学习。

## 初学者导读

上一节 C12 主要学习“表达式”，也就是程序中能够计算出结果的部分，例如 `a + b`、`x > 0`、`x = 10`。本节学习“语句”，也就是程序中可以被执行的一条完整命令。

可以先这样理解：

- 表达式关注“算出什么”。
- 语句关注“让程序做什么”。

例如 `x + 1` 只是一个表达式；如果写成 `x = x + 1;`，它就成为一条赋值语句，程序会真正修改变量 `x` 的值。

本节不深入讲 `if`、`while`、`for` 等条件和循环结构。这些内容会在后续章节单独学习。这里先掌握最基础的语句形式，避免一开始把多个概念混在一起。

## 关键术语说明

- 语句：程序中可以被执行的一条完整命令。
- 表达式语句：表达式后面加分号形成的语句，例如 `x = 10;`。
- 声明：告诉编译器要使用某个变量或对象，例如 `int age;`。
- 分号：许多简单语句的结束标记。
- 复合语句：用 `{}` 包起来的一组语句，也常称为语句块。
- 空语句：只有一个分号 `;` 的语句，表示什么也不做。
- 控制语句：改变程序执行顺序的语句，本节只做初步认识，后续再详细学习。

## 学习思路

学习本知识点时，建议按照以下顺序理解：

1. 先分清表达式和语句。
2. 再掌握分号表示一条简单语句结束。
3. 观察变量声明、赋值、函数调用、返回这些常见语句。
4. 最后知道 `{}` 可以把多条语句组成一个整体。

## 核心概念

语句是 C 程序执行的基本单位。程序运行时，会按照一定顺序执行一条条语句。

例如：

```c
int x = 10;
x = x + 1;
return 0;
```

这三行都可以看作程序中的动作：

- `int x = 10;`：准备一个整数变量，并给它初始值。
- `x = x + 1;`：把 `x` 的值增加 1。
- `return 0;`：结束当前函数，并返回结果。

## 关键内容

- 语句通常表示程序要执行的一步动作。
- 多数简单语句以分号 `;` 结束。
- 表达式加分号可以形成表达式语句。
- 声明用于引入变量，不要和普通赋值语句混淆。
- `{}` 可以把多条语句组成一个语句块。
- 条件语句和循环语句属于后续重点，本节只需要知道它们也是语句的一类。

## 语句与表达式的区别

表达式通常可以计算出一个值。

```c
x + 1
```

这只是一个表达式，它计算出了 `x + 1` 的结果，但没有说明要把结果保存到哪里。

如果写成：

```c
x = x + 1;
```

它就成为一条语句。程序会执行赋值操作，把右边计算出的结果存回 `x`。

初学阶段可以用下面的问题来判断：

| 问题 | 更接近的概念 |
|---|---|
| 这段代码能算出一个值吗？ | 表达式 |
| 这段代码会让程序执行一个动作吗？ | 语句 |
| 这段代码是否以分号结束，成为完整一行命令？ | 常见简单语句 |

## 常见的简单语句

### 1. 声明语句

声明用于告诉编译器：程序中将要使用某个变量。

```c
int age;
double score;
char grade;
```

也可以在声明时给变量初始值：

```c
int age = 16;
double score = 92.5;
char grade = 'A';
```

声明的重点不是“重新计算”，而是“准备一个可以使用的名字和存储位置”。

### 2. 赋值语句

赋值语句用于把一个值保存到变量中。

```c
age = 17;
score = score + 1.5;
grade = 'B';
```

赋值语句左边通常是变量名，右边通常是表达式。程序会先计算右边，再把结果存入左边变量。

需要区分：

```c
int age = 16; // 声明并初始化
age = 17;     // 赋值语句
```

第一行是在创建变量时给初始值；第二行是在变量已经存在后修改它的值。

### 3. 函数调用语句

函数调用表示让某个函数执行工作。初学阶段最常见的是 `printf`。

```c
printf("hello\n");
printf("%d\n", age);
```

这里暂时只需要知道：函数调用后面加分号，也可以形成一条语句。`printf` 和 `scanf` 的具体格式会在 C14 中详细学习。

### 4. 返回语句

`return` 用于结束当前函数，并把结果交回给调用者。

在初学者最常见的程序中，经常会看到：

```c
return 0;
```

在 `main` 函数中，`return 0;` 通常表示程序正常结束。

## 分号的作用

在 C 语言中，很多简单语句必须用分号结束。

```c
int x = 10;
x = x + 1;
printf("%d\n", x);
```

分号告诉编译器：这条语句到这里结束。

常见错误是忘记分号：

```c
int x = 10
x = x + 1;
```

编译器通常会报错，因为它无法正确判断第一条语句在哪里结束。

需要注意：换行不等于语句结束。下面这条语句虽然分成多行书写，但直到分号出现才结束。

```c
x =
    x + 1;
```

这种写法合法，但初学阶段建议先保持一条简单语句写在一行，便于阅读。

## 空语句

空语句只有一个分号：

```c
;
```

它表示“什么也不做”。空语句本身合法，但初学阶段多数情况下不是有意写出来的。

例如：

```c
x = 10;;
```

第二个分号就是一个空语句。它通常不会影响这个简单例子的结果，但会降低代码清晰度。后续学习条件和循环结构时，错误多写分号可能造成更明显的逻辑问题，因此现在就应养成认真检查分号的习惯。

## 复合语句：把多条语句组成一个整体

复合语句用 `{}` 包围多条语句。

```c
{
    int x = 10;
    x = x + 1;
    printf("%d\n", x);
}
```

这几条语句被放在同一个语句块中。语句块常用于组织代码，也会在后续的分支、循环和函数中频繁出现。

初学阶段可以先记住两点：

- 左花括号 `{` 表示一组语句开始。
- 右花括号 `}` 表示这一组语句结束。

## 程序会按顺序执行语句

在没有条件分支和循环时，程序通常从上到下执行语句。

```c
int x = 1;
x = x + 2;
x = x * 3;
```

执行过程是：

1. `x` 的初始值是 1。
2. 执行 `x = x + 2;` 后，`x` 变成 3。
3. 执行 `x = x * 3;` 后，`x` 变成 9。

理解顺序执行后，再学习条件分支和循环会更容易。因为条件和循环本质上是在改变“下一步执行哪条语句”。

## 关于控制语句的说明

C 语言中确实还有条件语句、循环语句和跳转语句，例如：

- 条件语句：根据条件决定是否执行某些语句。
- 循环语句：在条件满足时重复执行某些语句。
- 跳转语句：让程序提前结束某段执行过程。

这些内容对程序设计很重要，但它们各自都有新的规则。为了降低学习难度，本节只说明它们属于“语句”的范围，不在这里展开语法细节。

后续章节会分别学习：

- C16 if/else 分支
- C18 while 循环
- C19 for 循环
- C20 break/continue

## 示例

```c
#include <stdio.h>

int main(void) {
    int x = 10;
    x = x + 1;
    printf("%d\n", x);
    return 0;
}
```

## 代码逐行解释

- `#include <stdio.h>`：引入输入输出所需的标准库声明。
- `int main(void) {`：程序从 `main` 函数开始执行。
- `int x = 10;`：声明整数变量 `x`，并把初始值设为 10。
- `x = x + 1;`：执行赋值语句，使 `x` 增加 1。
- `printf("%d\n", x);`：输出变量 `x` 的值。
- `return 0;`：程序正常结束。
- `}`：`main` 函数的语句块结束。

## 常见错误

- 忘记在简单语句末尾写分号。
- 把中文分号 `；` 写成 C 代码中的分号。
- 误以为换行就表示语句结束。
- 写出 `x + 1;` 这样的语句，但没有保存计算结果。
- 把声明并初始化 `int x = 10;` 和后续赋值 `x = 20;` 混为一谈。
- 多写无意义的空语句，使代码变得不清楚。

## 初学者常见误区

- 不是每一行代码都一定是一条语句，例如预处理指令 `#include <stdio.h>` 就不是普通语句。
- 不是所有表达式都有实际效果，例如 `x + 1;` 虽然合法，但通常没有意义。
- 分号是语句的重要边界，不能随意省略。
- 花括号不是装饰符号，它表示一组语句的范围。
- 条件和循环虽然也是语句，但应放到后续章节逐步学习。

## 语法格式

```c
类型 变量名;
类型 变量名 = 初始值;

变量名 = 表达式;
函数名(参数);
return 表达式;

{
    语句1;
    语句2;
}
```
