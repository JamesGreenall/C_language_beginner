# C33. 指针与数组

## 节点定位

- 所属模块：内存与指针
- 学习难度：重点进阶
- 建议学习时间：90-120 分钟
- 典型用途：理解数组名与首元素地址的关系，使用指针访问和传递数组。

## 学习目标

- 理解数组元素连续存储的含义。
- 理解数组名在多数表达式中为何会转换为首元素指针。
- 掌握 `arr[i]` 与 `*(arr + i)` 的关系。
- 会使用指针遍历数组，并理解指针运算的有效范围。
- 区分数组本身与指针变量，特别是二者在 `sizeof` 中的差异。
- 理解数组作为函数参数时为何还需要单独传递长度。

## 一、从数组的连续存储开始

```c
int numbers[4] = {10, 20, 30, 40};
```

这一定义创建 4 个类型相同、连续存储的 `int` 元素。数组下标从 0 开始：

```text
元素       numbers[0]  numbers[1]  numbers[2]  numbers[3]
值             10          20          30          40
```

如果一个 `int` 占 4 字节，那么相邻元素的起始地址通常相差 4 字节。程序正是利用“起始位置、元素大小和下标”找到指定元素。

## 二、数组名在多数表达式中的转换

在多数表达式中，数组名 `numbers` 会自动转换为指向首元素的指针，也就是 `&numbers[0]`。

```c
int *p = numbers;
```

可以理解为：

```c
int *p = &numbers[0];
```

此时 `p` 指向数组第一个元素。以下两个地址输出通常相同：

```c
printf("%p\n", (void *)numbers);
printf("%p\n", (void *)&numbers[0]);
```

这里说“转换为指针”，不等于“数组就是指针”。数组和指针仍是两种不同的对象，后文会具体比较。

## 三、指针加 1 不是简单加 1 字节

```c
int *p = numbers;
```

此时：

- `p` 指向 `numbers[0]`；
- `p + 1` 指向 `numbers[1]`；
- `p + 2` 指向 `numbers[2]`。

指针加 1 的含义是移动到“下一个同类型元素”，实际跨过的字节数由指针类型决定。

若 `sizeof(int)` 为 4，则 `int *` 加 1 通常跨过 4 字节；若 `double` 占 8 字节，则 `double *` 加 1 通常跨过 8 字节。

因此，指针类型不仅决定怎样读取数据，也决定指针运算的步长。

## 四、下标访问与指针访问

数组下标表达式：

```c
numbers[i]
```

在 C 语言中与下面的表达式含义相同：

```c
*(numbers + i)
```

推导过程如下：

1. `numbers` 转换为首元素地址；
2. `numbers + i` 移动到第 `i` 个元素；
3. `*(numbers + i)` 解引用该地址，取得对应元素。

例如：

```c
printf("%d\n", numbers[2]);
printf("%d\n", *(numbers + 2));
```

两行都输出 30。

同样，如果 `p` 指向数组首元素，那么 `p[i]` 与 `*(p + i)` 也具有相同含义。

## 五、用指针遍历数组

### 方法一：指针配合下标

```c
#include <stdio.h>

int main(void) {
    int numbers[5] = {12, 18, 25, 31, 44};
    int *p = numbers;

    for (int i = 0; i < 5; i++) {
        printf("%d ", p[i]);
    }
    printf("\n");

    return 0;
}
```

### 方法二：移动指针

```c
for (int *current = numbers; current < numbers + 5; current++) {
    printf("%d ", *current);
}
```

其中：

- `current = numbers`：从首元素开始；
- `current < numbers + 5`：尚未到达尾后位置；
- `current++`：移动到下一个元素；
- `*current`：读取当前元素。

初学阶段使用“下标加长度”的形式通常更直观，理解原理后再使用移动指针的写法。

## 六、尾后指针是什么

对于长度为 5 的数组，`numbers + 5` 指向最后一个元素之后的位置，称为尾后指针。

可以生成和比较尾后指针，但不能解引用它：

```c
int *end = numbers + 5;  // 允许
// printf("%d\n", *end);  // 错误：越界访问
```

合法元素的范围是 `numbers[0]` 到 `numbers[4]`。尾后位置只用于表示遍历终点，不代表那里存在数组元素。

## 七、数组和指针并不相同

虽然数组名常转换为指针，但数组本身和指针变量有重要区别。

### 1. 数组包含全部元素，指针只保存地址

```c
int arr[5];
int *p = arr;
```

`arr` 对象包含 5 个整数空间，`p` 对象只包含一个地址。

### 2. 数组名不能重新赋值

```c
int other[5];
// arr = other;  // 错误
p = other;       // 正确：p 可以改变指向
```

数组名不是可修改的指针变量。

### 3. sizeof 的结果不同

```c
printf("%zu\n", sizeof arr);
printf("%zu\n", sizeof p);
```

若 `int` 占 4 字节，`sizeof arr` 通常为 20，因为它计算整个数组；`sizeof p` 计算指针变量本身的大小，在常见 64 位环境中通常为 8。

## 八、数组名不转换为首元素指针的常见情况

“数组名总是地址”并不准确。至少在以下常见场景中，需要单独理解：

### 1. 作为 sizeof 的操作数

```c
sizeof arr
```

这里得到整个数组的大小，而不是指针大小。

### 2. 对数组名取地址

```c
&arr
```

`arr` 在一般表达式中转换为 `int *`，指向首元素；`&arr` 的类型是“指向整个数组的指针”。二者常显示相同的起始地址，但类型和指针运算步长不同。

初学阶段只需记住：输出首元素地址通常使用 `arr` 或 `&arr[0]`，不要因为地址数字相同就认为它们的类型完全相同。

## 九、使用 sizeof 计算数组长度

在数组定义所在的作用域中，可以写：

```c
int arr[] = {10, 20, 30, 40};
size_t length = sizeof arr / sizeof arr[0];
```

含义是：

- `sizeof arr`：整个数组的字节数；
- `sizeof arr[0]`：一个元素的字节数；
- 二者相除：元素个数。

但这种方法传入函数后通常不能继续使用，因为函数参数中的数组形式会被调整为指针。

## 十、数组作为函数参数

下面两个函数声明在参数位置上具有等价含义：

```c
void print_array(int arr[], int length);
void print_array(int *arr, int length);
```

函数实际接收到的是首元素地址，不是整个数组的副本。因此函数还需要单独接收长度：

```c
#include <stdio.h>

void print_array(const int arr[], int length) {
    for (int i = 0; i < length; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int data[] = {3, 6, 9, 12};
    int length = (int)(sizeof data / sizeof data[0]);

    print_array(data, length);
    return 0;
}
```

`const int arr[]` 表示函数只读取数组元素，不应修改它们。长度参数告诉函数哪些元素属于有效范围。

## 十一、为什么函数中不能用 sizeof 参数求数组长度

```c
void wrong(int arr[]) {
    size_t length = sizeof arr / sizeof arr[0];  // 错误思路
}
```

在函数参数中，`arr` 已按指针处理。因此 `sizeof arr` 得到的是指针大小，而不是调用者数组的总大小。正确做法是由调用者传入元素个数。

这也是“数组不是指针，但数组参数会按指针处理”最重要的实际表现之一。

## 十二、通过指针修改数组元素

```c
void double_values(int arr[], int length) {
    for (int i = 0; i < length; i++) {
        arr[i] *= 2;
    }
}
```

函数接收到首元素地址，通过该地址访问的是调用者原数组，所以修改会保留下来。这并不表示数组整体进行了值传递，而是地址被按值传入，函数通过地址修改原数组。

## 十三、指针相减

若两个指针都指向同一个数组中的元素，二者相减可以得到相隔的元素个数：

```c
int arr[5];
int *first = &arr[1];
int *last = &arr[4];

printf("%td\n", last - first);  // 3
```

指针差的类型是 `ptrdiff_t`，使用 `%td` 输出。不能随意对来自不同数组的指针做减法或顺序比较，因为那不具有可靠的 C 语言含义。

## 十四、字符串与字符指针

字符串本质上是以空字符 `\0` 结尾的字符数组，因此字符指针也常用于遍历字符串：

```c
char text[] = "C language";

for (char *p = text; *p != '\0'; p++) {
    printf("%c\n", *p);
}
```

循环以 `*p != '\0'` 为条件，因为空字符标志字符串有效内容结束。指针仍然必须停留在数组有效范围内。

## 十五、常见错误与原因

### 1. 访问数组边界之外

```c
int arr[3] = {1, 2, 3};
printf("%d\n", *(arr + 3));  // 错误：这是尾后位置
```

### 2. 把数组名当成可修改指针

```c
arr++;  // 错误
```

可以移动指针变量，但不能修改数组名。

### 3. 在函数中用 sizeof 求数组长度

函数参数只保存地址，不保存原数组总大小。长度必须单独传入。

### 4. 指针指向一个数组，却按另一个数组范围移动

指针运算必须限制在同一个数组对象及其尾后位置内。跨越到其他对象没有可靠意义。

### 5. 认为指针保存了整个数组

指针只保存起始地址。元素类型和长度需要由程序设计者另外掌握。

## 十六、完整示例：求和并查找最大值

```c
#include <stdio.h>

void analyze(const int *arr, int length, int *sum, int *maximum) {
    *sum = 0;
    *maximum = arr[0];

    for (int i = 0; i < length; i++) {
        *sum += arr[i];
        if (arr[i] > *maximum) {
            *maximum = arr[i];
        }
    }
}

int main(void) {
    int data[] = {18, 7, 25, 13, 20};
    int length = (int)(sizeof data / sizeof data[0]);
    int sum;
    int maximum;

    analyze(data, length, &sum, &maximum);
    printf("总和：%d\n", sum);
    printf("最大值：%d\n", maximum);

    return 0;
}
```

这个示例同时体现：

- 数组名向首元素指针转换；
- 长度需要单独传入；
- `const int *arr` 只用于读取数组；
- `sum` 和 `maximum` 通过指针参数返回结果。

## 分层练习

1. 分别使用 `arr[i]` 和 `*(arr + i)` 输出同一个数组。
2. 使用移动指针的方式计算数组所有元素之和。
3. 比较 `sizeof arr` 与 `sizeof p`，解释结果不同的原因。
4. 编写函数，把数组中的所有负数改为 0，并由调用者传入数组长度。
5. 解释为什么 `arr + length` 可以作为循环终点，却不能被解引用。

## 小结

数组元素连续存储，数组名在多数表达式中会转换为首元素指针，因此 `arr[i]` 可以理解为 `*(arr + i)`。但数组包含完整元素空间，指针只保存地址，二者不能混为一谈。使用指针处理数组时，必须同时掌握元素类型、有效长度和访问边界。
