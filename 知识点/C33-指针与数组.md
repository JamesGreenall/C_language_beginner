## 初学者导读

数组和指针在 C 语言中关系密切，因为数组名在许多表达式中会转换为首元素地址。理解这种关系，有助于掌握数组传参和指针遍历。

## 关键术语说明

- 数组名退化：数组名在很多表达式中会变成首元素地址。
- 首元素地址：数组第一个元素的位置。
- 指针运算：指针加 1 通常移动到下一个同类型元素。
- `sizeof(arr)`：整个数组大小。
- `sizeof(p)`：指针变量本身大小。

## 核心概念

数组名在多数表达式中会转换为首元素指针，指针可通过偏移访问数组元素。

## 关键内容

- `arr[i]` 与 `*(arr + i)` 在含义上密切相关。
- 数组名不是普通可修改指针变量。
- 指针运算按元素类型大小移动。
- 函数参数中的数组通常退化为指针。

## 示例

```c
int arr[3] = {10, 20, 30};
int *p = arr;
printf("%d\n", *(p + 1)); // 20
```

## 代码逐行解释

- `int arr[3]`：创建 3 个连续整数空间。
- `int *p = arr;`：p 指向数组第一个元素。
- `p + 1`：移动到下一个整数元素的位置。
- `*(p + 1)`：访问第二个元素，也就是 20。

## 常见错误

- 把数组名当作可重新赋值的变量。
- 指针越界访问数组。
- 混淆 `sizeof(arr)` 和 `sizeof(p)`。

## 初学者常见误区

- 数组名不是普通指针变量，不能随便给它重新赋值。
- 指针移动要保证仍在数组范围内。
- `sizeof(arr)` 和 `sizeof(p)` 的结果通常不同。

## 语法格式

```c
arr[i]
*(arr + i)
指针 + 偏移量
```
