# C45. 小型程序设计

## 节点定位

- 所属模块：文件、调试与综合应用
- 学习难度：综合应用
- 建议学习时间：40-60 分钟
- 典型用途：在 C 程序中正确理解和使用“小型程序设计”。

## 学习目标

- 能说清楚“小型程序设计”解决的具体问题。
- 能在一段 C 代码中识别与“小型程序设计”有关的语法现象。
- 能独立写出一个包含该知识点的最小示例程序。
- 能说明它与前置知识点、后续知识点之间的关系。

## 初学者导读

小型程序设计要求综合使用变量、控制流、函数、数组、结构体和调试方法。它关注的不只是单个语法点，而是如何把知识点组织成可运行、可维护的程序。

## 关键术语说明

- 需求：程序要解决什么问题。
- 数据结构：用什么方式保存数据。
- 函数拆分：把大任务拆成小任务。
- 边界条件：极端或特殊输入。
- 测试：检查程序是否按预期工作。

## 学习思路

学习本知识点时，建议按照以下顺序理解：

1. 明确它要解决的具体问题。
2. 观察它在代码中的基本形式。
3. 分析它会如何影响程序的输入、输出、内存或执行顺序。
4. 理解它与前置知识点和后续知识点的联系。

## 核心概念

小型程序设计要求把基础语法组合起来，形成可读、可测、可维护的完整程序。

## 关键内容

- 明确输入、处理、输出。
- 把重复逻辑提取成函数。
- 用数组、结构体组织数据。
- 用头文件和源文件拆分模块。
- 处理错误情况和边界条件。

## 示例任务

学生成绩管理小程序：

- 输入学生姓名和成绩。
- 计算平均分、最高分、最低分。
- 按条件查询学生。
- 可选：保存到文件。

## 示例结构

```c
struct Student {
    char name[20];
    double score;
};

double average_score(struct Student students[], int count);
void print_students(struct Student students[], int count);
```

## 代码逐行解释

- `struct Student`：用结构体保存一个学生的数据。
- `students[]`：用数组保存多个学生。
- `average_score`：把计算平均分拆成函数。
- `print_students`：把输出学生列表拆成函数。
- 结构体、数组、函数组合起来，就能形成完整小程序。

## 常见错误

- 一开始就写全部代码，不拆小函数。
- 只考虑正常输入，不处理异常输入。
- 数据结构设计混乱，导致后续功能难加。

## 初学者常见误区

- 不要一上来写完整程序，先写最小可运行版本。
- 每加一个功能就测试一次。
- 数据结构设计清楚，后面的函数会简单很多。

## 语法格式

```text
需求分析 -> 数据结构设计 -> 函数拆分 -> 编码实现 -> 测试边界 -> 整理模块
```
