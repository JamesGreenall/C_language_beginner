## 初学者导读

`printf` 用于向屏幕输出信息，`scanf` 用于从键盘读取输入。掌握基础输入输出后，程序才能与使用者进行简单交互。初学者学习本节时，要重点关注格式占位符、变量类型、`scanf` 中的取地址符 `&`，以及输入空格和换行带来的影响。

## 关键术语说明

- 标准输入：通常是键盘输入。
- 标准输出：通常是屏幕输出。
- 格式字符串：告诉 `printf` 或 `scanf` 按什么格式处理数据。
- 占位符：如 `%d`、`%f`，表示这里对应一个数据。
- 取地址符 `&`：告诉 `scanf` 数据应该存到哪个变量位置。
- 缓冲区：输入数据临时存放的位置，换行和空格也可能留在其中。
- 返回值：函数执行后返回的结果，`scanf` 的返回值可用于判断读取是否成功。

## 核心概念

`printf` 用于格式化输出，`scanf` 用于格式化输入。二者都需要包含 `<stdio.h>`。

最小示例：

```c
#include <stdio.h>

int main(void) {
    int age;
    scanf("%d", &age);
    printf("age = %d\n", age);
    return 0;
}
```

这段程序完成了两个动作：

1. 从键盘读取一个整数，保存到 `age`。
2. 把 `age` 的值输出到屏幕。

## 关键内容

- `%d` 输出或输入整数。
- `%f` 用于 `float`。
- `%lf` 用于 `double` 的 `scanf`。
- `%c` 用于字符。
- `%s` 用于字符串。
- `scanf` 读取变量时通常需要取地址符 `&`。

## printf：格式化输出

`printf` 的基本形式是：

```c
printf("格式字符串", 输出项1, 输出项2, ...);
```

格式字符串中可以包含普通文字，也可以包含格式占位符。

```c
int age = 18;
printf("age = %d\n", age);
```

这里：

- `"age = %d\n"` 是格式字符串。
- `%d` 表示这里要填入一个整数。
- `age` 是要填入的位置对应的数据。
- `\n` 表示换行。

### printf 常用占位符

| 占位符 | 对应类型 | 说明 |
|---|---|---|
| `%d` | `int` | 输出十进制整数 |
| `%u` | `unsigned int` | 输出无符号整数 |
| `%f` | `float`、`double` | 输出小数，默认 6 位小数 |
| `%.2f` | `float`、`double` | 输出小数，保留 2 位小数 |
| `%c` | `char` | 输出单个字符 |
| `%s` | 字符串 | 输出字符串 |
| `%p` | 地址 | 输出地址，通常配合 `(void *)` |
| `%zu` | `sizeof` 的结果 | 输出 `size_t` 类型数值 |

示例：

```c
int count = 10;
double price = 19.99;
char level = 'A';

printf("count = %d\n", count);
printf("price = %.2f\n", price);
printf("level = %c\n", level);
```

### 输出宽度和精度

`printf` 可以控制输出宽度和小数位数。

```c
printf("%8d\n", 123);    // 至少占 8 个字符宽度
printf("%.2f\n", 3.14159); // 保留两位小数
printf("%8.2f\n", 3.14159); // 至少占 8 个字符宽度，保留两位小数
```

初学阶段不必记住所有格式规则，但应掌握 `%.2f`，因为它常用于输出价格、平均分等小数。

## scanf：格式化输入

`scanf` 的基本形式是：

```c
scanf("格式字符串", &变量1, &变量2, ...);
```

示例：

```c
int age;
scanf("%d", &age);
```

这里必须写 `&age`，因为 `scanf` 需要知道把输入数据保存到哪个变量的内存位置。

### scanf 常用占位符

| 占位符 | 对应变量类型 | 示例 |
|---|---|---|
| `%d` | `int` | `scanf("%d", &age);` |
| `%u` | `unsigned int` | `scanf("%u", &count);` |
| `%f` | `float` | `scanf("%f", &height);` |
| `%lf` | `double` | `scanf("%lf", &score);` |
| `%c` | `char` | `scanf("%c", &ch);` |
| `%s` | 字符数组 | `scanf("%s", name);` |

注意：`double` 在 `printf` 中常用 `%f`，但在 `scanf` 中必须使用 `%lf`。

## 为什么 scanf 通常需要 &

变量名表示变量中的值，而 `&变量名` 表示变量所在的地址。

```c
int age;
scanf("%d", &age);
```

`scanf` 的任务是把输入写入变量，所以它需要变量地址。如果写成：

```c
scanf("%d", age); // 错误
```

程序没有得到正确的存储位置，可能导致运行错误。

例外情况：读取字符串到字符数组时，数组名本身通常已经表示首元素地址，因此常见写法不加 `&`。

```c
char name[20];
scanf("%19s", name);
```

这里 `%19s` 表示最多读取 19 个字符，为字符串末尾的 `\0` 留出空间。

## 一次输入多个数据

`scanf` 可以一次读取多个数据：

```c
int a;
int b;
scanf("%d %d", &a, &b);
```

输入时可以写：

```text
10 20
```

也可以写成两行：

```text
10
20
```

因为 `%d` 会自动跳过空白字符，包括空格、制表符和换行。

## 输入字符时的换行问题

读取字符 `%c` 时要特别注意：`%c` 不会自动跳过空白字符。

```c
int age;
char level;

scanf("%d", &age);
scanf("%c", &level);
```

如果用户输入年龄后按下回车，第二个 `scanf("%c", &level)` 可能会读到上一次输入留下的换行符。

常见处理方式是在 `%c` 前加一个空格：

```c
scanf(" %c", &level);
```

格式字符串中的空格会让 `scanf` 跳过前面的空白字符。

## 检查 scanf 的返回值

`scanf` 会返回成功读取的数据个数。

```c
int age;
int ok = scanf("%d", &age);

if (ok == 1) {
    printf("age = %d\n", age);
} else {
    printf("input error\n");
}
```

如果用户输入的不是整数，`scanf("%d", &age)` 可能读取失败。检查返回值可以让程序更稳健。

## 字符串输入的安全问题

使用 `%s` 读取字符串时，如果不限制长度，可能写出数组范围。

不推荐：

```c
char name[20];
scanf("%s", name);
```

更推荐：

```c
char name[20];
scanf("%19s", name);
```

`%19s` 表示最多读取 19 个字符，因为 `name` 一共有 20 个位置，最后一个位置要留给字符串结束标记 `\0`。

## 示例

```c
#include <stdio.h>

int main(void) {
    int age;
    scanf("%d", &age);
    printf("age = %d\n", age);
    return 0;
}
```

## 代码逐行解释

- `int age;`：准备一个整数变量存放年龄。
- `scanf("%d", &age);`：从键盘读入整数，并存入 `age` 的位置。
- `&age` 的意思是“age 这个变量的地址”。
- `printf("age = %d\n", age);`：把变量值填到 `%d` 的位置并输出。

## 常见错误

- `scanf("%d", age);` 少写 `&`。
- `printf` 格式占位符与变量类型不匹配。
- 用 `%s` 读取字符串时没有限制长度。
- `scanf` 读取 `double` 时误用 `%f`，应使用 `%lf`。
- 使用 `%c` 读取字符时，没有处理前一次输入留下的换行符。
- 不检查 `scanf` 返回值，导致输入失败后继续使用未正确赋值的变量。

## 初学者常见误区

- `scanf` 后面常常要写 `&变量`，这是因为它要把输入存进变量。
- 占位符必须和变量类型对应。
- 输入字符和字符串时，空格、换行可能影响读取结果。
- `printf` 和 `scanf` 的占位符不完全相同，尤其是 `double`。
- `%s` 读取字符串时遇到空白会停止，因此不能直接读取带空格的一整句。
- `scanf` 不是一定成功，输入内容不符合格式时会读取失败。

## 语法格式

```c
printf("格式字符串", 输出项1, 输出项2);
scanf("格式字符串", &变量);

printf("%d %.2f %c\n", count, price, level);
scanf("%d %lf", &age, &score);
scanf(" %c", &choice);
```
