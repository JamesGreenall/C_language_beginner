## 初学者导读

C 语言中的字符串本质上是以空字符 `\0` 结尾的字符数组。理解这一点，可以帮助初学者正确处理字符串长度、输入和存储空间。

## 关键术语说明

- 字符数组：保存多个字符的数组。
- `\0`：字符串结束标记，不是字符 `'0'`。
- 字符串长度：有效字符个数，不包括 `\0`。
- 缓冲区：用来暂时存放输入或字符串的内存空间。
- `<string.h>`：提供常用字符串函数的头文件。

## 核心概念

C 字符串本质上是以空字符 `'\0'` 结尾的字符数组。

## 关键内容

- 字符串字面量用双引号。
- 字符串末尾自动带 `'\0'`。
- 常用头文件：`<string.h>`
- 常用函数：`strlen`、`strcpy`、`strcmp`、`strcat`
- 字符数组容量必须能容纳结尾的 `'\0'`。

## 示例

```c
char name[20] = "Alice";
printf("%s\n", name);
```

## 代码逐行解释

- `char name[20]`：准备 20 个字符空间。
- `"Alice"` 会占 6 个字符空间，因为末尾还有 `\0`。
- `%s` 按字符串形式输出字符数组。
- 如果数组容量太小，字符串就可能放不下。

## 常见错误

- 字符数组空间不足。
- 忘记字符串结束符。
- 使用 `scanf("%s", str)` 时没有限制长度。

## 初学者常见误区

- 字符串需要给 `\0` 留空间。
- `strlen` 统计有效字符，不包含 `\0`。
- 用 `%s` 输入时要注意长度限制，避免造成数组越界。

## 语法格式

```c
char str[容量] = "文本";
str[最后一个有效字符之后] = '\0';
```
