# C29. 字符串

## 节点定位

- 所属模块：数组与字符串
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：保存和处理一串字符组成的文本。

## 学习目标

- 能说明 C 语言字符串的本质是字符数组。
- 能理解字符串末尾的 `'\0'` 结束标记。
- 能区分字符、字符数组和字符串。
- 能正确声明和初始化字符串。
- 能使用 `%s` 输出和输入简单字符串。
- 能使用 `strlen`、`strcmp` 等常见字符串函数。
- 能避免字符数组空间不足和输入越界。

## 初学者导读

程序经常需要处理文本，例如姓名、密码、菜单命令、文件名等。C 语言没有单独的“字符串类型”，它使用字符数组来保存字符串。

例如：

```c
char name[20] = "Alice";
```

这表示准备 20 个字符空间，用来保存字符串 `"Alice"`。

需要特别注意：C 字符串的末尾必须有一个结束标记 `'\0'`。它告诉程序字符串到哪里结束。

因此，字符串 `"Alice"` 虽然看起来有 5 个字符，但实际存储需要 6 个位置：

```text
'A' 'l' 'i' 'c' 'e' '\0'
```

理解 `'\0'` 是学习 C 字符串最关键的一步。

## 关键术语说明

- 字符：单个字符，如 `'A'`、`'x'`、`'0'`。
- 字符数组：保存多个字符的数组。
- 字符串：以 `'\0'` 结尾的字符数组。
- `'\0'`：空字符，字符串结束标记。
- 字符串长度：有效字符个数，不包括 `'\0'`。
- 容量：字符数组一共能放多少个字符位置。
- 缓冲区：用于暂时保存输入或字符串的内存空间。
- `<string.h>`：提供常用字符串处理函数的头文件。

## 学习思路

学习字符串时，建议按下面顺序：

1. 先区分字符和字符串。
2. 再理解字符串实际存储在字符数组中。
3. 重点掌握 `'\0'` 的作用。
4. 学习输入、输出和常用字符串函数。
5. 始终检查数组容量是否足够。

## 核心概念

C 语言字符串本质上是以 `'\0'` 结尾的字符数组。

```c
char name[20] = "Alice";
```

实际存储可以理解为：

| 下标 | 内容 |
|---|---|
| `name[0]` | `'A'` |
| `name[1]` | `'l'` |
| `name[2]` | `'i'` |
| `name[3]` | `'c'` |
| `name[4]` | `'e'` |
| `name[5]` | `'\0'` |

`'\0'` 后面的空间仍属于数组，但不属于这个字符串的有效内容。

## 字符和字符串的区别

字符使用单引号：

```c
char ch = 'A';
```

字符串使用双引号：

```c
char str[] = "A";
```

二者不同：

| 写法 | 含义 | 占用 |
|---|---|---|
| `'A'` | 一个字符 | 1 个字符 |
| `"A"` | 一个字符串 | `'A'` 和 `'\0'`，共 2 个字符 |

因此：

```c
char ch = 'A';     // 正确
char str[] = "A";  // 正确
```

不要混用单引号和双引号。

## 声明和初始化字符串

常见写法：

```c
char name[20] = "Alice";
```

也可以让编译器根据字符串长度自动确定数组大小：

```c
char name[] = "Alice";
```

这时数组长度为 6，因为还要包含 `'\0'`。

也可以逐个字符初始化：

```c
char name[] = {'A', 'l', 'i', 'c', 'e', '\0'};
```

这与 `"Alice"` 的效果相同。

如果忘记 `'\0'`：

```c
char name[] = {'A', 'l', 'i', 'c', 'e'};
```

这只是一个字符数组，不是标准意义上的 C 字符串。用 `%s` 输出时可能出错，因为程序不知道字符串在哪里结束。

## 容量必须足够

字符串数组容量必须能容纳有效字符和结尾的 `'\0'`。

错误示例：

```c
char name[5] = "Alice";
```

`"Alice"` 需要 6 个位置：

```text
A l i c e \0
```

但 `name[5]` 只有 5 个位置，放不下完整字符串。

正确写法：

```c
char name[6] = "Alice";
```

或者：

```c
char name[20] = "Alice";
```

初学阶段宁愿多留一些空间，也不要刚好少一个。

## 输出字符串

使用 `%s` 输出字符串。

```c
char name[20] = "Alice";
printf("%s\n", name);
```

`%s` 会从 `name[0]` 开始输出字符，直到遇到 `'\0'` 为止。

如果字符串中没有正确的 `'\0'`，`printf("%s", ...)` 可能继续向后读，输出异常内容，甚至导致程序错误。

## 输入字符串

可以使用 `scanf("%s", str)` 输入不含空格的字符串。

```c
char name[20];
scanf("%19s", name);
printf("%s\n", name);
```

注意这里写 `%19s`，不是 `%s`。

原因是：

- `name` 有 20 个位置。
- 最后一个位置要留给 `'\0'`。
- 因此最多读取 19 个有效字符。

不推荐：

```c
scanf("%s", name);
```

如果用户输入太长，可能写出数组范围。

## scanf 读取字符串的特点

`scanf("%s", name)` 遇到空白字符会停止。空白字符包括空格、制表符和换行。

例如输入：

```text
Alice Smith
```

使用 `%s` 只会读到：

```text
Alice
```

如果需要读取带空格的一整行，通常使用 `fgets`。

```c
char line[100];
fgets(line, 100, stdin);
```

`fgets` 会读取一行，但可能把换行符也读入字符串。处理整行输入会涉及更多细节，初学阶段先掌握 `%s` 的特点即可。

## strlen：求字符串长度

使用 `strlen` 需要包含 `<string.h>`。

```c
#include <string.h>

char name[20] = "Alice";
printf("%zu\n", strlen(name));
```

输出：

```text
5
```

`strlen` 统计的是有效字符个数，不包括结尾的 `'\0'`。

注意：

```c
char name[20] = "Alice";
```

数组容量是 20，但字符串长度是 5。这两个概念不同。

## strcmp：比较字符串

字符串不能直接用 `==` 比较内容。

错误思路：

```c
if (name == "Alice") {
    printf("same\n");
}
```

在 C 语言中，这样比较的不是字符串内容。

应使用 `strcmp`：

```c
#include <string.h>

if (strcmp(name, "Alice") == 0) {
    printf("same\n");
}
```

`strcmp` 返回 0 表示两个字符串内容相同。

常见判断：

```c
strcmp(a, b) == 0  // 相等
strcmp(a, b) != 0  // 不相等
```

## strcpy：复制字符串

数组不能直接整体赋值。

错误：

```c
char name[20];
name = "Alice";
```

应使用初始化或字符串复制函数。

初始化：

```c
char name[20] = "Alice";
```

复制：

```c
#include <string.h>

char name[20];
strcpy(name, "Alice");
```

使用 `strcpy` 时，目标数组必须有足够空间，否则会越界。初学阶段应优先保证目标数组容量明显足够。

## strcat：拼接字符串

`strcat` 用于把一个字符串追加到另一个字符串后面。

```c
#include <string.h>

char text[30] = "Hello";
strcat(text, " ");
strcat(text, "C");

printf("%s\n", text);
```

输出：

```text
Hello C
```

使用 `strcat` 时，目标数组也必须有足够容量保存拼接后的完整字符串和 `'\0'`。

## 字符串和数组的关系

字符串是字符数组的一种特殊用法。

```c
char str[6] = "Alice";
```

可以像数组一样访问每个字符：

```c
printf("%c\n", str[0]); // A
printf("%c\n", str[1]); // l
```

也可以修改某个字符：

```c
str[0] = 'M';
printf("%s\n", str); // Mlice
```

但必须保护好结尾的 `'\0'`，否则字符串会失去结束标记。

## 遍历字符串

可以用循环逐个处理字符串中的字符。

```c
char str[] = "Alice";

for (int i = 0; str[i] != '\0'; i++) {
    printf("%c\n", str[i]);
}
```

循环条件是：

```c
str[i] != '\0'
```

这表示只要还没有遇到字符串结束标记，就继续处理。

## 示例

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[20];

    scanf("%19s", name);

    printf("%s\n", name);
    printf("%zu\n", strlen(name));

    return 0;
}
```

## 代码逐行解释

- `char name[20];`：准备 20 个字符位置保存字符串。
- `scanf("%19s", name);`：最多读取 19 个有效字符，为 `'\0'` 留出空间。
- `printf("%s\n", name);`：按字符串形式输出。
- `strlen(name)`：计算字符串有效长度，不包括 `'\0'`。
- `%zu`：用于输出 `strlen` 返回的长度类型。

## 常见错误

- 忘记字符串末尾需要 `'\0'`。
- 字符数组容量不足。
- 误以为字符串长度等于数组容量。
- 使用 `scanf("%s", str)` 时不限制长度。
- 用 `==` 比较字符串内容。
- 声明后试图用 `str = "text";` 给数组整体赋值。
- 混淆字符 `'A'` 和字符串 `"A"`。

## 初学者常见误区

- C 语言没有独立的字符串类型，字符串通常存放在字符数组中。
- `'\0'` 是字符串结束标记，不是字符 `'0'`。
- `strlen` 不统计 `'\0'`。
- `%s` 输出时会一直读到 `'\0'`。
- 字符串输入要考虑数组容量。
- 字符串比较应使用 `strcmp`，不是直接使用 `==`。

## 语法格式

```c
char str[容量] = "文本";
char str[] = "文本";

printf("%s\n", str);
scanf("%限制长度s", str);

```

```c
for (int i = 0; str[i] != '\0'; i++) {
    处理 str[i];
}
```

## 小结

C 字符串本质上是以 `'\0'` 结尾的字符数组。学习字符串时，要始终区分字符、字符串、数组容量和字符串长度。只要理解 `'\0'` 的作用，就能更可靠地处理字符串输入、输出、比较和遍历。
