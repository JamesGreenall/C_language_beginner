## 初学者导读

结构体用于把多个不同类型的数据组合为一个整体，适合描述具有多个属性的对象。它是从基础数据类型过渡到复杂数据建模的重要工具。

## 关键术语说明

- 成员：结构体内部的一个字段。
- 字段：对象的一个属性，如姓名、分数。
- `.` 运算符：访问结构体变量的成员。
- `->` 运算符：访问结构体指针指向对象的成员。
- 自定义类型：程序员自己组合出来的数据类型。

## 核心概念

结构体可以把多个不同类型的数据组合成一个自定义类型，适合描述具有多个属性的对象。

## 关键内容

- 使用 `struct` 定义结构体类型。
- 使用 `.` 访问结构体变量成员。
- 使用 `->` 访问结构体指针成员。
- 结构体可作为函数参数和返回值。

## 示例

```c
struct Student {
    int id;
    char name[20];
    double score;
};

struct Student s = {1, "Alice", 95.5};
printf("%s\n", s.name);
```

## 代码逐行解释

- `struct Student`：定义一个学生类型。
- `id`、`name`、`score` 是学生的不同属性。
- `struct Student s = ...`：创建一个学生变量。
- `s.name`：访问这个学生的姓名成员。

## 常见错误

- 忘记结构体定义末尾的分号。
- 混淆 `.` 和 `->`。
- 结构体中字符数组空间不足。

## 初学者常见误区

- 结构体定义末尾的分号不能丢。
- 结构体变量用 `.`, 结构体指针用 `->`。
- 字符数组成员要留足空间。

## 语法格式

```c
struct 类型名 {
    成员类型 成员名;
};

struct 类型名 变量名;
变量名.成员名;
指针名->成员名;
```
