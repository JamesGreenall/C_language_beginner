# C27. 一维数组

## 节点定位

- 所属模块：数组与字符串
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：保存和处理一组类型相同的数据。

## 学习目标

- 能说明数组解决什么问题。
- 能声明、初始化和访问一维数组。
- 能理解数组下标从 0 开始。
- 能使用 `for` 循环遍历数组。
- 能避免数组越界。
- 能完成数组求和、求平均值、求最大值等基本操作。

## 初学者导读

如果只保存一个分数，可以写：

```c
int score;
```

如果要保存 5 个分数，也可以写：

```c
int score1;
int score2;
int score3;
int score4;
int score5;
```

但这样很不方便：变量太多，难以循环处理，也不适合保存更多数据。

数组用于保存一组类型相同的数据。例如：

```c
int scores[5];
```

这表示准备 5 个 `int` 类型的位置，用来保存 5 个分数。数组让程序可以用同一个名字管理一组数据，再通过下标访问其中的某一个元素。

## 关键术语说明

- 数组：一组类型相同的数据。
- 元素：数组中的一个数据。
- 下标：元素的位置编号。
- 长度：数组中可以存放的元素个数。
- 下标从 0 开始：第一个元素下标是 0。
- 越界：访问了数组不存在的位置。
- 遍历：按顺序访问数组中的每个元素。
- 连续存储：数组元素在内存中通常按顺序挨着存放。

## 学习思路

学习一维数组时，建议按照以下顺序：

1. 先理解为什么需要数组。
2. 再掌握数组声明和初始化。
3. 然后学习用下标访问单个元素。
4. 最后结合 `for` 循环处理整组数据。

数组的核心不是“写一对中括号”，而是“一组数据可以用循环统一处理”。

## 核心概念

数组是一组相同类型元素的集合，通过下标访问。

```c
int scores[5] = {90, 80, 70, 60, 50};
```

这个数组有 5 个元素：

| 元素 | 值 |
|---|---|
| `scores[0]` | 90 |
| `scores[1]` | 80 |
| `scores[2]` | 70 |
| `scores[3]` | 60 |
| `scores[4]` | 50 |

长度为 5 的数组，下标范围是 0 到 4。不存在 `scores[5]`。

## 数组声明

数组声明格式：

```c
类型名 数组名[长度];
```

示例：

```c
int scores[5];
double prices[10];
char letters[26];
```

含义：

- `int scores[5];` 表示 5 个整数。
- `double prices[10];` 表示 10 个小数。
- `char letters[26];` 表示 26 个字符。

数组长度通常应是一个明确的正整数。初学阶段建议使用简单常量作为数组长度。

## 数组初始化

声明数组时可以同时给初值。

```c
int scores[5] = {90, 80, 70, 60, 50};
```

也可以让编译器根据初值个数推断长度：

```c
int scores[] = {90, 80, 70, 60, 50};
```

这里数组长度是 5。

如果初值少于数组长度，后面的元素会被初始化为 0。

```c
int a[5] = {1, 2};
```

等价于：

```text
a[0] = 1
a[1] = 2
a[2] = 0
a[3] = 0
a[4] = 0
```

常见写法：

```c
int a[5] = {0};
```

这会把所有元素初始化为 0。

## 访问数组元素

使用下标访问数组元素：

```c
scores[0]
scores[1]
scores[2]
```

数组元素可以像普通变量一样使用。

```c
scores[0] = 95;
printf("%d\n", scores[0]);
```

也可以参与计算：

```c
int total = scores[0] + scores[1];
```

需要注意：下标必须在合法范围内。

对于：

```c
int scores[5];
```

合法下标是：

```text
0, 1, 2, 3, 4
```

不合法：

```c
scores[5] = 100; // 越界
```

## 为什么下标从 0 开始

C 语言数组第一个元素下标是 0。

可以先这样记：

```text
长度为 n 的数组，合法下标是 0 到 n - 1。
```

例如：

```c
int a[5];
```

共有 5 个元素：

```text
a[0], a[1], a[2], a[3], a[4]
```

最后一个元素是 `a[4]`，不是 `a[5]`。

这是数组学习中最重要的习惯之一。

## 使用 for 遍历数组

数组常和 `for` 循环一起使用。

```c
int scores[5] = {90, 80, 70, 60, 50};

for (int i = 0; i < 5; i++) {
    printf("%d\n", scores[i]);
}
```

这里：

- `i` 从 0 开始。
- 条件是 `i < 5`。
- 因此 `i` 的值依次是 0、1、2、3、4。
- 正好对应数组的所有合法下标。

遍历长度为 `n` 的数组时，常见形式是：

```c
for (int i = 0; i < n; i++) {
    使用 arr[i];
}
```

不要写成 `i <= n`，否则会访问 `arr[n]`，造成越界。

## 数组输入

可以用循环输入数组元素。

```c
int scores[5];

for (int i = 0; i < 5; i++) {
    scanf("%d", &scores[i]);
}
```

`scores[i]` 是一个 `int` 元素，所以 `scanf` 需要它的地址：

```c
&scores[i]
```

输入 5 次后，数组中就保存了 5 个分数。

## 求数组总和

```c
int scores[5] = {90, 80, 70, 60, 50};
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum = sum + scores[i];
}

printf("%d\n", sum);
```

分析：

- `sum` 用于保存累计结果。
- 每一轮把一个数组元素加到 `sum` 中。
- 循环结束后，`sum` 就是所有元素之和。

## 求平均值

```c
int scores[5] = {90, 80, 70, 60, 50};
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum = sum + scores[i];
}

double average = sum / 5.0;
printf("%.2f\n", average);
```

这里用 `5.0`，是为了得到小数结果。如果写成 `sum / 5`，可能按整数除法计算。

## 求最大值

```c
int scores[5] = {90, 80, 70, 60, 50};
int max = scores[0];

for (int i = 1; i < 5; i++) {
    if (scores[i] > max) {
        max = scores[i];
    }
}

printf("%d\n", max);
```

为什么 `max` 初始为 `scores[0]`？

因为最大值应来自数组已有元素。先假设第一个元素最大，再依次检查后面的元素。

循环从 `i = 1` 开始，因为 `scores[0]` 已经用于初始化 `max`。

## 数组不能直接整体赋值

数组声明时可以初始化：

```c
int a[3] = {1, 2, 3};
```

但声明后不能这样整体赋值：

```c
int b[3];
b = {1, 2, 3}; // 错误
```

如果要修改数组元素，需要逐个赋值，或者用循环。

```c
b[0] = 1;
b[1] = 2;
b[2] = 3;
```

## 数组作为函数参数的预告

后续会学习数组和指针的关系。这里先知道：数组可以传给函数处理。

```c
int sum_array(int arr[], int n) {
    int sum = 0;

    for (int i = 0; i < n; i++) {
        sum = sum + arr[i];
    }

    return sum;
}
```

调用：

```c
int scores[5] = {90, 80, 70, 60, 50};
int total = sum_array(scores, 5);
```

注意：函数通常需要额外接收数组长度 `n`。因为只传数组名时，函数不一定知道数组有多少个元素。

## 示例

```c
#include <stdio.h>

int main(void) {
    int scores[5];
    int sum = 0;

    for (int i = 0; i < 5; i++) {
        scanf("%d", &scores[i]);
    }

    for (int i = 0; i < 5; i++) {
        sum = sum + scores[i];
    }

    printf("%.2f\n", sum / 5.0);
    return 0;
}
```

## 代码逐行解释

- `int scores[5];`：声明一个长度为 5 的整数数组。
- 第一个 `for` 循环：依次输入 5 个分数。
- `&scores[i]`：表示第 `i` 个元素的地址，供 `scanf` 写入数据。
- `int sum = 0;`：准备变量保存总和。
- 第二个 `for` 循环：依次累加数组元素。
- `sum / 5.0`：计算平均值，并保留小数。

## 常见错误

- 访问数组越界，如长度为 5 的数组访问 `arr[5]`。
- 把数组长度和最后一个下标混淆。
- 用 `i <= n` 遍历长度为 `n` 的数组。
- 使用未初始化的数组元素。
- 误以为数组声明后还能整体赋值。
- 把数组传给函数时忘记同时传长度。

## 初学者常见误区

- 数组下标从 0 开始。
- 长度为 `n` 的数组，最后一个下标是 `n - 1`。
- C 语言不会总是自动检查数组越界，越界可能造成严重错误。
- 数组元素类型必须相同。
- 数组大小一旦确定，不能像动态列表一样随意变长。
- 数组适合配合循环处理一批数据。

## 语法格式

```c
类型名 数组名[长度];
类型名 数组名[长度] = {初值1, 初值2, ...};
类型名 数组名[] = {初值1, 初值2, ...};

数组名[下标] = 值;
变量 = 数组名[下标];

for (int i = 0; i < 长度; i++) {
    使用 数组名[i];
}
```

## 练习题

1. 声明一个长度为 5 的整数数组，并给它初始化。
2. 用 `for` 循环输出数组中的所有元素。
3. 输入 5 个分数，求总和与平均值。
4. 求一个数组中的最大值。
5. 解释为什么长度为 5 的数组不能访问 `arr[5]`。

## 分层练习

1. 基础：定义数组 `{1, 2, 3, 4, 5}` 并输出每个元素。
2. 基础：把数组中每个元素都乘以 2 后输出。
3. 提升：输入 5 个整数，统计其中正数的个数。
4. 提升：输入 5 个整数，找出最大值和最小值。
5. 进阶：写函数 `sum_array`，接收数组和长度，返回数组总和。
6. 思考：为什么数组作为函数参数时通常还要传入长度？

## 小结

一维数组用于保存一组类型相同的数据。学习数组时，最重要的是理解下标从 0 开始、合法范围是 0 到长度减 1，并学会使用循环统一处理数组元素。数组是后续学习二维数组、字符串和指针的重要基础。
