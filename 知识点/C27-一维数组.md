## 初学者导读

一维数组用于保存一组类型相同的数据，并通过下标访问每个元素。它适合处理成绩、编号、统计数据等连续数据集合。

## 关键术语说明

- 元素：数组里的一个数据。
- 下标：元素的位置编号，从 0 开始。
- 长度：数组能放多少个元素。
- 连续存储：数组元素在内存中挨着放。
- 越界：访问不存在的下标。

## 核心概念

数组是一组相同类型元素的连续存储结构，通过下标访问元素。

## 关键内容

- 下标从 `0` 开始。
- 数组长度固定。
- 数组元素类型相同。
- 数组名在多数表达式中会转换为首元素地址。

## 示例

```c
int scores[5] = {90, 80, 70, 60, 50};

for (int i = 0; i < 5; i++) {
    printf("%d\n", scores[i]);
}
```

## 代码逐行解释

- `int scores[5]`：创建 5 个整数位置。
- `{90, 80, 70, 60, 50}`：依次给 5 个元素赋初值。
- `i < 5`：保证下标只到 4，不越界。
- `scores[i]`：访问第 i 个元素。

## 常见错误

- 数组下标越界。
- 误以为数组能整体赋值。
- 把数组长度和最后一个下标混淆。

## 初学者常见误区

- 下标从 0 开始，所以长度为 5 的数组最后下标是 4。
- C 不会自动帮你检查所有越界问题。
- 数组大小固定后，不能像列表一样随便变长。

## 语法格式

```c
类型名 数组名[长度];
类型名 数组名[长度] = {初值1, 初值2};
数组名[下标]
```
