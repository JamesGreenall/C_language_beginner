# C34. 指针与函数

## 节点定位

- 所属模块：内存与指针
- 学习难度：重点进阶
- 建议学习时间：90-120 分钟
- 典型用途：让函数访问或修改调用者的数据、处理数组，以及通过参数返回多个结果。

## 学习目标

- 理解“指针作为参数”仍然属于值传递。
- 会编写通过指针修改调用者变量的函数。
- 会区分输入参数、输出参数和输入输出参数。
- 会使用 `const` 表达函数只读数据的意图。
- 理解数组参数为何通常要与长度参数配合。
- 能识别空指针、局部变量地址失效等常见风险。

## 一、普通参数为什么不能修改调用者变量

C 语言的函数参数采用值传递。调用函数时，实参的值会复制给形参：

```c
#include <stdio.h>

void set_zero(int value) {
    value = 0;
}

int main(void) {
    int number = 10;
    set_zero(number);
    printf("%d\n", number);  // 仍然是 10
    return 0;
}
```

`set_zero` 中的 `value` 是一个新的局部变量。把它改为 0，不会改变 `main` 中的 `number`。

若函数确实需要修改 `number`，可以把 `number` 的地址传入函数。

## 二、把地址传给函数

```c
#include <stdio.h>

void set_zero(int *value) {
    if (value != NULL) {
        *value = 0;
    }
}

int main(void) {
    int number = 10;

    set_zero(&number);
    printf("%d\n", number);  // 0

    return 0;
}
```

执行过程如下：

1. `&number` 取得调用者变量的地址；
2. 该地址按值复制给指针形参 `value`；
3. `value` 和 `&number` 表示同一位置；
4. `*value = 0` 修改该位置中的数据；
5. 因此 `main` 中的 `number` 变为 0。

需要特别说明：C 语言仍然没有“引用传递”。传入函数的是地址值的副本，只是函数可以通过这份地址副本访问调用者对象。

## 三、指针参数的三种常见角色

### 1. 输入参数

函数只读取指针所指数据，不进行修改：

```c
void print_value(const int *value) {
    if (value != NULL) {
        printf("%d\n", *value);
    }
}
```

使用 `const int *` 可以清楚表达只读意图。

### 2. 输出参数

函数通过指针把计算结果写回调用者：

```c
void get_square(int number, int *result) {
    if (result != NULL) {
        *result = number * number;
    }
}
```

调用方式：

```c
int answer;
get_square(6, &answer);
```

`answer` 原来的值不重要，函数负责写入结果。

### 3. 输入输出参数

函数先读取原值，再将修改后的值写回：

```c
void add_bonus(int *score) {
    if (score != NULL) {
        *score += 5;
    }
}
```

此时参数同时承担输入和输出作用。

## 四、经典示例：交换两个变量

普通参数无法完成对调用者变量的交换：

```c
void wrong_swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}
```

这里交换的只是两个形参副本。正确写法应接收地址：

```c
#include <stdio.h>

void swap(int *a, int *b) {
    if (a == NULL || b == NULL) {
        return;
    }

    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10;
    int y = 20;

    swap(&x, &y);
    printf("x = %d, y = %d\n", x, y);

    return 0;
}
```

调用时传入 `&x` 和 `&y`，函数内部通过 `*a` 与 `*b` 访问原来的两个变量。

## 五、为什么要检查 NULL

指针参数可能接收到空指针：

```c
set_zero(NULL);
```

若函数直接执行 `*value = 0`，就会解引用空指针，产生未定义行为。因此，允许空指针的函数应先检查：

```c
if (value == NULL) {
    return;
}
```

但并非所有指针参数都必须接受 `NULL`。实际项目中还可以规定“调用者必须传入有效地址”。无论采用哪种规则，都应保持接口说明和实现一致。初学阶段主动检查 `NULL` 有助于建立安全意识。

## 六、通过指针返回多个结果

函数只能直接 `return` 一个值，但可以使用多个输出参数写回多个结果：

```c
#include <stdio.h>

int divide_with_remainder(int dividend,
                          int divisor,
                          int *quotient,
                          int *remainder) {
    if (divisor == 0 || quotient == NULL || remainder == NULL) {
        return 0;
    }

    *quotient = dividend / divisor;
    *remainder = dividend % divisor;
    return 1;
}

int main(void) {
    int quotient;
    int remainder;

    if (divide_with_remainder(17, 5, &quotient, &remainder)) {
        printf("商 = %d，余数 = %d\n", quotient, remainder);
    } else {
        printf("计算失败\n");
    }

    return 0;
}
```

这里：

- 返回值 1 或 0 表示函数是否成功；
- `quotient` 和 `remainder` 两个指针参数用于带回计算结果；
- 只有函数成功时，调用者才应使用输出结果。

这种设计把“执行状态”和“计算结果”分开，实际程序中十分常见。

## 七、数组传入函数

数组作为函数参数时，函数实际接收首元素地址：

```c
int sum_array(const int arr[], int length) {
    int sum = 0;

    for (int i = 0; i < length; i++) {
        sum += arr[i];
    }

    return sum;
}
```

也可以写成：

```c
int sum_array(const int *arr, int length)
```

在函数参数位置，二者表达相同的参数类型。由于指针本身不记录数组长度，所以必须另外传入 `length`。

`const` 表明函数不会修改数组元素。如果函数的任务是排序或批量修改，就不能给元素类型加这种 `const` 限制。

## 八、函数中修改数组

```c
void set_all_zero(int arr[], int length) {
    if (arr == NULL || length <= 0) {
        return;
    }

    for (int i = 0; i < length; i++) {
        arr[i] = 0;
    }
}
```

数组首元素地址被传入函数，因此函数访问的是调用者原数组。这里还检查了长度，防止循环使用无效范围。

需要注意，函数不会自动知道调用者实际提供了多少个元素。若调用者把长度写大，函数仍可能越界。因此长度也是函数参数约定的一部分。

## 九、指针本身也是按值传递

下面的函数不能让调用者的指针改为指向 `b`：

```c
void point_to_b(int *p, int *b) {
    p = b;
}
```

因为 `p` 只是调用者指针中地址值的一份副本。修改 `p` 的指向，只改变函数内部的副本。

```c
int a = 10;
int b = 20;
int *ptr = &a;

point_to_b(ptr, &b);
// ptr 仍然指向 a
```

若函数需要修改调用者的指针变量本身，就要传入该指针变量的地址，也就是使用二级指针。这属于后续进阶内容。当前阶段首先掌握：指针参数可以修改所指对象，但不能直接改变调用者指针变量中保存的地址。

## 十、不要返回局部变量的地址

```c
int *wrong(void) {
    int value = 100;
    return &value;
}
```

`value` 是自动存储期的局部变量，函数返回后生命周期结束。返回的地址随即失效，继续解引用会产生未定义行为。

函数可以安全返回：

- 普通计算结果；
- 调用者传入的有效地址；
- 静态存储期对象的地址；
- 成功申请且尚未释放的动态内存地址。

后三种情况都需要明确对象的生命周期和使用责任。

## 十一、const 指针参数的意义

比较下面两个函数：

```c
void display(const int *value);
void update(int *value);
```

从声明就可以看出：

- `display` 承诺不通过该指针修改整数；
- `update` 可能修改整数。

`const` 不只是为了防止误操作，也让函数接口更容易阅读。对于只读数组、字符串和结构体参数，都应考虑使用 `const`。

## 十二、指针参数的设计原则

编写函数时，可依次思考：

1. 普通值参数是否已经足够；
2. 函数是否需要修改调用者的数据；
3. 参数是输入、输出还是输入输出；
4. 指针是否允许为 `NULL`；
5. 若参数指向数组，有效长度从哪里得到；
6. 若只读取数据，是否应添加 `const`；
7. 所指对象在函数执行期间是否仍然有效。

清楚回答这些问题，比单纯记忆 `类型 *参数名` 更重要。

## 十三、常见错误与原因

### 1. 调用时忘记取地址

```c
int number = 10;
set_zero(number);  // 错误：需要 int *，却传入 int
```

应写为 `set_zero(&number)`。

### 2. 函数内忘记解引用

```c
void set_zero(int *value) {
    value = 0;  // 只把局部指针改为空，没有修改调用者变量
}
```

应写为 `*value = 0`。

### 3. 解引用空指针

在参数可能为空时，应先检查再使用。

### 4. 数组长度传错

函数只有首地址和调用者提供的长度。长度过大会越界，长度过小会漏掉元素。

### 5. 通过只读参数修改数据

若参数声明为 `const int *`，就不应强制去除 `const` 后修改对象。

### 6. 返回局部变量地址

局部变量离开函数后不再存在，其地址不能交给外部继续使用。

## 十四、完整示例：统计数组信息

```c
#include <stdio.h>

int analyze(const int data[], int length,
            int *minimum, int *maximum, double *average) {
    if (data == NULL || length <= 0 ||
        minimum == NULL || maximum == NULL || average == NULL) {
        return 0;
    }

    int sum = data[0];
    *minimum = data[0];
    *maximum = data[0];

    for (int i = 1; i < length; i++) {
        sum += data[i];

        if (data[i] < *minimum) {
            *minimum = data[i];
        }
        if (data[i] > *maximum) {
            *maximum = data[i];
        }
    }

    *average = (double)sum / length;
    return 1;
}

int main(void) {
    int scores[] = {82, 95, 76, 88, 91};
    int length = (int)(sizeof scores / sizeof scores[0]);
    int minimum;
    int maximum;
    double average;

    if (analyze(scores, length, &minimum, &maximum, &average)) {
        printf("最低分：%d\n", minimum);
        printf("最高分：%d\n", maximum);
        printf("平均分：%.2f\n", average);
    }

    return 0;
}
```

这个函数把数组作为只读输入，通过三个指针参数返回结果，并用普通返回值表示执行是否成功。

## 分层练习

1. 编写 `void increase(int *value)`，把调用者变量增加 1。
2. 编写交换两个 `double` 变量的函数。
3. 编写函数，同时计算一个整数的平方和立方，并通过两个输出参数返回。
4. 编写函数统计数组中正数、负数和零的个数，通过三个输出参数返回结果。
5. 解释为什么指针参数仍然是值传递，以及 `*参数 = 新值` 为什么能修改调用者变量。

## 小结

C 语言始终采用值传递。把地址作为实参时，函数得到的是地址值的副本，但可以通过该地址访问调用者对象。设计指针参数时，应明确数据方向、空指针规则、数组长度和对象生命周期，并在只读场景中使用 `const` 表达约束。
