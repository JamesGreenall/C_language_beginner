## 初学者导读

函数可以通过指针参数访问或修改外部数据。理解指针与函数的关系，是掌握交换变量、数组传参和输出参数的重要基础。

## 关键术语说明

- 指针参数：函数形参是指针类型。
- 间接修改：通过地址修改外部变量。
- `NULL` 检查：使用指针前确认它有效。
- 数组参数：常常以指针形式传给函数。
- `const`：表示函数不应该修改指针指向的数据。

## 核心概念

函数可以接收指针参数，从而修改外部数据、传递数组、返回复杂结果。

## 关键内容

- 指针参数常用于“输出参数”。
- 数组参数本质上常表现为指针参数。
- `const` 指针参数可保护输入数据不被修改。
- 函数指针可保存函数地址，但属于进阶内容。

## 示例

```c
void set_zero(int *value) {
    if (value != NULL) {
        *value = 0;
    }
}
```

## 代码逐行解释

- `void set_zero(int *value)`：接收一个整数变量的地址。
- `if (value != NULL)`：先确认地址有效。
- `*value = 0;`：通过地址把外部变量改成 0。
- 这是指针参数常见的安全写法。

## 常见错误

- 没有检查指针是否为 `NULL`。
- 返回局部变量地址。
- 不清楚函数是否会修改传入数据。

## 初学者常见误区

- 指针参数意味着函数可能修改外部数据。
- 写函数时要说明参数是输入、输出还是既输入又输出。
- 使用指针参数前先考虑是否需要 `NULL` 检查。

## 语法格式

```c
void 函数名(类型名 *参数) {
    if (参数 != NULL) {
        *参数 = 新值;
    }
}
```
