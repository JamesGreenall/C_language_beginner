# C22. 函数定义与调用

## 节点定位

- 所属模块：函数与模块化
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：把程序拆分成多个功能清晰的小任务。

## 学习目标

- 能说明函数为什么有助于组织程序。
- 能识别函数定义的返回类型、函数名、参数列表和函数体。
- 能写出一个简单函数，并在 `main` 中调用它。
- 能理解实参与形参的基本对应关系。
- 能理解函数调用时程序执行流程如何转移。
- 能区分有返回值函数和无返回值函数的基本写法。

## 初学者导读

前面学习的程序大多把代码写在 `main` 函数中。程序很小时这样没有问题，但当功能变多时，全部代码堆在 `main` 中会变得难以阅读和修改。

函数的作用是：把一段具有明确功能的代码单独取出来，给它一个名字。以后需要执行这段功能时，只要调用这个名字即可。

例如：

- 求两个数的和，可以写成 `add` 函数。
- 判断一个数是否为偶数，可以写成 `is_even` 函数。
- 输出菜单，可以写成 `print_menu` 函数。

函数让程序从“一大段代码”变成“多个小任务的组合”。这是程序设计中非常重要的一步。

## 关键术语说明

- 函数：完成某个明确任务的一段代码。
- 函数定义：真正写出函数如何工作的代码。
- 函数调用：使用函数名让函数执行。
- 返回类型：函数执行后返回结果的类型，如 `int`、`double`、`void`。
- 函数名：函数的名字，用于调用函数。
- 参数列表：函数接收的数据列表。
- 形参：函数定义中写出的参数变量。
- 实参：函数调用时实际传入的数据。
- 函数体：花括号 `{}` 中真正执行的语句。
- 返回值：函数通过 `return` 交回给调用位置的结果。

## 学习思路

学习函数时，建议按下面顺序理解：

1. 先理解为什么要把代码拆成函数。
2. 再观察函数定义由哪些部分组成。
3. 然后学习如何在 `main` 中调用函数。
4. 最后理解参数和返回值如何让函数与外部交换数据。

## 核心概念

函数可以把一段代码封装成一个独立功能。

```c
int add(int a, int b) {
    return a + b;
}
```

这个函数的含义是：

- 函数名是 `add`。
- 它接收两个 `int` 参数。
- 它返回一个 `int` 结果。
- 函数体中通过 `return a + b;` 返回两个数的和。

调用函数：

```c
int sum = add(3, 4);
```

这行代码会执行 `add` 函数，并把返回结果保存到 `sum` 中。

## 为什么需要函数

### 1. 减少重复代码

如果程序中多次需要求两个数中较大的值，不使用函数就可能反复写类似代码。

使用函数后：

```c
int max2(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}
```

需要时直接调用：

```c
int m1 = max2(3, 5);
int m2 = max2(10, 8);
```

相同逻辑只需要写一次。

### 2. 让程序结构更清楚

例如一个菜单程序可以拆成：

```c
print_menu();
read_choice();
handle_choice();
```

即使暂时不知道每个函数内部如何实现，也能先看出程序的大致结构。

### 3. 便于测试和修改

如果某个功能单独写成函数，就可以单独检查它是否正确。将来需要修改时，也更容易找到对应位置。

## 函数定义的基本结构

函数定义通常包含四个部分：

```c
返回类型 函数名(参数列表) {
    函数体;
}
```

示例：

```c
int add(int a, int b) {
    int result = a + b;
    return result;
}
```

对应关系：

| 部分 | 示例 | 说明 |
|---|---|---|
| 返回类型 | `int` | 函数返回整数 |
| 函数名 | `add` | 调用函数时使用的名字 |
| 参数列表 | `int a, int b` | 函数需要两个整数输入 |
| 函数体 | `{ ... }` | 函数实际执行的语句 |
| 返回语句 | `return result;` | 把结果交回调用处 |

## 函数调用

定义函数后，可以通过函数名调用它。

```c
int sum = add(3, 4);
```

调用过程可以理解为：

1. 程序遇到 `add(3, 4)`。
2. 把 3 传给参数 `a`，把 4 传给参数 `b`。
3. 进入 `add` 函数体执行。
4. 执行 `return a + b;`，得到结果 7。
5. 回到调用位置，把 7 赋给 `sum`。

函数调用不是把函数定义复制到当前位置，而是让程序暂时转去执行那个函数。执行完成后，再回到调用处继续。

## 形参与实参

形参是函数定义中的参数，实参是调用函数时传入的实际数据。

```c
int add(int a, int b) {
    return a + b;
}

int sum = add(3, 4);
```

这里：

- `a` 和 `b` 是形参。
- `3` 和 `4` 是实参。

调用时，实参的值会传给对应的形参。

| 位置 | 名称 | 示例 |
|---|---|---|
| 函数定义中 | 形参 | `int a, int b` |
| 函数调用中 | 实参 | `3, 4` |

实参与形参通常要在数量和类型上匹配。也就是说，函数需要两个整数，调用时就应提供两个合适的值。

## 返回值

有些函数会计算出一个结果，并通过 `return` 返回。

```c
int square(int x) {
    return x * x;
}
```

调用：

```c
int y = square(5);
```

`square(5)` 的结果是 25，因此 `y` 得到 25。

返回值可以：

- 保存到变量中。
- 直接用于表达式。
- 作为另一个函数的参数。

示例：

```c
printf("%d\n", square(5));
```

这里直接输出函数返回值。

## void 函数

并不是所有函数都需要返回计算结果。如果函数只负责执行动作，可以使用 `void` 作为返回类型。

```c
void print_line(void) {
    printf("----------\n");
}
```

调用：

```c
print_line();
```

`void` 表示这个函数不返回值。

参数列表中的 `void` 表示这个函数不需要参数。

```c
void print_menu(void) {
    printf("1. Start\n");
    printf("0. Exit\n");
}
```

初学阶段可以这样理解：

- `int add(int a, int b)`：需要输入，也返回结果。
- `void print_menu(void)`：不需要输入，也不返回结果，只执行输出动作。

## main 函数也是函数

C 程序从 `main` 函数开始执行。

```c
int main(void) {
    return 0;
}
```

它也是一个函数：

- 返回类型是 `int`。
- 函数名是 `main`。
- 参数列表是 `void`，表示不接收参数。
- 函数体在 `{}` 中。
- `return 0;` 表示程序正常结束。

学习普通函数后，可以更清楚地理解 `main` 的结构。

## 函数定义的位置

在简单程序中，可以先把自定义函数写在 `main` 前面。

```c
#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int sum = add(3, 4);
    printf("%d\n", sum);
    return 0;
}
```

这样编译器在看到 `main` 中的 `add(3, 4)` 之前，已经知道 `add` 函数是什么。

如果把函数定义写在 `main` 后面，就需要提前声明函数原型。这部分会在 C23 函数声明与原型中详细学习。

## 函数命名建议

函数名应尽量表达函数要做的事情。

较好的函数名：

```c
add
max2
print_menu
is_even
```

不清楚的函数名：

```c
f
test
doit
abc
```

函数名不影响机器执行，但会影响人理解程序。学习阶段应养成使用清楚名字的习惯。

## 函数职责要单一

一个函数最好完成一个明确任务。

例如：

```c
int add(int a, int b) {
    return a + b;
}
```

这个函数只负责求和，职责清楚。

如果一个函数既输入、又计算、又判断、又输出很多内容，就会变得难以理解和修改。

可以先记住一个原则：如果一段代码可以用一句清楚的话说明它的功能，就适合考虑写成函数。

## 示例

```c
#include <stdio.h>

int max2(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

int main(void) {
    int x;
    int y;

    scanf("%d %d", &x, &y);

    int bigger = max2(x, y);
    printf("%d\n", bigger);

    return 0;
}
```

## 代码逐行解释

- `int max2(int a, int b)`：定义函数，接收两个整数，返回一个整数。
- `if (a > b)`：判断哪个参数更大。
- `return a;`：如果 `a` 更大，返回 `a`。
- `return b;`：否则返回 `b`。
- `int main(void)`：程序入口函数。
- `scanf("%d %d", &x, &y);`：输入两个整数。
- `max2(x, y)`：调用函数，把 `x` 和 `y` 的值传进去。
- `int bigger = ...`：保存函数返回结果。
- `printf("%d\n", bigger);`：输出较大的数。

## 常见错误

- 函数名拼写前后不一致。
- 调用函数时参数数量不匹配。
- 调用函数时参数类型不合适。
- 函数需要返回值，却漏写 `return`。
- `void` 函数返回类型写错。
- 把函数定义写在 `main` 后面，却没有提前声明。
- 一个函数承担太多任务，导致逻辑混乱。

## 初学者常见误区

- 函数定义不会自动执行，只有调用时才会执行。
- 参数列表中的变量只在函数内部使用。
- `return` 会结束当前函数，并把结果交回调用处。
- 有返回值的函数通常应使用返回值，例如赋给变量或参与表达式。
- `void` 表示没有返回值，不是返回 0。
- 函数不是越长越好，功能清楚的小函数更容易理解。

## 语法格式

有返回值函数：

```c
返回类型 函数名(参数列表) {
    语句;
    return 返回值;
}
```

无返回值函数：

```c
void 函数名(参数列表或 void) {
    语句;
}
```

函数调用：

```c
函数名(实参列表);
变量 = 函数名(实参列表);
```

1. 基础：写一个 `square` 函数，返回一个整数的平方。
2. 基础：写一个 `print_line` 函数，输出一行分隔线。
3. 提升：写一个 `is_even` 函数，偶数返回 1，奇数返回 0。
4. 提升：在 `main` 中输入两个整数，调用函数输出较大值。
5. 进阶：把一个菜单程序中的“显示菜单”部分提取成函数。

## 小结

函数用于把程序拆分成多个功能明确的小任务。学习本节时，要重点理解函数定义、函数调用、参数和返回值之间的关系。掌握函数后，程序不再只是从头到尾写在 `main` 中，而是可以逐步组织成结构清晰、便于复用和修改的形式。
