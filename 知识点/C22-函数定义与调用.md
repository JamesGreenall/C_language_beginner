# C22. 函数定义与调用

## 节点定位

- 所属模块：函数与模块化
- 学习难度：基础

## 初学者导读

函数用于把一段具有明确功能的代码封装起来，便于重复使用和单独测试。学习函数可以帮助初学者把较大的程序拆分成多个清晰的小任务。

## 关键术语说明

- 函数名：调用函数时使用的名字。
- 参数：函数需要的输入数据。
- 返回值：函数处理后交回的结果。
- 函数体：函数内部真正执行的代码。
- 调用：让某个函数开始执行。

## 核心概念

函数把一段可复用逻辑封装起来，通过函数名调用。函数是 C 程序组织结构的核心。

## 关键内容

- 函数定义包括返回类型、函数名、参数列表、函数体。
- 函数调用会把控制权转移到函数体中执行。
- 函数让程序更容易拆分、测试和复用。

## 示例

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int sum = add(3, 4);
    return 0;
}
```

## 代码逐行解释

- `int add(int a, int b)`：定义一个接收两个整数、返回整数的函数。
- `return a + b;`：把两个参数相加后返回。
- `add(3, 4)`：调用函数，把 3 和 4 传进去。
- `sum` 保存函数返回的结果。

## 常见错误

- 调用函数前没有声明。
- 参数数量或类型不匹配。
- 函数职责过大。

## 初学者常见误区

- 函数一次只做一件清楚的事更好。
- 函数名最好用动词或动词短语。
- 调用函数时，参数数量和类型要对应。

## 语法格式

```c
返回类型 函数名(参数列表) {
    函数体;
    return 返回值;
}

函数名(实参列表);
```
