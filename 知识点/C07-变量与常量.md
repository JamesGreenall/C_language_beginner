# C07. 变量与常量

## 节点定位

- 所属模块：数据、表达式与基础交互
- 学习难度：入门

- 能独立写出一个包含该知识点的最小示例程序。
- 能说明它与前置知识点、后续知识点之间的关系。

## 初学者导读

变量用于保存程序运行过程中可能变化的数据，常量用于表示不应随意改变的固定值。理解变量与常量，有助于把现实问题中的数量、状态和结果转化为程序中的数据。

## 关键术语说明

- 变量：有名字、能保存值、值可以改变的存储位置。
- 常量：运行中不希望改变的值。
- 声明：告诉编译器变量叫什么、是什么类型。
- 初始化：变量刚创建时给它一个初始值。
- 魔法数字：代码里突然出现、含义不清的数字。

## 核心概念

变量是可以改变的数据存储位置，常量是程序运行过程中不应改变的值。

## 关键内容

- 变量声明：说明变量名和类型。
- 变量初始化：声明时赋初值。
- `const` 可声明只读变量。
- 常量能提升程序可读性，避免“魔法数字”。

## 示例

```c
int score = 95;
const double PI = 3.14159;
```

## 代码逐行解释

- `int score = 95;`：创建一个整数变量并赋初值。
- `const double PI = 3.14159;`：创建一个不应被修改的小数常量。
- `const` 不是让值更快，而是提醒编译器和程序员这个值不能改。
- 初始化能避免变量中出现未知值。

## 常见错误

- 使用未初始化变量。
- 试图修改 `const` 变量。
- 变量名不能表达业务含义。

## 初学者常见误区

- 变量声明后不初始化，里面可能是未知值。
- `const` 保护的是“不应修改”，不是绝对的数学常量概念。
- 变量名要表达用途，不只是为了让程序能跑。

## 语法格式

```c
类型名 变量名;
类型名 变量名 = 初始值;
const 类型名 常量名 = 初始值;
```
