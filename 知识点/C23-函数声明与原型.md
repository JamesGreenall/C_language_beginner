# C23. 函数声明与原型

## 节点定位

- 所属模块：函数与模块化
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：在调用函数之前，提前告诉编译器函数的基本信息。

## 学习目标

- 能说明函数声明解决什么问题。
- 能区分函数声明和函数定义。
- 能写出简单函数的声明，也称函数原型。
- 能理解声明末尾有分号，定义末尾没有额外分号。
- 能说明声明与定义为什么必须保持一致。
- 能初步理解函数声明与头文件、多文件程序之间的关系。

## 初学者导读

在 C22 中，已经学习了函数定义和函数调用。为了让初学者更容易理解，前面的示例通常把自定义函数写在 `main` 前面：

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int sum = add(3, 4);
    return 0;
}
```

这样写时，编译器在看到 `add(3, 4)` 之前，已经知道 `add` 是什么函数。

但实际程序中，函数定义不一定总是写在调用位置前面。函数可能写在 `main` 后面，也可能写在另一个源文件中。这时就需要函数声明。函数声明的作用是：先告诉编译器“有这样一个函数，它叫什么、需要什么参数、返回什么类型”。

可以把函数声明理解为函数的“简要说明书”。

## 关键术语说明

- 函数声明：提前说明函数的名字、返回类型和参数类型。
- 函数原型：函数声明的一种常见说法，强调函数的接口形式。
- 函数定义：真正写出函数体，也就是函数具体怎样执行。
- 返回类型：函数返回结果的数据类型，如 `int`、`double`、`void`。
- 参数类型：函数接收的数据类型。
- 接口：调用者需要知道的信息，包括函数名、参数和返回类型。
- 一致性：函数声明和函数定义的返回类型、参数数量、参数类型应保持一致。

## 学习思路

学习本知识点时，建议按下面顺序理解：

1. 先理解编译器为什么需要提前知道函数信息。
2. 再区分函数声明和函数定义。
3. 然后学习函数原型的书写格式。
4. 最后理解它和头文件、多文件程序的关系。

## 核心概念

函数声明告诉编译器函数的基本形式，使函数可以在定义出现之前被调用。

```c
int add(int a, int b);
```

这行代码说明：

- 函数名是 `add`。
- 函数返回 `int` 类型结果。
- 函数需要两个 `int` 类型参数。
- 这只是声明，不包含函数体。

声明后，程序可以在后面再给出函数定义。

```c
int add(int a, int b) {
    return a + b;
}
```

## 为什么需要函数声明

C 编译器通常从上到下阅读源代码。如果在看到函数定义之前就遇到了函数调用，编译器需要先知道这个函数的基本信息。

例如：

```c
int main(void) {
    int sum = add(3, 4);
    return 0;
}

int add(int a, int b) {
    return a + b;
}
```

在这段代码中，编译器先看到 `main`，又在 `main` 中看到 `add(3, 4)`。但是此时它还没有看到 `add` 的定义，不知道：

- `add` 是否存在。
- `add` 返回什么类型。
- `add` 需要几个参数。
- 每个参数是什么类型。

因此应在 `main` 前面加上声明：

```c
int add(int a, int b);

int main(void) {
    int sum = add(3, 4);
    return 0;
}

int add(int a, int b) {
    return a + b;
}
```

这样编译器在处理 `main` 时，已经知道 `add` 的基本形式。

## 函数声明与函数定义的区别

函数声明只说明函数“长什么样”，函数定义才说明函数“怎么做”。

| 项目 | 函数声明 | 函数定义 |
|---|---|---|
| 是否有函数体 | 没有 | 有 |
| 是否以分号结束 | 是 | 不是额外加分号 |
| 作用 | 告诉编译器函数接口 | 写出函数具体实现 |
| 可以出现次数 | 可以多次声明 | 同一个函数通常只能定义一次 |

声明示例：

```c
int max2(int a, int b);
```

定义示例：

```c
int max2(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}
```

注意：声明末尾有分号；定义后面不再额外写分号。

## 函数原型的基本格式

函数原型通常写成：

```c
返回类型 函数名(参数类型1 参数名1, 参数类型2 参数名2);
```

例如：

```c
int add(int a, int b);
double average(int a, int b);
void print_menu(void);
```

也可以在声明中省略参数名，只保留参数类型：

```c
int add(int, int);
double average(int, int);
void print_menu(void);
```

两种写法都合法。初学阶段建议保留参数名，因为这样更容易看懂函数的用途。

## 声明与定义必须一致

函数声明和函数定义必须在关键部分保持一致。

正确：

```c
int add(int a, int b);

int add(int a, int b) {
    return a + b;
}
```

错误示例：

```c
int add(int a, int b);

double add(double a, double b) {
    return a + b;
}
```

前面声明说 `add` 返回 `int`，接收两个 `int` 参数；后面定义却写成返回 `double`，接收两个 `double` 参数。这会造成不一致。

需要保持一致的部分包括：

- 函数名。
- 返回类型。
- 参数数量。
- 参数类型和顺序。

参数名可以不同，但不建议故意写得不一致。

```c
int add(int x, int y);

int add(int a, int b) {
    return a + b;
}
```

这在语法上通常可以接受，因为参数名只在各自位置起作用。但为了阅读清楚，建议声明和定义使用一致或含义接近的参数名。

## 声明的位置

在单个源文件中，函数声明常放在文件开头、`main` 函数之前。

```c
#include <stdio.h>

int add(int a, int b);
void print_result(int value);

int main(void) {
    int sum = add(3, 4);
    print_result(sum);
    return 0;
}
```

这样读者一开始就能看到这个文件中会用到哪些函数。

在更大的程序中，函数声明常放入头文件。例如 `.h` 文件中放声明，`.c` 文件中放定义。这部分会在 C41 头文件组织中进一步学习。

## 为什么标准库函数可以直接调用

初学者常写：

```c
#include <stdio.h>

int main(void) {
    printf("hello\n");
    return 0;
}
```

`printf` 并没有在本文件中定义，为什么可以调用？

原因是：`#include <stdio.h>` 会引入标准输入输出库中的函数声明。编译器通过这些声明知道 `printf`、`scanf` 等函数的基本形式。

因此，头文件的一个重要作用就是提供函数声明。

## 常见声明示例

无参数、无返回值：

```c
void print_line(void);
```

有参数、无返回值：

```c
void print_number(int x);
```

有参数、有返回值：

```c
int max2(int a, int b);
```

无参数、有返回值：

```c
int read_choice(void);
```

这些声明不执行任何代码，只是告诉编译器这些函数的接口。

## 示例

```c
#include <stdio.h>

int max2(int a, int b);

int main(void) {
    int result = max2(3, 5);
    printf("%d\n", result);
    return 0;
}

int max2(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}
```

## 代码逐行解释

- `int max2(int a, int b);`：函数声明，提前告诉编译器 `max2` 的返回类型和参数类型。
- `int result = max2(3, 5);`：在 `main` 中调用 `max2`。
- `printf("%d\n", result);`：输出函数返回结果。
- `int max2(int a, int b) { ... }`：函数定义，真正写出如何求较大值。
- 声明在前，定义在后，调用位置依然合法。

## 常见错误

- 忘记函数声明末尾的分号。
- 把函数声明误写成函数定义，或者把函数定义误写成声明。
- 声明和定义的返回类型不一致。
- 声明和定义的参数数量或参数类型不一致。
- 在调用函数前既没有定义，也没有声明。
- 在头文件中随意写普通函数定义，可能导致重复定义问题。

## 初学者常见误区

- 函数声明不会执行代码，它只是告诉编译器函数接口。
- 函数定义才包含函数体，才是真正的实现。
- 声明可以有多个，定义通常只能有一个。
- 声明末尾有分号，定义的花括号后不需要额外分号。
- 参数名在声明中可以省略，但保留参数名更利于学习和阅读。
- 头文件通常放声明，不是把所有代码都塞进去。

## 语法格式

函数声明：

```c
返回类型 函数名(参数列表);
```

函数定义：

```c
返回类型 函数名(参数列表) {
    函数体;
}
```

常见声明：

```c
int add(int a, int b);
double average(int a, int b);
void print_menu(void);
```

## 练习题

1. 把一个 `add` 函数的声明写在 `main` 前面，函数定义写在 `main` 后面。
2. 写出 `double average(int a, int b);` 这个声明表示的含义。
3. 判断 `int max2(int a, int b);` 是函数声明还是函数定义，并说明理由。
4. 故意让声明和定义的返回类型不一致，观察编译器提示。
5. 说明为什么 `#include <stdio.h>` 后可以使用 `printf`。

## 分层练习

1. 基础：写出 `print_menu` 函数的声明，要求它没有参数、没有返回值。
2. 基础：写出 `square` 函数的声明，要求它接收一个整数并返回整数。
3. 提升：把 `max2` 的声明、调用、定义按顺序写成完整程序。
4. 提升：写三个函数声明，分别表示输入、计算、输出三个小任务。
5. 进阶：尝试把函数声明集中放在文件开头，再把函数定义放在 `main` 后面。
6. 思考：为什么多文件项目中更需要函数声明？

## 小结

函数声明用于提前告诉编译器函数的接口，包括函数名、返回类型和参数类型。它不执行代码，也不包含函数体。掌握函数声明后，就能把函数定义放在调用位置之后，并为后续学习头文件和多文件程序组织打下基础。
