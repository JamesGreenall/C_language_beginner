## 初学者导读

函数声明用于提前告诉编译器某个函数的名称、参数和返回类型。理解函数声明，可以帮助初学者掌握函数调用顺序和多文件程序的组织方式。

## 关键术语说明

- 函数原型：函数声明的另一种叫法。
- 返回类型：函数结果的数据类型。
- 参数类型：调用函数时每个参数应该是什么类型。
- 声明位置：通常放在文件开头或头文件里。
- 一致性：声明和定义必须匹配。

## 核心概念

函数声明告诉编译器函数的名字、返回类型和参数类型，使函数可以在定义之前被调用。

## 关键内容

- 函数声明也叫函数原型。
- 声明通常写在 `.h` 文件或源文件顶部。
- 函数定义只能有一个，声明可以有多个。

## 示例

```c
int max(int a, int b);

int main(void) {
    return max(3, 5);
}

int max(int a, int b) {
    return a > b ? a : b;
}
```

## 代码逐行解释

- `int max(int a, int b);`：这是函数声明，不是函数实现。
- `main` 可以在函数定义出现前先调用 `max`。
- 后面的 `int max(...) { ... }` 才是真正的函数定义。
- 声明和定义的返回类型、参数类型必须一致。

## 常见错误

- 声明和定义的参数类型不一致。
- 忘记声明末尾的分号。
- 在头文件中写普通函数定义导致重复定义。

## 初学者常见误区

- 声明末尾有分号，定义没有。
- 声明和定义不一致会造成编译或链接问题。
- 头文件里通常放声明，不随便放普通函数定义。

## 语法格式

```c
返回类型 函数名(参数类型1 参数名1, 参数类型2 参数名2);
```
