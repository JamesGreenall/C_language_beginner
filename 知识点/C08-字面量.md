## 核心概念

字面量是直接写在代码中的固定值，如 `10`、`3.14`、`'A'`、`"hello"`。

例如：

```c
int age = 18;
double score = 95.5;
char grade = 'A';
printf("hello\n");
```

其中，`18`、`95.5`、`'A'`、`"hello\n"` 都是字面量。它们没有单独的变量名，而是直接出现在代码中。

## 关键内容

- 整数字面量：`100`
- 浮点字面量：`3.14`
- 字符字面量：`'x'`
- 字符串字面量：`"hello"`
- 转义字符：`\n`、`\t`、`\\`、`\"`

## 整数字面量

整数字面量是不带小数点的数字，通常用于表示年龄、人数、次数、编号等整数数据。

```c
int age = 18;
int count = 100;
int zero = 0;
```

常见写法：

| 写法 | 含义 |
|---|---|
| `10` | 十进制整数 |
| `0` | 整数 0 |
| `100L` | `long` 类型整数 |
| `100LL` | `long long` 类型整数 |
| `100U` | `unsigned int` 类型整数 |

初学阶段最常见的是普通十进制整数，如 `0`、`1`、`60`、`100`。

## 浮点字面量

浮点字面量用于表示带小数部分的数。

```c
double price = 19.99;
double average = 87.5;
float temperature = 36.5f;
```

常见写法：

| 写法 | 含义 |
|---|---|
| `3.14` | 默认通常作为 `double` 类型 |
| `3.14f` | `float` 类型 |
| `2.0` | 小数形式的 2 |
| `1e3` | 科学计数法，表示 1000 |
| `2.5e-2` | 科学计数法，表示 0.025 |

需要注意：`2` 是整数字面量，`2.0` 是浮点字面量。它们在除法和类型转换中可能产生不同结果。

## 字符字面量

字符字面量用单引号表示，只能表示一个字符。

```c
char grade = 'A';
char option = 'y';
char digit = '5';
```

需要注意：

- `'A'` 是一个字符。
- `'5'` 是字符 5，不是整数 5。
- `'AB'` 不是初学阶段应使用的普通字符写法，因为字符字面量通常只表示一个字符。

## 字符串字面量

字符串字面量用双引号表示，可以表示一串字符。

```c
printf("hello");
printf("C language");
```

字符串和字符不同：

| 写法 | 类型理解 | 含义 |
|---|---|---|
| `'A'` | 字符 | 一个字符 A |
| `"A"` | 字符串 | 一个包含字符 A 的字符串，末尾还有隐藏的 `\0` |
| `"hello"` | 字符串 | 多个字符组成的文本 |

字符串字面量末尾会自动包含一个空字符 `\0`，用于表示字符串结束。这也是 C 语言字符串和普通字符数组关系密切的原因。

## 转义字符

有些字符不能直接写在代码里，或者直接写出来会和 C 语言语法冲突。此时可以使用转义字符。转义字符通常以反斜杠 `\` 开头。

### 为什么需要转义字符

例如，想在字符串中输出双引号：

```c
printf("He said \"hello\".\n");
```

如果不写 `\"`，编译器会误以为中间的双引号就是字符串结束位置。

再比如，想输出换行效果：

```c
printf("line 1\nline 2\n");
```

这里的 `\n` 不表示两个普通字符 `\` 和 `n`，而表示一个换行字符。

### 常见转义字符表

| 转义字符 | 含义 | 常见用途 |
|---|---|---|
| `\n` | 换行 | 输出下一行 |
| `\t` | 水平制表符 | 对齐输出内容 |
| `\\` | 反斜杠本身 | 输出路径或反斜杠 |
| `\"` | 双引号 | 在字符串中输出 `"` |
| `\'` | 单引号 | 在字符或字符串中表示 `'` |
| `\0` | 空字符 | 标记 C 字符串结束 |
| `\r` | 回车 | 某些文本环境中使用 |
| `\b` | 退格 | 较少使用 |
| `\a` | 响铃 | 较少使用，现代环境中不一定明显 |

### 转义字符在字符和字符串中的用法

转义字符既可以出现在字符字面量中，也可以出现在字符串字面量中。

```c
char newline = '\n';
printf("hello\nworld\n");
```

- `'\n'` 是一个字符字面量，表示单个换行字符。
- `"hello\nworld\n"` 是字符串字面量，其中包含多个普通字符和两个换行字符。

### 路径中的反斜杠

如果要在字符串中写 Windows 风格路径，需要注意反斜杠本身也要转义：

```c
printf("C:\\Users\\Student\\code\n");
```

这里每个 `\\` 才表示一个真正输出的反斜杠。

## 示例

```c
printf("score = %d\n", 100);
printf("char = %c\n", 'A');
printf("path = C:\\Users\\Student\\code\n");
printf("He said \"hello\".\n");
```

## 代码逐行解释

- `100` 是整数值，常与 `%d` 配合输出。
- `'A'` 是单个字符，常与 `%c` 配合输出。
- `"score = %d\n"` 是字符串，里面的 `%d` 是等待填入整数的占位符。
- `\n` 表示换行，不是普通的字母 `n`。
- `\\` 表示输出一个反斜杠。
- `\"` 表示在字符串内部输出双引号。
- 单引号和双引号在 C 中含义不同，不能随便互换。

## 常见错误

- 把字符写成 `"A"`。
- 把字符串写成 `'hello'`。
- 忘记字符串结尾存在隐藏的 `'\0'`。
- 在字符串中直接写未转义的双引号，例如 `"He said "hello"."`。
- 在路径中只写一个反斜杠，例如 `"C:\Users\Student"`，导致 `\U`、`\S` 等被错误理解。

## 初学者常见误区

- `'A'` 和 `"A"` 不一样，前者是字符，后者是字符串。
- `\n` 是一个换行字符，不是两个普通字符。
- 字符串末尾隐藏的 `\0` 会占空间。
- `'\n'` 是字符字面量，`"\n"` 是字符串字面量，二者写法和占用空间不同。
- 转义字符虽然写成两个符号，但通常表示一个特殊字符。

## 语法格式

```c
100       // 整数字面量
3.14      // 浮点字面量
'A'       // 字符字面量
"hello"   // 字符串字面量
'\n'      // 转义字符
"hello\n" // 含转义字符的字符串字面量
```
