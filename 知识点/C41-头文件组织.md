## 初学者导读

头文件用于描述模块对外提供的接口，源文件用于实现具体功能。良好的头文件组织可以降低多文件程序的耦合度。

## 关键术语说明

- 接口：模块对外提供的函数、类型和常量。
- 实现：接口内部具体怎么做。
- include guard：防止头文件被重复包含。
- 重复定义：同一个函数或变量被定义多次。
- 模块化：把程序拆成职责清楚的部分。

## 核心概念

头文件用于暴露模块接口，源文件用于实现模块细节。良好的头文件组织能降低项目复杂度。

## 关键内容

- 头文件放声明，不随意放定义。
- 使用 include guard 防止重复包含。
- `.c` 文件包含自己的 `.h` 文件以验证声明一致。
- 标准库头文件用尖括号，自定义头文件用双引号。

## 示例

```c
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

int add(int a, int b);

#endif
```

## 代码逐行解释

- `#ifndef MATH_UTILS_H`：如果还没定义这个名字，就继续。
- `#define MATH_UTILS_H`：标记这个头文件已经被包含过。
- `int add(int a, int b);`：在头文件里放函数声明。
- `#endif`：结束条件编译区域。

## 常见错误

- 头文件没有 include guard。
- 在头文件中定义普通全局变量。
- 头文件互相包含造成依赖混乱。

## 初学者常见误区

- 头文件负责接口，源文件负责实现。
- include guard 能避免同一个头文件被重复展开。
- 模块之间依赖越清楚，项目越容易维护。

## 语法格式

```c
#ifndef HEADER_NAME_H
#define HEADER_NAME_H

声明区域

#endif
```
