# C25. 返回值

## 节点定位

- 所属模块：函数与模块化
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：让函数把执行结果交回调用者。

## 学习目标

- 能说明返回值解决什么问题。
- 能理解返回类型和 `return` 语句的关系。
- 能区分有返回值函数和 `void` 函数。
- 能正确使用函数返回值参与赋值、输出和表达式计算。
- 能理解 `return` 会结束当前函数。
- 能避免非 `void` 函数缺少返回值、返回类型不匹配等常见错误。

## 初学者导读

函数可以接收参数，也可以把结果交回给调用者。参数解决“数据怎样进入函数”，返回值解决“结果怎样从函数出来”。

例如：

```c
int sum = add(3, 4);
```

`3` 和 `4` 是传入函数的数据，`add(3, 4)` 计算出的结果会返回给调用位置，再保存到 `sum` 中。

如果没有返回值，函数只能在内部做动作，例如输出文字；如果有返回值，函数就可以把计算结果交给外部继续使用。

## 关键术语说明

- 返回值：函数执行后交回调用位置的结果。
- 返回类型：函数声明或定义中写在函数名前面的类型。
- `return` 语句：结束当前函数，并可返回一个值。
- 调用者：调用函数并接收或使用结果的代码。
- `void`：表示函数没有返回值。
- 返回类型匹配：`return` 后表达式的类型应适合函数的返回类型。
- 提前返回：在函数中根据条件提前执行 `return`，结束函数。

## 学习思路

学习返回值时，建议抓住四个问题：

1. 这个函数是否需要把结果交给外部？
2. 如果需要，返回结果是什么类型？
3. 函数内部在哪些位置执行 `return`？
4. 调用者如何使用返回值？

函数设计时，先想清楚“输入是什么、输出是什么”，再写参数和返回值。

## 核心概念

返回值是函数执行后交还给调用者的结果。返回类型决定函数应该返回什么类型的数据。

```c
int add(int a, int b) {
    return a + b;
}
```

这里：

- `int` 是返回类型。
- `return a + b;` 返回一个整数结果。
- 调用 `add(3, 4)` 时，结果是 7。

调用者可以这样使用返回值：

```c
int sum = add(3, 4);
printf("%d\n", sum);
```

## return 的基本作用

`return` 有两个作用：

1. 结束当前函数。
2. 把结果返回给调用者。

示例：

```c
int square(int x) {
    return x * x;
}
```

调用：

```c
int result = square(5);
```

执行过程：

1. 调用 `square(5)`。
2. 实参 5 传给形参 `x`。
3. 执行 `return x * x;`。
4. 返回结果 25。
5. `result` 得到 25。

## 返回类型

函数名前面的类型就是返回类型。

```c
int add(int a, int b);
double average(int a, int b);
char get_grade(int score);
void print_menu(void);
```

含义：

| 函数声明 | 返回类型 | 说明 |
|---|---|---|
| `int add(int a, int b);` | `int` | 返回整数 |
| `double average(int a, int b);` | `double` | 返回小数 |
| `char get_grade(int score);` | `char` | 返回字符 |
| `void print_menu(void);` | `void` | 不返回值 |

返回类型是函数对调用者的承诺。函数内部的 `return` 应与这个承诺一致。

## 返回值的使用方式

函数返回值可以有多种用法。

### 1. 保存到变量

```c
int sum = add(3, 4);
```

这是最常见的用法。

### 2. 直接输出

```c
printf("%d\n", add(3, 4));
```

这里没有单独定义 `sum`，而是直接输出函数返回结果。

### 3. 参与表达式计算

```c
int total = add(3, 4) + add(5, 6);
```

函数调用本身可以看作一个表达式，它的值就是函数返回值。

### 4. 作为另一个函数的实参

```c
printf("%d\n", square(add(2, 3)));
```

先计算 `add(2, 3)`，得到 5，再调用 `square(5)`，最后输出 25。

初学阶段可以先少写嵌套调用，等理解清楚后再使用。

## void 函数

如果函数只执行动作，不需要返回结果，可以把返回类型写成 `void`。

```c
void print_line(void) {
    printf("----------\n");
}
```

调用：

```c
print_line();
```

`void` 函数不应该写成：

```c
int x = print_line(); // 错误
```

因为它没有返回值，不能赋给变量。

在 `void` 函数中，可以使用不带表达式的 `return;` 提前结束函数。

```c
void print_positive(int x) {
    if (x <= 0) {
        return;
    }

    printf("%d\n", x);
}
```

如果 `x <= 0`，函数直接结束，不执行后面的输出。

## return 会结束当前函数

`return` 后面的语句通常不会再执行。

```c
int test(void) {
    return 1;
    printf("hello\n");
}
```

`printf("hello\n");` 不会执行，因为 `return 1;` 已经结束了函数。

因此，写函数时不要把必须执行的代码放在 `return` 后面。

## 多个 return

一个函数中可以有多个 `return`。常见于根据条件返回不同结果。

```c
int max2(int a, int b) {
    if (a > b) {
        return a;
    }

    return b;
}
```

如果 `a > b` 成立，执行 `return a;`，函数结束。否则继续执行 `return b;`。

再如判断是否为偶数：

```c
int is_even(int x) {
    if (x % 2 == 0) {
        return 1;
    } else {
        return 0;
    }
}
```

这里用 `1` 表示真，用 `0` 表示假。

## 非 void 函数应返回值

如果函数返回类型不是 `void`，通常每条可能执行到的路径都应该返回一个值。

错误示例：

```c
int get_sign(int x) {
    if (x > 0) {
        return 1;
    }
}
```

如果 `x <= 0`，函数没有返回值。这是不可靠的。

修正：

```c
int get_sign(int x) {
    if (x > 0) {
        return 1;
    } else if (x < 0) {
        return -1;
    } else {
        return 0;
    }
}
```

这样正数、负数、零都有明确返回值。

## 返回类型与表达式类型

`return` 后面的表达式类型应与函数返回类型相适合。

```c
double average(int a, int b) {
    return (a + b) / 2.0;
}
```

这里返回类型是 `double`，`(a + b) / 2.0` 的结果也是小数。

如果写成：

```c
double average(int a, int b) {
    return (a + b) / 2;
}
```

`2` 是整数，表达式可能先按整数除法计算，再转换为 `double`。例如 `average(3, 4)` 可能得到 3.0，而不是 3.5。

因此需要写 `2.0`：

```c
return (a + b) / 2.0;
```

类型转换已经在 C09 中学习过，本节重点是：返回表达式的类型要符合函数设计意图。

## 返回值与输出不是一回事

很多初学者会把“返回值”和“输出到屏幕”混为一谈。

```c
int add(int a, int b) {
    return a + b;
}
```

这个函数返回结果，但不会自动显示到屏幕。

```c
void print_sum(int a, int b) {
    printf("%d\n", a + b);
}
```

这个函数输出结果，但没有把结果返回给调用者。

区别：

| 行为 | 结果给谁 |
|---|---|
| `return` | 交给调用者继续使用 |
| `printf` | 显示到屏幕 |

如果后续代码还要使用计算结果，通常应该返回值；如果只是展示信息，可以输出。

## main 函数的返回值

`main` 函数通常写成：

```c
int main(void) {
    return 0;
}
```

这里 `return 0;` 表示程序正常结束。

在许多学习环境中，即使省略 `main` 末尾的 `return 0;`，程序也可能正常运行。但初学阶段建议保留它，因为这能帮助理解 `main` 也是一个返回 `int` 的函数。

## 不要返回局部变量的地址

后面学习指针时会更深入理解这一点。现在可以先记住：

```c
int *bad(void) {
    int x = 10;
    return &x; // 错误示例
}
```

`x` 是函数内部的局部变量，函数结束后它的存储空间不再可靠。返回它的地址会造成危险错误。

注意：返回普通局部变量的值是可以的。

```c
int good(void) {
    int x = 10;
    return x;
}
```

这里返回的是 `x` 的值，而不是 `x` 的地址。

## 示例

```c
#include <stdio.h>

double average(int a, int b) {
    return (a + b) / 2.0;
}

int main(void) {
    int x;
    int y;

    scanf("%d %d", &x, &y);

    double result = average(x, y);
    printf("%.2f\n", result);

    return 0;
}
```

## 代码逐行解释

- `double average(int a, int b)`：定义函数，返回类型是 `double`。
- `return (a + b) / 2.0;`：计算两个整数的平均值，并返回小数结果。
- `scanf("%d %d", &x, &y);`：输入两个整数。
- `average(x, y)`：调用函数，把 `x` 和 `y` 的值传入。
- `double result = ...`：保存函数返回值。
- `printf("%.2f\n", result);`：保留两位小数输出结果。

## 常见错误

- 非 `void` 函数缺少 `return`。
- 某些条件路径没有返回值。
- 返回类型与 `return` 表达式类型不匹配。
- 把 `printf` 当成返回值。
- 在 `return` 后面继续写以为会执行的语句。
- 返回局部变量的地址。
- 忽略整数除法导致返回结果不符合预期。

## 初学者常见误区

- 返回值是给调用者的，不是自动显示到屏幕。
- `return` 会结束当前函数。
- `void` 函数没有返回值，不能把它赋给变量。
- 有返回值的函数调用可以放在表达式中使用。
- 非 `void` 函数应保证所有合理路径都有返回值。
- 返回局部变量的值可以，返回局部变量的地址不可以。

## 语法格式

有返回值：

```c
返回类型 函数名(参数列表) {
    return 表达式;
}
```

无返回值：

```c
void 函数名(参数列表或 void) {
    语句;
    return;
}
```

调用并使用返回值：

```c
变量 = 函数名(实参列表);
printf("%d\n", 函数名(实参列表));
```

3. 提升：写一个 `get_grade` 函数，根据分数返回字符等级。
4. 提升：写一个 `abs_value` 函数，返回整数的绝对值。
5. 进阶：写一个函数，输入年份，返回它是否为闰年。

## 小结

返回值是函数向调用者交回结果的方式。学习本节时，要重点理解返回类型、`return` 语句和调用者使用返回值之间的关系。函数通过参数接收输入，通过返回值交回输出，这是函数设计中最基本的思路。
