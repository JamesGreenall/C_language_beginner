## 初学者导读

返回值是函数执行后交给调用者的结果。理解返回类型和 `return` 语句，有助于正确设计函数的输入和输出。

## 关键术语说明

- 返回类型：函数承诺会返回什么类型的值。
- `return`：结束函数并交回结果。
- `void`：表示没有返回值。
- 调用者：使用函数结果的那段代码。
- 局部变量地址：函数结束后会失效，不能返回。

## 核心概念

返回值是函数执行后交还给调用者的结果。返回类型决定函数可以返回什么数据。

## 关键内容

- `return` 结束函数并返回结果。
- `void` 函数可以不返回值。
- 返回值可以用于表达式。
- 返回局部变量的地址是危险错误。

## 示例

```c
double average(int a, int b) {
    return (a + b) / 2.0;
}
```

## 代码逐行解释

- `double average(int a, int b)`：函数返回一个小数结果。
- `(a + b) / 2.0`：使用 `2.0` 保证按小数除法计算。
- `return` 把平均值交给调用者。
- 如果写成 `/ 2`，有些情况下会更容易产生整数除法误解。

## 常见错误

- 非 `void` 函数缺少 `return`。
- 返回类型与表达式类型不匹配。
- 返回局部数组或局部变量地址。

## 初学者常见误区

- 非 `void` 函数应该返回对应类型的值。
- `return` 后面的代码通常不会再执行。
- 不要返回局部变量的地址。

## 语法格式

```c
return 表达式;
return;
```
