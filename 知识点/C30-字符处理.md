# C30. 字符处理

## 节点定位

- 所属模块：数组与字符串
- 学习难度：基础
- 建议学习时间：30-40 分钟
- 典型用途：判断、转换和统计单个字符。

## 学习目标

- 能说明字符处理和字符串处理的区别。
- 能理解字符在 C 语言中与整数编码有关。
- 能使用 `<ctype.h>` 中的常见字符判断函数。
- 能使用 `toupper`、`tolower` 进行大小写转换。
- 能理解字符处理函数通常不会直接修改原变量。
- 能结合字符串遍历统计字母、数字等字符。

## 初学者导读

C29 学习了字符串，字符串是一串字符。本节学习字符处理，重点是处理“单个字符”。

例如：

- 判断一个字符是不是数字。
- 判断一个字符是不是字母。
- 把小写字母转换成大写字母。
- 统计一个字符串中有多少个数字字符。

字符处理经常和字符串结合使用：字符串负责保存一串字符，字符处理函数负责逐个判断或转换其中的字符。

## 关键术语说明

- 字符：单个字符，如 `'A'`、`'7'`、`'#'`。
- 字符编码：字符在计算机中对应的整数编号。
- `<ctype.h>`：C 标准库中提供字符判断和转换函数的头文件。
- 判断函数：判断字符类别的函数，如 `isdigit`、`isalpha`。
- 转换函数：转换字符形式的函数，如 `toupper`、`tolower`。
- 返回值：函数执行后交回的结果。
- 单字符处理：一次处理一个字符，而不是一整串字符串。

## 学习思路

学习字符处理时，建议按以下顺序：

1. 先区分字符和字符串。
2. 再理解字符可以看作一个整数编码。
3. 学习常见判断函数，如是否数字、是否字母。
4. 学习大小写转换函数。
5. 最后结合字符串遍历，对每个字符逐个处理。

## 核心概念

字符处理函数通常处理一个字符，并返回判断结果或转换后的字符。

```c
#include <ctype.h>

char ch = 'a';
char upper = toupper(ch);
```

这里 `toupper(ch)` 返回转换后的字符，但不会自动修改 `ch`。如果要保存结果，需要赋值：

```c
ch = toupper(ch);
```

## 字符和字符串再次区分

字符用单引号：

```c
char ch = 'A';
```

字符串用双引号：

```c
char str[] = "A";
```

字符处理函数处理的是单个字符：

```c
isdigit(ch)
toupper(ch)
```

不能把整个字符串直接传给这些函数：

```c
char str[] = "abc";
toupper(str); // 错误思路
```

如果要转换字符串中的字符，应使用循环逐个处理。

## 字符与整数编码

在 C 语言中，`char` 属于整数类型。字符在底层会对应一个整数编码。

例如在常见编码中：

```c
printf("%d\n", 'A');
printf("%d\n", 'a');
printf("%d\n", '0');
```

可能输出类似：

```text
65
97
48
```

具体数字与字符编码有关。初学阶段不必背编码表，但要理解：字符可以参与比较和计算，是因为它底层对应整数编码。

例如：

```c
if (ch >= '0' && ch <= '9') {
    printf("digit\n");
}
```

这可以判断 `ch` 是否是数字字符。不过实际编程中，更推荐使用标准库函数 `isdigit`，表达更清楚。

## 引入 ctype.h

使用字符处理函数需要包含头文件：

```c
#include <ctype.h>
```

常见函数包括：

| 函数 | 作用 |
|---|---|
| `isdigit(ch)` | 判断是否为数字字符 |
| `isalpha(ch)` | 判断是否为字母 |
| `isalnum(ch)` | 判断是否为字母或数字 |
| `islower(ch)` | 判断是否为小写字母 |
| `isupper(ch)` | 判断是否为大写字母 |
| `isspace(ch)` | 判断是否为空白字符 |
| `toupper(ch)` | 转换为大写 |
| `tolower(ch)` | 转换为小写 |

判断函数的返回值通常表示真假：返回 0 表示假，返回非 0 表示真。

## 判断数字字符

```c
#include <ctype.h>

char ch = '7';

if (isdigit(ch)) {
    printf("digit\n");
}
```

`isdigit(ch)` 判断的是字符是否为 `'0'` 到 `'9'` 之间的数字字符。

注意：

```c
char ch = '7';
int n = 7;
```

`'7'` 是字符，`7` 是整数。二者不是同一个概念。

如果要把数字字符转成对应整数，可以写：

```c
int value = ch - '0';
```

例如 `'7' - '0'` 的结果是 7。

## 判断字母

```c
char ch = 'A';

if (isalpha(ch)) {
    printf("letter\n");
}
```

`isalpha` 判断字符是否为字母。

如果要分别判断大小写：

```c
if (islower(ch)) {
    printf("lowercase\n");
}

if (isupper(ch)) {
    printf("uppercase\n");
}
```

## 判断空白字符

空白字符不仅包括普通空格，还包括换行、制表符等。

```c
if (isspace(ch)) {
    printf("space-like character\n");
}
```

常见空白字符：

- 空格 `' '`
- 换行 `'\n'`
- 制表符 `'\t'`

这个函数在处理输入文本时很有用。

## 大小写转换

`toupper` 用于把小写字母转换为大写。

```c
char ch = 'a';
ch = toupper(ch);
printf("%c\n", ch);
```

输出：

```text
A
```

`tolower` 用于把大写字母转换为小写。

```c
char ch = 'A';
ch = tolower(ch);
printf("%c\n", ch);
```

输出：

```text
a
```

如果传入的字符本来不需要转换，通常会返回原字符。

```c
printf("%c\n", toupper('7')); // 仍然是 '7'
```

## 转换函数不会自动修改原变量

错误理解：

```c
char ch = 'a';
toupper(ch);
printf("%c\n", ch);
```

输出仍然是：

```text
a
```

因为 `toupper(ch)` 返回转换后的结果，但没有自动改变 `ch`。

正确写法：

```c
char ch = 'a';
ch = toupper(ch);
printf("%c\n", ch);
```

如果函数有返回值，通常需要接收或使用这个返回值。

## 输入单个字符

可以使用 `scanf(" %c", &ch);` 输入字符。

```c
char ch;
scanf(" %c", &ch);
```

`%c` 前面的空格用于跳过前面残留的空白字符，例如换行。这个细节在输入输出章节中已经介绍过。

如果写成：

```c
scanf("%c", &ch);
```

有时可能读到上一次输入留下的换行符。

## 遍历字符串处理每个字符

字符处理常与字符串结合使用。

统计字符串中有多少个数字字符：

```c
#include <ctype.h>
#include <stdio.h>

int main(void) {
    char str[] = "a1b2c3";
    int count = 0;

    for (int i = 0; str[i] != '\0'; i++) {
        if (isdigit(str[i])) {
            count++;
        }
    }

    printf("%d\n", count);
    return 0;
}
```

这里：

- `str[i]` 是字符串中的单个字符。
- `isdigit(str[i])` 判断这个字符是否为数字。
- 遇到 `'\0'` 时字符串结束。

## 将字符串转为大写

```c
#include <ctype.h>
#include <stdio.h>

int main(void) {
    char str[] = "Hello";

    for (int i = 0; str[i] != '\0'; i++) {
        str[i] = toupper(str[i]);
    }

    printf("%s\n", str);
    return 0;
}
```

输出：

```text
HELLO
```

注意这里必须写：

```c
str[i] = toupper(str[i]);
```

否则转换结果不会保存回数组。

## 字符处理与字符串处理的区别

| 内容 | 处理对象 | 示例 |
|---|---|---|
| 字符处理 | 单个字符 | `toupper(ch)` |
| 字符串处理 | 一串字符 | `strlen(str)` |

示例：

```c
char ch = 'a';
char str[] = "abc";

toupper(ch);   // 处理单个字符
strlen(str);   // 处理整个字符串
```

如果要对字符串中每个字符进行转换，需要循环：

```c
for (int i = 0; str[i] != '\0'; i++) {
    str[i] = toupper(str[i]);
}
```

## 示例

```c
#include <stdio.h>
#include <ctype.h>

int main(void) {
    char ch;

    scanf(" %c", &ch);

    if (isdigit(ch)) {
        printf("digit\n");
    } else if (isalpha(ch)) {
        printf("letter\n");
        printf("%c\n", toupper(ch));
    } else {
        printf("other\n");
    }

    return 0;
}
```

## 代码逐行解释

- `#include <ctype.h>`：引入字符判断和转换函数。
- `char ch;`：声明一个字符变量。
- `scanf(" %c", &ch);`：输入一个字符，并跳过前面的空白字符。
- `isdigit(ch)`：判断是否为数字字符。
- `isalpha(ch)`：判断是否为字母。
- `toupper(ch)`：返回转换为大写后的字符。
- `else`：处理既不是数字也不是字母的情况。

## 常见错误

- 把字符和字符串混淆，如把 `"A"` 当作单个字符。
- 忘记包含 `<ctype.h>`。
- 调用 `toupper(ch)` 后没有接收返回值。
- 用字符处理函数直接处理整个字符串。
- 输入字符时没有处理前一次输入留下的换行。
- 把数字字符 `'7'` 和整数 `7` 混为一谈。

## 初学者常见误区

- 字符处理函数一次处理一个字符。
- 判断函数返回 0 表示假，非 0 表示真。
- `toupper` 和 `tolower` 返回转换结果，不会自动修改原变量。
- 字符底层与整数编码有关，但写字符常量时仍要使用单引号。
- 处理字符串中的字符时，需要循环逐个处理。
- `%c` 读取字符时常需要在格式字符串前加空格来跳过空白。

## 语法格式

```c
#include <ctype.h>

isdigit(ch);
isalpha(ch);
isalnum(ch);
islower(ch);
isupper(ch);

```

遍历字符串并处理字符：

```c
for (int i = 0; str[i] != '\0'; i++) {
    str[i] = toupper(str[i]);
}
```

## 小结

字符处理关注单个字符的判断和转换，常用头文件是 `<ctype.h>`。它与字符串处理密切相关：字符串是一串字符，很多文本任务需要遍历字符串并逐个处理字符。学习本节时要重点区分字符和字符串，并记住大小写转换函数需要使用返回值。
