# C05. 标识符与关键字

## 节点定位

- 所属模块：数据、表达式与基础交互
- 学习难度：入门
- 建议学习时间：20-30 分钟
- 典型用途：在 C 程序中正确理解和使用“标识符与关键字”。

## 学习目标

- 能说清楚“标识符与关键字”解决的具体问题。
- 能在一段 C 代码中识别与“标识符与关键字”有关的语法现象。
- 能独立写出一个包含该知识点的最小示例程序。
- 能说明它与前置知识点、后续知识点之间的关系。

## 初学者导读

标识符是程序中由开发者命名的内容，例如变量名、函数名和类型名。关键字是 C 语言已经规定用途的保留词。理解二者的区别，是正确书写代码的基础。

## 关键术语说明

- 标识符：程序员自己起的名字。
- 关键字：C 语言保留词，例如 `int`、`if`、`return`。
- 大小写敏感：`Score` 和 `score` 是两个不同名字。
- 命名规则：名字能包含什么字符、不能怎样开头。
- 语义命名：名字能表达用途，例如 `student_count`。

## 核心概念

标识符是程序员给变量、函数、类型等起的名字。关键字是 C 语言保留的特殊单词，不能作为普通名字使用。

## 关键内容

- 标识符可由字母、数字、下划线组成。
- 标识符不能以数字开头。
- C 语言区分大小写。
- `int`、`return`、`if`、`while` 等是关键字。

## C 语言常见关键字速查

关键字是 C 语言已经规定好用途的单词，不能用作变量名、函数名或结构体名。初学阶段不需要一次性掌握所有细节，但应先知道这些词不能随意拿来命名。

### 数据类型相关

| 关键字 | 基本含义 | 简单示例 |
|---|---|---|
| `char` | 字符类型 | `char grade = 'A';` |
| `short` | 短整型 | `short age = 18;` |
| `int` | 整型 | `int count = 10;` |
| `long` | 长整型 | `long distance = 100000L;` |
| `float` | 单精度小数 | `float price = 3.5f;` |
| `double` | 双精度小数 | `double score = 95.5;` |
| `void` | 空类型，常表示无返回值或无参数 | `int main(void)` |

### 符号与范围修饰

| 关键字 | 基本含义 | 简单示例 |
|---|---|---|
| `signed` | 有符号数，可表示正数、负数和 0 | `signed int n;` |
| `unsigned` | 无符号数，通常只表示非负数 | `unsigned int count;` |

### 控制流程相关

| 关键字 | 基本含义 | 简单示例 |
|---|---|---|
| `if` | 条件成立时执行 | `if (score >= 60) { ... }` |
| `else` | 条件不成立时执行 | `else { ... }` |
| `switch` | 多分支选择 | `switch (choice) { ... }` |
| `case` | `switch` 中的某个分支 | `case 1:` |
| `default` | `switch` 中的默认分支 | `default:` |
| `for` | 常用于已知次数的循环 | `for (int i = 0; i < 10; i++)` |
| `while` | 条件成立时循环 | `while (n > 0)` |
| `do` | 先执行一次再判断的循环 | `do { ... } while (condition);` |
| `break` | 跳出循环或 `switch` | `break;` |
| `continue` | 跳过本轮循环剩余部分 | `continue;` |
| `goto` | 跳转到标签位置，初学阶段不建议使用 | `goto label;` |

### 函数与返回相关

| 关键字 | 基本含义 | 简单示例 |
|---|---|---|
| `return` | 结束函数并返回结果 | `return 0;` |

### 复合类型相关

| 关键字 | 基本含义 | 简单示例 |
|---|---|---|
| `struct` | 定义结构体 | `struct Student { ... };` |
| `union` | 定义共用体，多个成员共用一段内存 | `union Data { ... };` |
| `enum` | 定义枚举 | `enum Status { OK, ERROR };` |
| `typedef` | 给类型起别名 | `typedef int Integer;` |

### 存储与类型限定相关

| 关键字 | 基本含义 | 简单示例 |
|---|---|---|
| `const` | 表示值不应被修改 | `const double PI = 3.14;` |
| `static` | 改变变量生命周期或可见范围 | `static int count;` |
| `extern` | 声明外部定义的变量或函数 | `extern int total;` |
| `auto` | 自动存储期，局部变量默认如此，较少显式使用 | `auto int x;` |
| `register` | 建议编译器把变量放入寄存器，现代编译中较少使用 | `register int i;` |
| `volatile` | 表示变量可能被程序外部因素改变 | `volatile int flag;` |

### 运算符形式的关键字

| 关键字 | 基本含义 | 简单示例 |
|---|---|---|
| `sizeof` | 计算类型或变量占用的字节数 | `sizeof(int)` |

### 需要了解但不急于深入的关键字

| 关键字 | 基本含义 | 学习建议 |
|---|---|---|
| `inline` | 建议编译器内联函数 | 后续学习函数优化时再了解 |
| `restrict` | 用于指针优化的限定符 | 指针学习较深入后再了解 |
| `_Bool` | 布尔类型 | 可在了解 C99 标准时学习 |
| `_Complex` | 复数类型 | 基础语法阶段通常不用 |
| `_Imaginary` | 虚数类型 | 基础语法阶段通常不用 |

> 说明：不同 C 标准引入的关键字略有差异。基础学习阶段，应优先掌握 `int`、`char`、`double`、`if`、`else`、`for`、`while`、`return`、`struct`、`const`、`sizeof` 等高频关键字。

## 示例

```c
int student_count = 30;
int StudentCount = 40; // 与 student_count 是不同标识符
```

## 代码逐行解释

- `student_count` 是一个合法标识符，表达“学生数量”。
- `StudentCount` 也是合法标识符，但和 `student_count` 不是同一个名字。
- `int` 是关键字，不能拿来当变量名。
- 好名字能让别人不用猜就知道变量用途。

## 常见错误

- 使用关键字作为变量名。
- 名字以数字开头。
- 大小写混用导致找不到变量。

## 初学者常见误区

- 名字合法不代表名字好，`x` 合法但可能不清楚。
- 大小写不同就是不同名字。
- 不要用拼音缩写到别人看不懂。
- 关键字不能作为标识符，例如不能写成 `int int = 10;`。
- 有些关键字现在暂时用不到，但看到时应知道它们不是普通变量名。

## 语法格式

```text
合法标识符：student_count、sum2、_temp
非法标识符：2sum、int、student-name
```
