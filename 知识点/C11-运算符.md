# C11. 运算符

## 节点定位

- 所属模块：数据、表达式与基础交互
- 学习难度：入门
- 建议学习时间：20-30 分钟
- 典型用途：在 C 程序中正确理解和使用“运算符”。

## 学习目标

- 能说清楚“运算符”解决的具体问题。
- 能在一段 C 代码中识别与“运算符”有关的语法现象。
- 能独立写出一个包含该知识点的最小示例程序。
- 能说明它与前置知识点、后续知识点之间的关系。

## 初学者导读

运算符用于完成计算、赋值、比较、逻辑判断和地址操作等任务。初学者学习运算符时，不应只背符号，而要理解每类运算符“做什么”“结果是什么”“是否会修改变量”。其中，`=` 与 `==`、整数除法、逻辑运算、自增自减和优先级是最容易出错的部分。

## 关键术语说明

- 操作数：被运算符操作的数据。
- 赋值：把右边的值放到左边变量里。
- 比较：判断两个值大小或是否相等。
- 逻辑运算：把多个真假条件合在一起。
- 优先级：多个运算符同时出现时先算谁。
- 结合性：优先级相同的运算符按什么方向结合。
- 副作用：表达式除了产生结果，还修改了变量或程序状态。

## 核心概念

运算符用于对数据进行计算、比较、赋值或逻辑判断。

一个运算符通常需要操作数。例如：

```c
int sum = a + b;
```

其中，`+` 是运算符，`a` 和 `b` 是操作数，`a + b` 的结果会参与后续赋值。

## 关键内容

- 算术运算符：`+`、`-`、`*`、`/`、`%`
- 赋值运算符：`=`、`+=`、`-=`
- 比较运算符：`==`、`!=`、`>`、`<`
- 逻辑运算符：`&&`、`||`、`!`
- 自增自减：`++`、`--`
- 地址与解引用：`&`、`*`

## 1. 算术运算符

算术运算符用于数值计算。

| 运算符 | 含义 | 示例 |
|---|---|---|
| `+` | 加法 | `a + b` |
| `-` | 减法 | `a - b` |
| `*` | 乘法 | `a * b` |
| `/` | 除法 | `a / b` |
| `%` | 取余 | `a % b` |

示例：

```c
int a = 7;
int b = 3;

printf("%d\n", a + b); // 10
printf("%d\n", a - b); // 4
printf("%d\n", a * b); // 21
printf("%d\n", a / b); // 2
printf("%d\n", a % b); // 1
```

需要注意：

- 两个整数相除时，结果仍按整数处理，小数部分会被丢弃。
- `%` 只能用于整数，不能用于 `double` 这类浮点数。
- 除数不能为 0，`a / 0` 或 `a % 0` 都是错误。

## 2. 赋值运算符

赋值运算符用于把右边的值保存到左边变量中。

| 运算符 | 含义 | 等价理解 |
|---|---|---|
| `=` | 普通赋值 | `x = 10` |
| `+=` | 加后赋值 | `x += 3` 等价于 `x = x + 3` |
| `-=` | 减后赋值 | `x -= 3` 等价于 `x = x - 3` |
| `*=` | 乘后赋值 | `x *= 3` 等价于 `x = x * 3` |
| `/=` | 除后赋值 | `x /= 3` 等价于 `x = x / 3` |
| `%=` | 取余后赋值 | `x %= 3` 等价于 `x = x % 3` |

示例：

```c
int x = 10;
x += 5; // x 变为 15
x *= 2; // x 变为 30
```

初学者必须区分：

```c
x = 10;   // 赋值：把 10 放入 x
x == 10;  // 比较：判断 x 是否等于 10
```

## 3. 关系运算符

关系运算符用于比较两个值，结果表示真假。在 C 语言中，`0` 表示假，非 `0` 表示真。

| 运算符 | 含义 | 示例 |
|---|---|---|
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于等于 | `a >= b` |
| `<=` | 小于等于 | `a <= b` |

示例：

```c
int score = 75;
int pass = score >= 60;
```

如果 `score >= 60` 成立，`pass` 的值通常为 `1`；否则为 `0`。

常见错误：

```c
if (score = 60) {  // 错误倾向：这是赋值，不是判断相等
}
```

应写成：

```c
if (score == 60) {
}
```

## 4. 逻辑运算符

逻辑运算符用于组合多个条件。

| 运算符 | 含义 | 示例 |
|---|---|---|
| `&&` | 逻辑与，并且 | `a > 0 && a < 10` |
| `||` | 逻辑或，或者 | `a < 0 || a > 100` |
| `!` | 逻辑非，取反 | `!ok` |

示例：

```c
int score = 85;
int valid = score >= 0 && score <= 100;
```

这里 `score >= 0` 和 `score <= 100` 都成立时，`valid` 才为真。

### 短路求值

`&&` 和 `||` 具有短路求值特点：

- `A && B`：如果 `A` 已经是假，就不会继续计算 `B`。
- `A || B`：如果 `A` 已经是真，就不会继续计算 `B`。

示例：

```c
if (count != 0 && sum / count > 60) {
    printf("average is greater than 60\n");
}
```

这里先判断 `count != 0`，可以避免 `sum / count` 出现除以 0 的问题。

## 5. 自增与自减运算符

`++` 表示变量加 1，`--` 表示变量减 1。

```c
int i = 0;
i++; // i 变为 1
i--; // i 变为 0
```

它们有前置和后置两种写法：

| 写法 | 含义 |
|---|---|
| `++i` | 先加 1，再使用新值 |
| `i++` | 先使用旧值，再加 1 |
| `--i` | 先减 1，再使用新值 |
| `i--` | 先使用旧值，再减 1 |

示例：

```c
int i = 1;
int a = ++i; // i 先变成 2，a 得到 2

int j = 1;
int b = j++; // b 先得到 1，j 再变成 2
```

初学阶段建议：不要把 `++`、`--` 放进复杂表达式中。更清楚的写法是单独一行：

```c
i++;
```

## 6. 条件运算符

条件运算符 `?:` 可以根据条件在两个值中选择一个。

```c
int max = a > b ? a : b;
```

含义是：

- 如果 `a > b` 成立，结果是 `a`。
- 否则结果是 `b`。

它适合简单选择，但不适合写很复杂的逻辑。复杂情况优先使用 `if/else`。

## 7. sizeof 运算符

`sizeof` 用于计算类型或变量占用的字节数。

```c
printf("%zu\n", sizeof(int));

double price = 9.99;
printf("%zu\n", sizeof(price));
```

`sizeof(int)` 查看类型大小，`sizeof(price)` 查看变量占用空间。结果类型通常用 `%zu` 输出。

## 8. 地址运算符与解引用运算符

这部分会在指针章节详细学习，本节先了解基本形式。

| 运算符 | 含义 | 示例 |
|---|---|---|
| `&` | 取地址 | `&value` |
| `*` | 解引用，访问指针指向的数据 | `*p` |

示例：

```c
int value = 10;
int *p = &value;
printf("%d\n", *p);
```

这里：

- `&value` 表示取得变量 `value` 的地址。
- `p` 保存这个地址。
- `*p` 表示通过地址访问 `value` 的值。

需要注意：`*` 既可以表示乘法，也可以用于指针解引用。具体含义要看它出现的位置。

## 9. 位运算符

位运算符直接操作整数的二进制位，初学阶段只需要先了解名称。

| 运算符 | 含义 |
|---|---|
| `&` | 按位与 |
| `|` | 按位或 |
| `^` | 按位异或 |
| `~` | 按位取反 |
| `<<` | 左移 |
| `>>` | 右移 |

示例：

```c
int x = 1 << 3; // 常见结果是 8
```

位运算在底层编程、权限标志、二进制处理等场景中常见。基础语法阶段可以先知道它们存在，不必立刻深入。

## 10. 运算符优先级与结合性

当一个表达式中出现多个运算符时，优先级决定先算谁。

```c
int result = 2 + 3 * 4; // 先算 3 * 4，再加 2，结果是 14
```

如果希望先算加法，应使用括号：

```c
int result = (2 + 3) * 4; // 结果是 20
```

常见优先级可以先记住下面这几类：

| 优先级大致顺序 | 运算符类型 | 示例 |
|---|---|---|
| 高 | 括号、函数调用 | `(a + b)` |
| 较高 | 自增自减、`sizeof`、取地址、解引用 | `++i`、`sizeof(int)`、`&x` |
| 中 | 乘除取余 | `*`、`/`、`%` |
| 中 | 加减 | `+`、`-` |
| 中 | 大小比较 | `>`、`<`、`>=`、`<=` |
| 中 | 相等比较 | `==`、`!=` |
| 较低 | 逻辑与、逻辑或 | `&&`、`||` |
| 低 | 赋值 | `=`、`+=` |

初学阶段不必强行背完整优先级表。更可靠的习惯是：当表达式稍微复杂时，主动加括号。

## 示例

```c
int x = 10;
x += 5;
int ok = x > 10 && x < 20;
```

## 代码逐行解释

- `int x = 10;`：先给变量一个初始值。
- `x += 5;` 等价于 `x = x + 5;`。
- `x > 10 && x < 20`：同时判断 x 大于 10 且小于 20。
- 比较表达式的结果常用于 `if` 或循环条件。

## 常见错误

- 把 `=` 当成 `==`。
- 不理解运算符优先级。
- 在复杂表达式中过度使用 `++`。
- 用 `%` 计算小数取余。
- 在逻辑表达式中混淆 `&&` 和 `||`。
- 忘记除数不能为 0。
- 把位运算符 `&` 和逻辑运算符 `&&` 混淆。

## 初学者常见误区

- `=` 是赋值，`==` 才是判断相等。
- 不确定优先级就加括号，清楚比追求复杂写法重要。
- `++` 放在复杂表达式里容易造成误解，初学时少这样写。
- 关系运算符的结果也是一个值，在 C 中通常用 `0` 表示假、非 `0` 表示真。
- `&` 在不同场景中含义不同，可能是取地址，也可能是按位与。
