## 初学者导读

文件读写使程序能够从磁盘读取数据或将结果保存到磁盘。掌握文件操作后，程序的数据不再只存在于一次运行过程中。

## 关键术语说明

- 文件指针：`FILE *`，用来代表一个打开的文件。
- 打开模式：如 `"r"` 读、`"w"` 写。
- 文件流：程序和文件之间的数据通道。
- 关闭文件：用完后释放相关资源。
- 读写失败：文件不存在、权限不足等情况。

## 核心概念

文件读写让程序可以把数据保存到磁盘，或从磁盘读取已有数据。

## 关键内容

- `FILE *` 表示文件对象指针。
- `fopen` 打开文件。
- `fclose` 关闭文件。
- `fprintf`、`fscanf` 进行格式化文件读写。
- `fgets` 适合按行读取文本。

## 示例

```c
FILE *fp = fopen("data.txt", "w");
if (fp != NULL) {
    fprintf(fp, "hello\n");
    fclose(fp);
}
```

## 代码逐行解释

- `fopen("data.txt", "w")`：以写入模式打开文件。
- `fp != NULL`：确认文件打开成功。
- `fprintf(fp, "hello\n")`：把文字写入文件。
- `fclose(fp)`：关闭文件，确保数据保存并释放资源。

## 常见错误

- 不检查 `fopen` 是否失败。
- 忘记关闭文件。
- 混淆文本模式和二进制模式。

## 初学者常见误区

- 打开文件可能失败，必须检查 `fp`。
- 写完文件要关闭，否则数据可能没有完全保存。
- 文本模式和二进制模式适合不同数据。

## 语法格式

```c
FILE *fp = fopen("文件名", "模式");
if (fp != NULL) {
    读写操作;
    fclose(fp);
}
```
