# C06. 基本数据类型

## 节点定位

- 所属模块：数据、表达式与基础交互
- 学习难度：入门
- 建议学习时间：20-30 分钟

- 能独立写出一个包含该知识点的最小示例程序。

## 初学者导读

数据类型决定一个数据能表示什么内容、占用多少内存空间，以及可以参与哪些运算。初学者学习数据类型时，不应只记住 `int`、`double`、`char` 这些名字，还要理解它们分别适合保存什么数据，以及选错类型会带来什么问题。

## 关键术语说明

- 整型：用于保存整数，例如人数、次数、编号、年龄。
- 浮点型：用于保存带小数部分的数据，例如身高、价格、平均分。
- 字符型：用于保存单个字符，例如 `'A'`、`'x'`、`'0'`。
- 空类型：`void`，常用于表示“没有返回值”或“没有参数”。
- 字节：内存大小单位，数据类型不同，占用的字节数可能不同。
- `sizeof`：查看某个类型或变量占多少字节。

## 核心概念

数据类型决定变量能保存什么数据、占用多少内存、可以进行哪些运算。

可以把数据类型理解为对数据的“分类规则”。例如：

- 学生人数、循环次数、数组下标通常是整数，适合用整型。
- 商品价格、考试平均分、身高体重可能带小数，适合用浮点型。
- 成绩等级、菜单选项中的单个字符适合用字符型。
- 函数没有返回值时，常使用 `void` 表示“没有结果需要返回”。

## 关键内容

- 整型：`char`、`short`、`int`、`long`、`long long`
- 浮点型：`float`、`double`
- 空类型：`void`
- 类型可配合 `signed`、`unsigned` 使用。
- `sizeof` 可查看类型或变量占用的字节数。

## 整型：用于保存整数

整型用于保存没有小数部分的数。常见场景包括人数、年龄、次数、编号、数组下标等。

| 类型 | 基本含义 | 常见用途 |
|---|---|---|
| `char` | 字符类型，本质上也属于整数类型的一种 | 保存单个字符，如 `'A'` |
| `short` | 短整型 | 较小范围的整数，使用较少 |
| `int` | 整型 | 最常用的整数类型 |
| `long` | 长整型 | 需要更大整数范围时使用 |
| `long long` | 更长的整型 | 需要保存很大整数时使用 |

示例：

```c
int age = 18;
int student_count = 45;
long long population = 1400000000LL;
```

初学阶段，普通整数优先使用 `int`。只有当数值范围明显很大时，再考虑 `long` 或 `long long`。

## 浮点型：用于保存小数

浮点型用于保存带小数部分的数据。常见场景包括价格、平均分、测量结果等。

| 类型 | 基本含义 | 常见用途 |
|---|---|---|
| `float` | 单精度浮点型，占用空间较小，精度较低 | 对精度要求不高的小数 |
| `double` | 双精度浮点型，精度通常高于 `float` | 初学阶段更常用的小数类型 |

示例：

```c
float temperature = 36.5f;
double average_score = 87.75;
double price = 19.99;
```

初学阶段，涉及小数时通常优先使用 `double`。需要注意的是，浮点数并不适合表示所有精确小数，因此在比较两个小数是否相等时要格外谨慎。

## 字符型：用于保存单个字符

`char` 用于保存单个字符，字符需要使用单引号。

```c
char grade = 'A';
char option = 'y';
char digit = '5';
```

需要特别注意：

- `'A'` 是字符，只表示一个字符。
- `"A"` 是字符串，里面除了字符 `A`，末尾还包含字符串结束标记。
- `'5'` 是字符 5，不等同于整数 `5`，虽然它们在某些运算中可能发生转换。

## 空类型 void

`void` 表示“没有具体类型”或“没有返回值”。初学阶段最常见的写法有两种：

```c
int main(void) {
    return 0;
}

void print_line(void) {
    printf("hello\n");
}
```

在 `int main(void)` 中，括号里的 `void` 表示这个 `main` 函数不接收参数。  
在 `void print_line(void)` 中，函数名前面的 `void` 表示这个函数不返回结果。

## signed 与 unsigned

整型可以配合 `signed` 和 `unsigned` 使用：

| 写法 | 含义 |
|---|---|
| `signed int` | 有符号整数，可以表示负数、0 和正数 |
| `unsigned int` | 无符号整数，通常只表示 0 和正数 |

示例：

```c
signed int temperature = -5;
unsigned int count = 100;
```

初学阶段，如果没有特殊需求，普通整数使用 `int` 即可。`unsigned` 常用于数量、大小、编号等不应为负数的数据，但它也会带来一些比较和运算上的细节问题，后续学习时再深入理解。

## 底层要点：字节、范围与溢出

数据类型并不是只决定“名字怎么写”，还决定数据在内存中占多少空间，以及最多能表示多大或多小的值。

### 1. 为什么类型会有范围

计算机保存数据需要使用有限的内存空间。一个类型占用的字节数越多，通常能表示的范围越大。

例如，一个 `int` 在很多常见环境中占 4 字节，也就是 32 个二进制位。因为位数有限，所以它不可能表示所有整数，只能表示某个范围内的整数。

### 2. 常见整型范围

下面是常见 32/64 位环境中的典型情况，实际结果可能因编译器和平台不同而变化。

| 类型 | 常见字节数 | 常见有符号范围 | 常见无符号范围 |
|---|---:|---|---|
| `char` | 1 | 约 -128 到 127 | 0 到 255 |
| `short` | 2 | 约 -32768 到 32767 | 0 到 65535 |
| `int` | 4 | 约 -2147483648 到 2147483647 | 0 到 4294967295 |
| `long` | 4 或 8 | 与平台有关 | 与平台有关 |
| `long long` | 8 | 约 -9223372036854775808 到 9223372036854775807 | 0 到 18446744073709551615 |

> 表中的范围是常见实现的结果，不应在所有环境中绝对假设。写程序时，如果确实关心范围，应查看标准头文件中的常量。

### 3. 使用 limits.h 查看整型范围

C 标准库提供了 `<limits.h>`，其中定义了常见整型的范围常量。

```c
#include <stdio.h>
#include <limits.h>

int main(void) {
    printf("int min = %d\n", INT_MIN);
    printf("int max = %d\n", INT_MAX);
    printf("unsigned int max = %u\n", UINT_MAX);
    return 0;
}
```

常见常量包括：

| 常量 | 含义 |
|---|---|
| `CHAR_MIN`、`CHAR_MAX` | `char` 的范围 |
| `SHRT_MIN`、`SHRT_MAX` | `short` 的范围 |
| `INT_MIN`、`INT_MAX` | `int` 的范围 |
| `LONG_MIN`、`LONG_MAX` | `long` 的范围 |
| `LLONG_MIN`、`LLONG_MAX` | `long long` 的范围 |
| `UCHAR_MAX`、`UINT_MAX`、`ULLONG_MAX` | 无符号整数的最大值 |

### 4. 什么是整型溢出

整型溢出指的是：计算结果超出了该类型能够表示的范围。

例如，在常见环境中，`int` 的最大值大约是 `2147483647`。如果继续加 1，就超出了 `int` 能表示的范围。

```c
int x = 2147483647;
x = x + 1; // 有符号整数溢出，结果不可靠
```

对有符号整数来说，溢出属于非常危险的错误。C 语言标准不保证它会得到什么结果，程序可能看似正常，也可能产生错误结果。

### 5. unsigned 的回绕现象

无符号整数超出范围时，通常会按固定范围回绕。可以先把它理解为“超过最大值后又从 0 开始”。

```c
unsigned int n = 4294967295U;
n = n + 1; // 常见结果是 0
```

这种行为有时是有用的，但初学阶段更重要的是知道：`unsigned` 并不只是“不能为负数”这么简单，它还会影响比较和运算结果。

### 6. 浮点型的范围与精度

浮点型也有范围限制，但它的问题通常不是“溢出到另一个整数”，而是“精度不够”。

| 类型 | 常见特点 |
|---|---|
| `float` | 占用空间较小，精度较低，通常只能可靠表示约 6 到 7 位有效数字 |
| `double` | 精度更高，通常能可靠表示约 15 到 16 位有效数字 |

例如，下面的结果可能并不是精确的 `0.3`：

```c
double x = 0.1 + 0.2;
```

原因是很多十进制小数在二进制中无法被精确表示。初学阶段只需要记住：浮点数适合表示测量值和近似值，不适合直接用 `==` 判断两个小数是否完全相等。

## sizeof：查看类型占用空间

不同数据类型可能占用不同大小的内存。可以使用 `sizeof` 查看类型或变量占用的字节数。

```c
printf("%zu\n", sizeof(int));
printf("%zu\n", sizeof(double));
printf("%zu\n", sizeof(char));
```

说明：

- `sizeof(int)` 表示 `int` 类型占多少字节。
- `sizeof(age)` 表示变量 `age` 占多少字节。
- 不同编译器和平台上，某些类型的大小可能不同，因此应以实际运行结果为准。

## 类型选择建议

| 数据场景 | 推荐类型 | 原因 |
|---|---|---|
| 年龄、人数、次数 | `int` | 都是普通整数 |
| 平均分、价格、身高 | `double` | 可能包含小数 |
| 单个等级字符 | `char` | 只需要保存一个字符 |
| 很大的整数 | `long long` | 表示范围通常比 `int` 更大 |
| 无返回值函数 | `void` | 表示函数不返回结果 |

## 示例

```c
int age = 18;
double price = 9.99;
char grade = 'A';
printf("age = %d\n", age);
printf("price = %.2f\n", price);
printf("grade = %c\n", grade);
```

## 代码逐行解释

- `int age = 18;`：用整数类型保存年龄。
- `double price = 9.99;`：用双精度小数保存价格。
- `char grade = 'A';`：用字符类型保存一个等级字符。
- `%d` 用于按整数格式输出。
- `%.2f` 用于输出小数，并保留两位小数。
- `%c` 用于输出单个字符。
- 每种类型决定了数据的保存方式和可参与的运算。

## 常见错误

- 用 `int` 保存小数。
- 混淆字符 `'A'` 和字符串 `"A"`。
- 忽视整数溢出。
- 认为 `int` 可以保存任意大小的整数。
- 认为无符号整数只是不允许负数，而忽略它的回绕行为。
- 用 `%d` 输出 `double`，或用 `%f` 输出 `int`，导致格式不匹配。
- 认为 `float` 和 `double` 能精确表示所有小数。

## 初学者常见误区

- `char` 本质上也和整数有关，但学习初期先把它当单个字符。
- 小数默认常用 `double`，不要随便用 `int` 存小数。
- 不同电脑上类型大小可能有差异，所以要学会用 `sizeof` 验证。
- 类型不是单纯的“名字”，它会影响数据范围、内存大小、输出格式和运算结果。
