## 初学者导读

动态内存允许程序在运行时按需要申请空间。它提高了程序处理可变规模数据的能力，同时也要求开发者负责释放不再使用的内存。

## 关键术语说明

- 堆内存：程序运行时可动态申请的内存区域。
- `malloc`：申请指定大小的内存。
- `free`：释放不再使用的动态内存。
- 内存泄漏：申请后忘记释放。
- 悬空指针：释放后还保存旧地址的指针。

## 核心概念

动态内存允许程序在运行时申请和释放内存，适合处理大小不固定的数据。

## 关键内容

- `malloc` 申请内存。
- `free` 释放内存。
- `calloc` 申请并清零。
- `realloc` 调整内存大小。
- 使用动态内存需包含 `<stdlib.h>`。

## 示例

```c
#include <stdlib.h>

int *arr = malloc(10 * sizeof(int));
if (arr != NULL) {
    arr[0] = 1;
    free(arr);
    arr = NULL;
}
```

## 代码逐行解释

- `malloc(10 * sizeof(int))`：申请能放 10 个整数的空间。
- `arr != NULL`：确认申请成功。
- `arr[0] = 1;`：像数组一样使用动态内存。
- `free(arr); arr = NULL;`：释放后把指针清空，减少误用风险。

## 常见错误

- 忘记检查 `malloc` 返回值。
- 忘记 `free` 导致内存泄漏。
- `free` 后继续使用指针。

## 初学者常见误区

- `malloc` 可能失败，所以要检查返回值。
- 谁申请，谁负责释放，这是重要习惯。
- `free` 后不要继续使用原来的地址。

## 语法格式

```c
指针 = malloc(元素个数 * sizeof(元素类型));
if (指针 != NULL) {
    使用内存;
    free(指针);
    指针 = NULL;
}
```
