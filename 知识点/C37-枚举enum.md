## 初学者导读

枚举用于定义一组有名称的整数常量，适合表示状态、选项和错误码。使用枚举可以提升代码的可读性和维护性。

## 关键术语说明

- 枚举成员：一组有名字的整数常量。
- 默认编号：从 0 开始依次增加。
- 状态：程序当前处于哪种情况。
- 错误码：用编号表示不同错误。
- 可读性：用名字代替数字，让代码更清楚。

## 核心概念

枚举用于定义一组有名字的整数常量，让程序状态或选项更清晰。

## 关键内容

- 枚举成员默认从 `0` 开始递增。
- 可手动指定枚举值。
- 常用于状态、菜单选项、错误码。
- 与 `switch` 配合使用可读性很好。

## 示例

```c
enum Status {
    STATUS_OK,
    STATUS_ERROR
};

enum Status status = STATUS_OK;
```

## 代码逐行解释

- `enum Status`：定义一组状态值。
- `STATUS_OK` 默认通常是 0。
- `STATUS_ERROR` 默认通常是 1。
- `status = STATUS_OK` 比 `status = 0` 更容易看懂。

## 常见错误

- 以为枚举成员是字符串。
- 不处理未知枚举值。
- 命名过短导致含义不明。

## 初学者常见误区

- 枚举值不是字符串，而是有名字的整数。
- 不要依赖别人一定只传合法枚举值。
- 枚举名和成员名要能表达业务含义。

## 语法格式

```c
enum 类型名 {
    枚举值1,
    枚举值2
};
```
