## 初学者导读

指针是用于保存内存地址的变量。理解指针时，应先区分“数据本身”和“数据所在的位置”，再理解通过地址间接访问数据的过程。

## 关键术语说明

- 指针变量：专门保存地址的变量。
- 取地址 `&`：得到变量的位置。
- 解引用 `*`：根据地址找到并访问那个位置的数据。
- 空指针：不指向任何有效位置的指针。
- 指针类型：决定把地址处的数据当成什么类型理解。

## 核心概念

指针是保存地址的变量。通过指针可以间接访问或修改某个内存位置中的数据。

## 关键内容

- 声明指针：`int *p;`
- 取地址：`p = &x;`
- 解引用：`*p`
- 空指针：`NULL`
- 指针类型决定解引用方式和指针运算步长。

## 示例

```c
int x = 10;
int *p = &x;
*p = 20;
```

## 代码逐行解释

- `int x = 10;`：普通变量保存数据 10。
- `int *p = &x;`：指针 p 保存 x 的地址。
- `*p = 20;`：通过 p 找到 x 的位置，把里面的值改成 20。
- 这说明指针可以间接修改变量。

## 常见错误

- 使用未初始化指针。
- 解引用空指针。
- 指针类型不匹配。

## 初学者常见误区

- 指针未初始化就使用非常危险。
- `*` 在声明和使用时含义相关但读法不同：声明指针、解引用。
- 建议先画出变量存储位置与地址指向关系，再阅读代码。

## 语法格式

```c
类型名 *指针名;
指针名 = &变量;
*指针名 = 新值;
```
