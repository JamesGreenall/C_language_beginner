# C32. 指针基础

## 节点定位

- 所属模块：内存与指针
- 学习难度：重点进阶
- 建议学习时间：90-120 分钟
- 典型用途：保存变量地址，通过地址访问数据，并为数组传参、动态内存等内容建立基础。

## 学习目标

- 理解指针变量保存的是地址，而不是被指向对象的值。
- 会声明、初始化和使用基本指针变量。
- 区分 `&` 取地址与 `*` 解引用。
- 理解指针类型、空指针和未初始化指针。
- 能画出普通变量、指针变量与被指对象之间的关系。

## 一、为什么需要指针

普通变量直接保存数据：

```c
int score = 90;
```

指针变量则保存另一个对象的地址：

```c
int *p = &score;
```

这里可以分成三个层次理解：

- `score` 保存整数 90；
- `&score` 得到 `score` 的地址；
- `p` 保存这个地址，所以称 `p` 指向 `score`。

指针使程序能够根据地址间接找到数据。函数修改调用者变量、处理数组、管理动态内存等操作，都依赖这种能力。

## 二、指针变量也是变量

指针并不是地址本身的另一种名称，而是一个专门用于保存地址的变量。它与普通变量一样：

- 有自己的变量名；
- 有自己的类型；
- 自己也占用内存；
- 自己也有地址；
- 保存的内容恰好是另一个对象的地址。

```c
int value = 10;
int *p = &value;
```

关系可以写成：

```text
p 中保存 &value  ----->  value 中保存 10
```

不要把 `p` 与 `value` 看成同一个变量。修改 `p` 是改变“指向哪里”，修改 `*p` 才是改变“所指位置中的数据”。

## 三、声明指针

基本形式为：

```c
类型名 *指针变量名;
```

例如：

```c
int *p;
double *price_ptr;
char *letter_ptr;
```

这些声明分别表示：

- `p` 可以保存 `int` 对象的地址；
- `price_ptr` 可以保存 `double` 对象的地址；
- `letter_ptr` 可以保存 `char` 对象的地址。

`*` 靠近类型名或变量名都可以：

```c
int* p;
int *p;
```

二者语法意义相同。不过一次声明多个变量时要特别注意：

```c
int *p, q;
```

只有 `p` 是指针，`q` 是普通 `int`。为了减少误解，初学阶段建议每行只声明一个指针变量。

## 四、初始化指针

指针应在声明时获得一个明确状态。最常见的两种初始化方式是指向有效对象，或初始化为空指针。

```c
int number = 20;
int *p = &number;
int *q = NULL;
```

第一种情况下，`p` 指向 `number`；第二种情况下，`q` 明确表示当前不指向有效对象。

使用 `NULL` 时通常应包含：

```c
#include <stddef.h>
```

许多其他标准头文件也会定义 `NULL`，但直接依赖实际需要的头文件更清楚。

以下写法危险：

```c
int *p;
*p = 10;  // 错误：p 尚未初始化
```

未初始化的局部指针保存不确定值。程序不知道它指向哪里，因此不能解引用。

## 五、取地址运算符 &

一元运算符 `&` 用于取得对象地址：

```c
int value = 10;
int *p = &value;
```

类型关系是：

```text
value   的类型：int
&value  的类型：int *
p       的类型：int *
```

因为左右两边类型匹配，所以 `p = &value` 是合理赋值。

## 六、解引用运算符 *

当 `*` 出现在表达式中时，它表示“根据指针中保存的地址，访问该位置的对象”，这种操作称为解引用。

```c
int value = 10;
int *p = &value;

printf("%d\n", *p);
```

`p` 的值是地址，`*p` 的值是该地址处保存的整数，因此输出 10。

解引用不仅能读取数据，也能修改数据：

```c
*p = 35;
printf("%d\n", value);  // 35
```

执行 `*p = 35` 时，程序沿着 `p` 中保存的地址找到 `value`，再将该位置中的数据改为 35。

## 七、同一个 * 为什么有两种用法

观察下列代码：

```c
int *p = &value;
*p = 35;
```

- 第一行中的 `*` 属于声明语法，说明 `p` 是指针变量；
- 第二行中的 `*` 是解引用运算符，表示访问 `p` 指向的对象。

二者符号相同，但出现位置和作用不同。判断时先看它是否处于变量声明中。

## 八、完整示例：通过指针读写变量

```c
#include <stdio.h>

int main(void) {
    int score = 80;
    int *p = &score;

    printf("score 的值：%d\n", score);
    printf("score 的地址：%p\n", (void *)&score);
    printf("p 保存的地址：%p\n", (void *)p);
    printf("p 指向的数据：%d\n", *p);

    *p = 95;
    printf("修改后的 score：%d\n", score);

    return 0;
}
```

应重点观察：

- `&score` 与 `p` 保存的地址相同；
- `score` 与 `*p` 表示同一个对象中的值；
- `&p` 是指针变量 `p` 自己的地址，通常与 `&score` 不同。

## 九、指针类型为什么重要

指针类型告诉编译器如何解释所指位置中的数据。

```c
int count = 100;
int *p = &count;
```

`int *` 表明：解引用 `p` 时，应按 `int` 的大小和表示方式读取数据。此外，指针加 1 时，也应移动到下一个 `int` 对象的位置。

类型不匹配通常会产生警告：

```c
double price = 9.5;
int *p = &price;  // 类型不匹配
```

不要为了消除警告而随意进行强制类型转换。类型不匹配往往意味着程序设计本身存在问题。

## 十、空指针 NULL

空指针表示“目前没有指向有效对象”。

```c
int *p = NULL;
```

可以判断它是否为空：

```c
if (p != NULL) {
    printf("%d\n", *p);
}
```

空指针可以比较和赋值，但不能解引用：

```c
*p = 10;  // 错误：不能解引用空指针
```

空指针的意义是明确表达“没有有效目标”，它比未初始化指针安全，因为程序可以检查它。

## 十一、改变指针与改变所指对象

```c
int a = 10;
int b = 20;
int *p = &a;

*p = 15;  // 修改 a
p = &b;   // 改变 p 的指向
*p = 25;  // 修改 b
```

执行结果是 `a` 为 15，`b` 为 25。

- `p = &b` 修改的是指针变量自身保存的地址；
- `*p = 25` 修改的是该地址所指向的对象。

这是阅读指针代码时最需要保持清楚的区别。

## 十二、指向同一对象的多个指针

```c
int value = 10;
int *p = &value;
int *q = &value;

*p = 30;
printf("%d\n", *q);  // 30
```

`p` 与 `q` 是两个不同的指针变量，但它们保存同一个地址，所以通过任意一个指针修改对象，另一个指针再次读取时都会看到新值。这种现象称为别名，即多个表达式能够访问同一个对象。

## 十三、const 与只读访问

如果程序只需要通过指针读取数据，不应修改数据，可以写成：

```c
int value = 10;
const int *p = &value;

printf("%d\n", *p);
// *p = 20;  // 错误：不能通过 p 修改 value
```

`const int *p` 表示不能通过 `p` 修改它所指向的整数，但 `p` 自身仍可以改为指向其他整数。

更复杂的 `int *const p` 涉及“指针本身不可改变”，初学阶段先掌握 `const int *` 的只读含义即可。

## 十四、指针的基本安全规则

每次解引用指针前，都应确认以下条件：

1. 指针已经初始化；
2. 指针不是空指针；
3. 指针所指对象仍在生命周期内；
4. 指针类型与对象类型适合；
5. 如果指向数组元素，访问没有越过数组边界；
6. 如果指向动态内存，该内存尚未被释放。

编译器不一定能发现所有违反规则的情况。程序即使暂时没有崩溃，也不代表访问是正确的。

## 十五、常见错误与辨析

### 1. 未初始化就解引用

```c
int *p;
printf("%d\n", *p);  // 未定义行为
```

### 2. 解引用空指针

```c
int *p = NULL;
printf("%d\n", *p);  // 未定义行为
```

### 3. 把整数值当成地址

```c
int value = 10;
int *p = value;  // 错误：value 是整数，不是 int 地址
```

### 4. 忘记解引用

```c
int value = 10;
int *p = &value;
printf("%d\n", p);  // 格式和含义都不正确
```

若想输出数据，应使用 `*p` 和 `%d`；若想输出地址，应使用 `(void *)p` 和 `%p`。

### 5. 返回局部变量地址

局部变量生命周期结束后，它的地址失效。不要把这种地址交给函数外部继续使用。

## 十六、与后续知识的联系

- C33 指针与数组：指针可以指向数组元素，并按元素位置移动。
- C34 指针与函数：把地址作为参数传入函数，实现对外部数据的访问和修改。
- C35 动态内存：内存申请函数返回地址，必须使用指针接收。
- C36 结构体：指针可以指向结构体，并通过成员访问运算符使用其成员。
- C44 常见未定义行为：无效解引用是 C 程序中常见且危险的问题。

## 分层练习

1. 声明整数 `number` 和指向它的指针 `p`，分别输出 `number`、`&number`、`p` 和 `*p`。
2. 通过指针把 `number` 从 10 修改为 50，并验证普通变量的值也发生变化。
3. 声明两个整数，让同一个指针先后指向它们并分别修改。
4. 解释 `p`、`*p`、`&p` 三个表达式各表示什么。
5. 找出并修正“未初始化指针”“空指针解引用”和“指针类型不匹配”三个错误。

## 小结

指针是保存地址的变量。`&` 从对象得到地址，`*` 根据地址访问对象。学习指针时应始终分清“指针变量自身”“指针保存的地址”和“地址所指向的数据”这三个层次，并在每次解引用前确认地址有效。
