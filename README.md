# C 语言基础语法知识图谱

一个面向 C 语言初学者的系统化学习仓库。项目将基础语法拆分为 45 个知识点，并通过前置依赖、核心路径和横向关联组织成可交互的知识图谱，帮助学习者理解“先学什么、为什么要学、接下来学什么”。

## 项目内容

- **45 篇知识点文档**：覆盖开发环境、数据类型、控制流程、函数、数组、指针、结构体、预处理、文件读写、调试和小型程序设计。
- **9 个学习模块**：从最小可运行程序逐步过渡到完整项目开发。
- **117 条知识关系**：区分核心前置、一般前置和横向关联。
- **5 条推荐路径**：可按最小程序、控制流程、函数模块、内存和综合项目等目标学习。
- **交互式图谱**：支持搜索、筛选、路径高亮、节点拖动、缩放，以及前置和后续知识查看。
- **无构建依赖**：交互页面使用原生 HTML、CSS 和 JavaScript，可通过任意静态 Web 服务器运行。

## 快速开始

交互页面会通过 `fetch` 读取 JSON 数据，因此建议使用本地 Web 服务器访问，而不是直接双击 HTML 文件。

```bash
python -m http.server 8000
```

然后在浏览器中打开：

```text
http://localhost:8000/
```

也可以使用 VS Code Live Server、Node.js `serve` 或其他静态文件服务器。

## 图谱数据

`c-knowledge-graph.json` 是交互页面的数据源，主要包含：

- `modules`：知识模块及其展示信息；
- `nodes`：知识点编号、标题、摘要和文档路径；
- `edges`：知识点之间的关系；
- `learningPaths`：推荐学习路径。

新增或调整知识点时，请同步检查 Markdown 文档、JSON 节点、关系边和推荐路径，避免页面数据与教程内容不一致。

## 部署到 GitHub Pages

1. 将仓库推送到 GitHub。
2. 进入仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和根目录 `/ (root)`，然后保存。

部署完成后，仓库根地址会通过 `index.html` 自动进入交互式图谱。
